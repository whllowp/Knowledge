# 记忆技术洞察 · 第 104 期（20261117-0100）

**主题：记忆的「可验证退役」（verified retirement）——训练过 ≠ 学会，学会 ≠ 可以从检索中退场**

> 洞察范围：2026 年（近 30 天为主）。四维度：发展趋势 / 技术现状 / 技术竞争力 / 技术挑战。

## 一、发展趋势

前 103 期把经验"写进记忆"（#1/#89）与"存进权重"（#80/#81/#84）研究到极致，也研究过"抹除"（#103），但都是单向：经验进来、越积越多。11-06 的 ENGRAM 首次追问反向问题——一条经验何时可从在线检索中安全退役？竞争轴从"记得更多"转向"记得更轻且不掉点"：把记忆从永久在线债务，变成可验证毕业的临时拐杖。

## 二、技术现状

ENGRAM（arXiv 2611.09472，11-06）把"允许参与训练"与"允许退出检索"拆成两个独立门控。Gate 1 示范感知准入：学生 mastery 不足时，只要成功教师示范达阈值（d_min=2）也可入学，打破"越不会越学不到"的冷启动悖论。Gate 2 释放门要求隔离探针上"无检索新权重"不弱于"基础模型＋检索"（相对门 δ）且超过绝对线（α），逐技能判定，分三态：批准释放、仅激活（有增益但不够资格退役）、不批准。

## 三、技术竞争力

HotpotQA 600 条经验/5 类技能仅 3 类通过释放，可检索足迹降 55.2%（269 条），但归档不等于删除、总量仍 600。固定检查点对照最见真章：立即全放 F1 跌 4.3 点、随机放跌 3.5 点，验证后释放仅跌 0.2（CI[−0.6,0.2]）——同样省 55% 预算，验证规则凭空换回 3.3 点。五项目（OpenViking v0.5.5／Hy-Memory 2.0.16＋MemHub v1.0.7／TencentDB v2.0.3／dsh v26092802／ReMe v0.4.2.2）零权重巩固验证、零逐技能退役门，倒挂延续。

## 四、技术挑战

①验证者失真：WebShop 100 目标中 ENGRAM 成功 47 vs Base 44，却有 14 例失败转成功、11 例成功转失败——平均提升掩盖逐样本回归，小探针 n=3 远不够，接 #94。②归档≠删除：退役只降在线足迹不降总存储，权重会忘旧事实、判不出"从未记录"，仍需文本兜底。③反证明确：WebShop 83.4 低于 MAGE 84.0、FinQA 69.3 低于 APOLLO 70.9，非全面占优。④延迟反直觉：ALFWorld token 降 42.8% 但墙钟从 43.76 升到 65.91 秒，与 #96 同源。

## 五、需求分析

长程 agent 的隐性成本：成功经验全留在线检索，token 随任务膨胀，但一部分已练成"肌肉记忆"（权重能力），继续检索纯属冗余。用户要的不是"删记忆"——那会丢审计与回滚——而是"验证后可不再检索"的凭证：卸掉在线负担，又保留重开检索的路径。这与 #74/#103 的彻底遗忘相反。

## 六、用户旅程

客服 agent 半年积累 600 条问答经验，检索成本居高不下。运营者不"一键清空"，而是按技能（事实检索/实体识别/关系判断/复杂解析/多答案）分组，用隔离探针比对"无检索新权重"与"基础模型＋检索"：前三类通过、后两类未达标——于是只对前三类关检索、归档 331 条。某天探针发现某技能回退，从归档重开该技能检索并回滚适配器，而非全局重训。

## 七、具体实现方案

数据层把经验建成 ETG 图（技能/条件/轨迹/结果/来源五元组），来源字段支撑示范感知准入。训练层用 LoRA 微调，训练带 ETG 上下文、部署可选关闭。验证层每技能备隔离探针，双门判据 z=准入∧有效样本∧有探针∧(A_w−A_m≥δ)∧(A_w>α)，"激活"与"释放"分权。部署层逐技能路由，归档而非删除（保留审计/回滚），加漂移检测自动重开。评测报四本账：退役率、足迹降幅、逐样本回归率、墙钟延迟；AML 补 verified-retirement 维度，接 #56/#69。

## 八、本期新观点

1. **生命周期补"退役"终环**：写入→巩固→验证→退役，与 #1 闸门首尾对称——过去研究"怎么进"，本期研究"怎么出"。
2. **训练与释放解耦**：z=u（训练过即退役）跌 4.3 点，是 #1 闸门出口侧镜像；"激活≠退役"应成独立权限。
3. **相对门＋绝对门双约束**：防"两边都差但候选略好"被误放，是 #94 评判者偏差的权重验收解药。
4. **退役≠遗忘**：区别于回滚(#60)、遗忘(#74/#103)、压缩(#66)，归档保留可恢复性，深化"可逆性工程"。
5. **反证优先＋延迟陷阱**：11 例成功转失败、少 token 却更慢，不作普适结论（续 #56/#94/#96）。
