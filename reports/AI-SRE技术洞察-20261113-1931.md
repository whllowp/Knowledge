# AI-SRE 技术洞察（第 191 期）

**生成时间**：2026-11-13 19:31（北京时间）｜**窗口**：2026 年，重点最近 30 天
**本期主题**：输出面／结构面（Structured Output）——Agent 说人话时很清楚，转成 JSON 就掉字段；下游解析失败，上游以为成功

---

## 题眼

96 期说「工具显式报错时不可怕，可怕的是合式错值」；115 期说「返回 200 不等于动作生效」；142 期说「数据契约要带单位与空值语义」。三件事在 Agent 的输出侧汇成一个具体故障：**它用自然语言说得头头是道，一旦要求结构化输出（JSON/工具参数），就出现三类问题——字段少了、类型变了、被截断了**。而下游看到的是「解析失败」或「默认值」，**上游看到的却是「成功返回」**。**自然语言的容错是优点，结构化的容错是事故**：**缺一个字段，下游就按默认值走，而默认值往往是错的。** **输出契约不是格式问题，是正确性问题。** **而「解析成功」是最容易被误读的成功。**

## 一、发展趋势

**趋势一：从「解析后修补」转向「边界校验」。** 出口即校验；**不合 schema 就拒绝，不猜**。

**趋势二：从「自由 JSON」转向「schema 约束生成」。** 结构化输出模式；**但约束生成不保证语义**。**格式对、值错，一样是错。**

**趋势三：输出契约与数据契约合流。** 字段、单位、空值语义；**和输入一样要版本化**（142 期）。

## 二、技术现状：三种输出，三种失效

**自然语言：容错高。** 人能读懂；**但下游无法稳定解析**。

**结构化 JSON：容错低。** 缺字段、类型漂移、嵌套错位；**解析器一报错，整条链断**。

**工具参数：最严格。** schema 校验；**但校验通过不等于值对**（124 期）。

**现状：失败被默认值吞掉。** 字段缺失 → 默认值；**默认值往往是「0」「空」「false」，而业务以为是「没发生」**（96 期）。

**三种缺法，一种比一种难发现。** 缺字段（默认值吞）、类型漂移（"1" vs 1）、截断（半截 JSON）；**前两种解析成功，第三种才算显式失败**。

## 四、技术挑战

**一，缺字段被默认值吞。** 解析器给默认值；**上游不知道下游在猜**。

**二，截断发生在 token 上限。** JSON 半截；**解析失败或部分成功**（151 期）。

**三，schema 会漂移。** 模型升级、prompt 调整；**字段名/类型悄悄变**（137 期）。

**四，嵌套与数组。** 深层嵌套错位；**校验通过但语义错**。

**五，修复比重试更危险。** 解析器「尽力修补」；**修出来的 JSON 看起来对**。

**六，多语言/多格式。** 同一字段中英文混用；**下游按枚举解析就挂**。

**七，契约与版本脱节。** 输出 schema v2，下游还在 v1；**没有版本协商，升级就是事故**（172 期）。

## 五、需求分解、用户旅程与实现方案

### 5.1 需求（按优先级）

- **R1 `output.*` 字段**：`schema_id`、`valid`、`missing[]`、`truncated`、`repaired`、`contract_version`。
- **R2 schema 化**：每个结构化输出有 schema；**版本化**。
- **R3 边界校验**：出口即校验；**不合规拒绝，不修补**。
- **R4 截断检测**：token 上限与 finish reason；**截断即失败**。
- **R5 契约化**：字段/单位/空值语义进契约（142 期）。
- **R6 指标**：解析成功率、缺字段率、截断率、修复率。

### 5.2 用户旅程

- **平台工程师**：新结构化输出 → 定 schema → 边界校验 → 拒绝修补 → 版本协商。
- **SRE**：下游报错 → 查 `missing` → 发现字段缺失 → 修 prompt/加约束。
- **Agent**：输出被截断 → 收到 `truncated` → 分块重出，而不是硬塞。
- **审计**：抽查一次输出 → 核对 schema 与值 → 确认没有默认值吞错。

### 5.3 实现方案（90 天）

- **0–30 天：定 schema。** 结构化输出逐个建 schema；版本化。
- **30–60 天：边界校验。** 拒绝修补；截断检测；缺字段告警。
- **60–90 天：契约化。** 单位/空值语义；季度复核；指标上线；版本协商。

**第 133 个市场空白（五项）**：输出 schema 覆盖率、边界校验覆盖率、截断检测率、缺字段可报率、修复率可算率——无一内建；`output.*`／`schema.*` 为**第 102 次无人提字段族**。本地 173／173-kb 连续第 92 期成组启用：余锦泽 03「上下文装配、工具调用、结果校验」＝全库唯一把「结果校验」写成流水线环节的实践，本期首次当主线；配 96 期错值、142 期契约。判词：**本地把结果校验写进流水线，联网侧 2026 年才承认「合式错值」；两边都没把「字段齐全、类型正确、未被截断」做成输出验收。**
