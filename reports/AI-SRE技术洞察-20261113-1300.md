# AI-SRE 技术洞察（第 181 期 · 2026-11-13 13:00）

> **题眼｜新立面：人机闭环坍缩面 / 能力迁移衰减面（Human-AI Feedback Loop Decay / Skill Atrophy）**
> 全行业都在给 Agent 建「越用越强」的反馈环（轨迹资产、在线 RL、Badcase Loop），却没人给**人**建反馈环——当 Agent 吸走 Tier 1–2 的例行工单，值班工程师失去的是「手感」，留下的全是怪异、模糊、高影响的 Tier 0 事件。NIST 2026 与 Uptime Labs 的「Leftover Principle（左剩原理）」同时指向同一盲区：自动化监控能否替代人类校验，至今没有答案。本期把「人类值班能力保有率」立为一等运维对象。

## 一、发展趋势

2026 年的 Agentic SRE 叙事主线是「调查优先、自治缓行」：Gartner 在 1 月将其列为独立品类，Resolve AI 2 月以 12.5 亿美元估值完成 1.25 亿美元 A 轮，Google、AWS、OpenAI、字节、阿里、腾讯全部下场。但一个被刻意轻描淡写的趋势正在成型——**能力从人向 Agent 单向迁移**。早期采用者报告 MTTR 最高下降 70%，且几乎全部来自「调查阶段」的压缩（Ivinco 实测每次调查 6–27 次工具查询，结论草稿人人可用），而非无人值守修复。于是人退到「只批不查」，Agent 退到「只查不修」的舒适区。

更深一层的趋势是**反馈环的单极化**。本地知识库 173 的「评测→轨迹资产→受控进化」主题簇（22 肖汉松 / 31 马云雷 / 24 袁彬航 / 10 周昕毅）几乎全部围绕「让 Agent 越用越强」展开：阿福 Badcase Loop 把修复从 12.6 天压到 1–3 天形成可复核结果；马云雷把轨迹做成数字资产反哺 Benchmark；袁彬航 AReaL 2.0 用在线强化学习闭环让 Agent 持续进化。**整条证据链里，没有一环是为了保住「人」的能力而设计的**。2026 下半年的西方分析才开始补这块：NIST 将「human-AI feedback loops 研究不足」列为开放风险，Uptime Labs 提出 Leftover Principle——AI 接管常规故障后，剩余工作愈发异常复杂，而失去 Tier 1–2 实战的工程师在 Tier 0 来临时反而更弱。这构成本期要立的**第一百六十四条全新立面**。

## 二、技术现状

**厂商侧**：Google 的 AI Incident Hypothesis 把假设/验证步骤/看板推到 oncaller 主工具，MTTM 降 10%、调查看板降 44%，AI Operator 仅在小故障自主、关键缓解须人接受；Anthropic 的 on-call 演示里每个动作都需人批，并强调「记忆隔离区——被证伪就隔离」以阻止记忆层退化成谣言库；OpenAI 的 Sevbot「算缓解方案但不执行」；字节 SRE-Copilot 多 Agent 混合专家 + 火山引擎助手把 MTTR 从 45 压到 8 分钟；阿里 STAROps「人定目标与边界、Agent 持续工作」并开放 RCA Benchmark；腾讯 CloudQ + 蓝鲸 MCP 化、IEG 跑出 635 活跃智能体。

**人类侧**：现状是「零机制」。六家的治理都假设「人仍在环内、且仍有能力决策」，却没有任何一家度量「人现在还有没有这个能力」。aiexpert.news 引 Uptime Labs 量化了成本：误导性 AI 辅助会把人类表现拉到「不用 AI 还更低」的基线之下；goal lock（目标锁定）则让 Agent 修好表象、引爆下游（自动扩缩容触发费用告警、重启清空下游依赖的内存态、RBAC 改动锁死工程师），而脱手的人类更晚才发现。

**判读（反转点）**：六家全部把「越用越强」的闭环建在 Agent 一侧，六家「技能衰减应对 / 值班能力保活」列全空或最弱。真正把「人类校验」当工程问题的是安全研究侧（Anthropic 记忆隔离区），但它防的是记忆腐败，不是能力萎缩。**结论：「把目标托管给 AI」「第二意见」「记忆隔离」全部可采购，「举证这位工程师在 Agent 接管后是否还保有人工处置能力」不可采购。**

## 四、技术挑战

1. **左剩原理（Leftover Principle）**：AI 吃掉 Tier 1–2 后，剩余工单越来越怪、越模糊、越跨域，工程师失去日常「手感」，Tier 0 来临时决策质量不升反降。
2. **责任-能力背离（accountability gap）**：人对决策负形式责任，却渐进失去做此决策所需的现场上下文——NIST 2026 明确指出自动化监控能否替代人工校验仍是未解问题。
3. **反馈单极化**：全行业只建 Agent 学习环（22/31/24/10 本地原型），人类侧无对应环，形成「Agent 越练越强、人越退越生」的剪刀差。
4. **goal lock 放大效应**：Agent 修表象引发下游故障，因人类脱手而更晚暴露，且人类因长期不接触细节难以快速接管。
5. **评测-生产落差不可量化**：RCA Benchmark、ITBench-AA（前沿模型 SRE 任务 <50%）只测 Agent，不测「人机组合」的端到端恢复力，人类能力成了黑盒。

## 五、展望与建议

- **把「人类值班能力保有率」立为 SLO 基元**（呼应第 176 期决策质量 SLO）：设 `human.competence.*` 字段族——oncall_rep_rate（无 Agent 辅助独立处置比例）、shadow_mode_ratio（影子模式占比）、handoff_quality（交接上下文充分度）、leftover_coverage（剩余异常工单覆盖）、skill_decay_slo（能力保有目标）。六家零公开，第 128 个市场空白五项。
- **反馈环双向化**：Agent 学（轨迹资产 / 在线 RL）+ 人学（复盘萃取人机组合失误）+ 双向度量。把本地 31 马云雷「轨迹数字资产」的范式平移到「人的轨迹」——哪些故障是被 Agent 悄悄接管、人已不会处理的，应进回归集。
- **强制去 Agent 演练**：固定比例工单由人独立处理（影子模式回看），保留 Tier 1–2 手感，避免 Leftover Principle 滑向失控。
- **交接质量门禁**：Agent 移交给人的上下文须达到可快速上手标准，否则升级而非静默甩锅（深化第 179 期意图保真）。
- **评测扩展为人机组合基准**：RCA Benchmark / ITBench-AA 增加「有无人类辅助」对照组，度量端到端恢复力而非单测 Agent。
- **信通院六维补「人类能力保有率」格**，把组织级能力衰退纳入治理报表。
