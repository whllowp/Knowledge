# AgentMemory 技术洞察（第 21 期）

**报告时间**：2026-11-08 01:00（北京时间）
**覆盖范围**：2026 年 10 月下旬至 11 月 7 日，重点为最近 30 天
**本期主线**：记忆的替代品——上下文是记忆的对手，不是记忆的容器

> 前二十期依次拿掉了"写入可信""删除彻底""检索可靠""持久可恢复"，但都共享一个更基础的假设：记忆必需，因为上下文装不下。本期拿掉这个假设。11 月头七天出现三篇互不引用却同向的论文，把问题从容量之争改写为归约之争。

---

## 一、发展趋势

**一、从"上下文扩容"转向"上下文归约"。** Memento（arXiv:2611.00244，10-30，哥伦比亚大学）用 16K—20K 窗口的 8B 模型处理最长 250 万 token 的整本书问答；Rate-Limited Filtering（arXiv:2611.02361，11-02）证明显式状态在 256 个事件后稳定压过长上下文；Attention-Competition（arXiv:2611.04169，11-03，UCSD）指出退化根因根本不是长度。

**二、度量从召回率换到同键唯一性。** 过去两年比拼 LoCoMo 准确率与 token 降幅，两者都只是归约质量的下游指标。当一个 key 在窗口里同时存在三个取值，注意力从 0.51—0.77 被摊薄到 0.17—0.31，准确率从 0.97 掉到 0.25。记忆的第一性动作不是"存下来"，而是"把同键收敛为一个当前值、保留可回溯历史链"。

**三、价值论证被迫迁移。** 缓存读价已到基础输入的 0.1 倍，Anthropic Fable 5.1/Mythos 5.1 更降到 0.025 倍（$0.25/MTok，基础价 $10）。"记忆更省钱"这一最常用采购理由正被侵蚀，记忆必须改说去冲突与治理权。

**四、写入能力被重新识别为训练问题。** GPT-5.5 在 337 个样本上一条压缩笔记都没写；GLM-5.3 的 12,000 次 rollout 无一条有效笔记；Qwen3-8B 仅约 6% 轨迹合格且倾向连写重复笔记。纯 RL 救不回来——无 SFT 冷启动，压缩率 20 步内塌到近零。

## 二、技术现状

### 2.1 上下文侧：三组打架的证据，只有一种解释活得下来

Jagtap 6 月预印本在 15 万 token 内测不出长度退化；9 月 Boolean 研究在 terminal-bench v4 上发现 GPT-5.6 Sol 从 31% 掉到 24%（相关与无关填充一样），Claude Opus 5 对无关填充持平、对**任务相关填充**却从 50% 掉到 40%，且 25 万以上会"回跳"回答更早的问题；Chroma 的 18 模型报告显示语义连贯的干扰比打乱的更伤——当时当作长度有害的旁证，如今是反证。

arXiv:2611.04169 给出唯一能同时解释三者的机制。固定长度与证据位置，只改周边内容：中性填充下 8K—32K 损失中位数始终 ≤0.006 nats、准确率 0.96—1.00；换成**同键竞争陈述**，损失跳到 2.82/3.94/4.03/4.76 nats，准确率跌到 0.11—0.21。126,473 次试验中，证据注意力占比 log(1/a\*) 解释 35%—58% 的损失方差，log 长度只解释 2%—8%。

这对记忆是利好：**上下文变长几乎免费，致命的是同一个问题在窗口里有多个答案**。把多值收敛为一值正是记忆的职能——记忆不是把文本变短（压缩），是把多值收敛为单值（归约）。需打折：作者自曝竞争填充未排除被查询 key（约 1/51 重述该 key 并给不同值），修好的 measure_v4.py 却未运行。

### 2.2 记忆侧：地平线存在，但随读者移动

arXiv:2611.02361 把记忆重述为速率受限滤波：决策只依赖一个状态，大小由被追踪 key 数决定。在授权/撤回/恢复/过期的可执行基准上，7B—32B 模型在 8—16 个事件后还有 72%—86%，到 256 个事件只剩 48%—55%；读当前状态的 32B 推理模型是 96%/98%。关键在"地平线随读者增长"：120B 直读全历史，在 256/512 事件落后显式状态 4/7 个点，1,024 事件落后约 10 个点。**变强只是推迟，不是取消**。

另有被忽略的结构性发现：存储记录数少于状态所需 key 数时，会按容量决定的时间尺度遗忘。**容量不足不表现为"检索不到"，而表现为"答案悄悄变旧"**——一类不可观测的失效。

### 2.3 写入侧：笔记能力不可由提示诱导

Memento 两阶段值得抄：先用 GLM-5.3 跑正确轨迹、事后注入压缩笔记（关键结论/须避开的错误/下一步），约 6,000 条过筛后微调 Qwen3-8B；再用 GRPO，奖励含格式合规（门控项，不合规零奖励）、笔记有效性、答案正确性、置信度校准（负 Brier）。有效性靠三条手工启发式（非末窗至少一条且总数少于五、不得为首个工具调用或紧跟另一条、两条重合不超 80%）。巧处在训练与推理解耦：训练只练"压缩进新窗口"，测试时可支撑 context folding 与低置信回退检查点——本质是把记忆写成可回溯状态机。

### 2.4 产品侧：符号化与归约的工程实现

TencentDB-Agent-Memory v2.0.3（10-26）是最完整的"反上下文"样本：完整工具日志外置 Markdown，上下文只留任务状态的 **Mermaid 图 + node_id**，需细节按 id 回取原文——几百 token 的任务图替代几十万 token 日志。四类记忆各带 owner、version、visibility；跨会话走 L0→L1→L2→L3，下层 SQLite FTS5+vec0 保证据、上层 Markdown 保结构。自报 WideSearch 33%→50%、token −61.38%；SWE-bench 58.4%→64.2%、token −33.09%；PersonaMem 48%→76%（自家框架内、非受控、v2 仍 Beta）。

Hy-Memory 2.0（10-16）走专用模型：30B-A3B（约 3B 激活）在 Mem0/MemOS/Hy-Memory 三套框架上训练，四套评测宏观均 55.49%，高于 Claude Opus 5 的 54.62%；LoCoMo 72.6%，每题 token 1,159→703。AgenticSTS（Alaya Lab + 上海交大）在《杀戮尖塔 2》上做五层记忆，每得一分 token 为对照的 1/66—1/90，96% 时间损失来自等待超长提示（每组仅 10 局）。

其余指定对象：**ReMe** 走文件轨（Apache-2.0，3,578★，最近推送 10-09），10 月新增"决策模型上下文压缩"——按下一步动作给旧工具调用打分、保护关键历史、返回可恢复压缩提案。**dsh-memory-evolve** 为 MIT/JS 五轨插件，可按 git 分支限域、Memory Sync 用仓库分支做 remote 且冲突三选；索引页显示最近推送停在 10-01、0 fork，活跃度与声量继续脱节。**OpenViking** 本期未见新版，v0.5.2.1 仍为最新。**ReMe2Ops** 仍无独立实体，按 ReMe 运维化路径处理。

### 2.5 定价侧：厂商用价目表承认了"记忆必要"

Claude Haiku 5.5 在 10 万 token 以上跳档，Gemini 3.1 Pro 在 20 万，GPT-5.4 在 27.2 万以上对**整个会话**收 2 倍输入、1.5 倍输出，且缓存读随之翻倍；Anthropic 更把缓存读写计入 Haiku 5.5 阈值——**即使部分是命中，超阈值照样按高价计**。同时缓存把有效单价压到 0.1/0.05/0.025 倍，Google 对 Gemini 3.1 Pro 收 $0.20/1M（对 $2.00）外加 $4.50/1M/小时存储费。

两边合起来等于官方划出"安全上下文预算"这条线：线以下进上下文，线以上必须外置。而 Gartner 指出代理式模型每任务 token 是普通对话的 5—30 倍——**单价降、总账升**。

### 2.6 评测侧：AML 二期仍未见榜，Letta 给出第一张"每美元得分"表

AML 第二届 11-04 截止评测，榜单仍定在 11 月中；截至 11-06 的媒体稿仍是预热（首期：文本商业榜 MemoraX 58.02/MemOS 45.89/NTES 44.21；代码榜 MemoraX 62.00%，claude-mem v12.1.1、hs v3、MemOS 均 52.00%）。

新东西是 Letta FrontierMemory 榜：Dream 73.3%/$2.80 每任务、Prime 60.0%/$3.74、OpenAI Agents SDK 40.0%/$0.82、Claude Managed 33.3%/$3.21、Hermes 26.7%/$2.79。按每美元得分重排完全反转：OpenAI 48.8、Letta 26.2、Prime 16.0、Claude 10.4、Hermes 9.6。**总分第一者性价比第二，最便宜者性价比第一**。

## 三、技术竞争力

### 3.1 主要方案在"对阵长上下文"维度上的定位

| 方案 | 同键归约方式 | 替代上下文的策略 | 治理能力 | 公开收益 | 主要局限 |
|---|---|---|---|---|---|
| 裸长上下文（GPT-6 Astra/Fable 5.1/Gemini 3.1 Pro） | 无，多值并存 | — | 无删除与溯源 | 96.3%（OpenAI）/26.3%@1M（Google） | 同键冲突即崩；触发溢价 |
| 阈值压缩（Anthropic compact_20260112） | 摘要时顺带消解 | 15 万自动摘要重启（最小 5 万） | 可删原文，丢隐性细节 | 官方称上下文工程第一杠杆 | 有损不可逆；额外计费 |
| 符号化任务图（TencentDB v2.0.3） | L1 原子层收敛，node_id 唯一 | 日志外置，只留 Mermaid 图 | owner/version/visibility | token −61.38%（WideSearch） | 自家框架自报；Beta |
| 分层+专用模型（Hy-Memory 2.0） | L0→L2 逐层收敛 | 每题 703 token | 有接口，删后留原文 | MemoryArena 55.31%、LoCoMo 72.6% | 收益绑模型，换模型失效 |
| 时序知识图（Zep/Graphiti） | 双时态+事实自动失效 | 只注入当前有效子图 | 失效≠删除 | LongMemEval +18.5%、时延 −90% | 构图贵；失效靠 LLM 判 |
| 文件轨（ReMe） | 人工/Agent 编辑收敛 | 行级召回，不整库入窗 | 文件即真相，git 可回滚 | 14 查询压缩基准 | 归约靠人 |

### 3.2 判读

**一、归约能力取代召回能力成为分水岭。** 表中多数方案仍是"让模型在摘要时顺便消解冲突"，只有显式状态滤波与训练式笔记器把归约做成**可判定操作**。arXiv:2611.04169 已量化不消解的代价：同键冲突 0→6 个，损失从 0.03 单调爬升到 3.45 nats。

**二、"省 token"不再是可持续壁垒。** 缓存把长上下文压到 0.025 倍后，−61% 与 −39.3% 在绝对金额上被大幅稀释，且均为对自家基线的自报值。缓存无法复制的是归约与治理：它让同一段长前缀变便宜，但不能让其中三个矛盾取值变成一个。

**三、专用模型形成第二梯队门槛。** 30B-A3B 与 Memento 8B 都说明归约需专门训练，市场会切成"有专用模型的"与"只能调通用模型的"两层。第 1 期预判的"控制面/数据面分离"，如今更像"归约模型/存储层分离"。

**四、倒挂第十三次出现。** 归约最彻底的三家——2611.02361、Memento、AgenticSTS——都不是记忆产品；商业化最成熟的几家，公开材料里没有一家给出同键唯一性度量。

## 四、技术挑战

**一、归约正确性无人测。** AML 三轨八维测"能不能找到"，无一维测"取值是否唯一、是否为当前值"。"库里有三个矛盾地址、检索全部命中"在榜单上表现为满分——本系列连续第十四次记录同一结构性缺口。

**二、地平线依赖读者，ROI 不可迁移。** 同一系统在 32B 与 120B 读者上的必要时刻差一个量级（256 vs 1,024 事件）。按 A 模型做的论证换 B 模型可能反向，而该文预测器需被测模型内部信息，采购方拿不到。

**三、写入缺口无法用工程填补。** 6,000 条轨迹需自建 harness 采集并事后过滤。开源产品只能"多塞"，于是库膨胀、冲突累积、检索预算被陈旧槽位吃掉——这是第 19、20 期现象的上游成因。

**四、缓存折扣与溢价断点方向相反。** 单价可低至 1/40，但跨过 10 万/20 万/27.2 万即整段跳档，且部分厂商把命中计入阈值。稳妥做法是把安全预算设成硬上限（标称窗口的 20%—40%），超限交给记忆。

**五、压缩与归约的可逆性要求冲突。** Anthropic 自承压缩会丢"重要但当时不显眼"的上下文，而归约要求留历史链回答"为什么改"。共存只有一条路：当前值单列、历史值进冷存、链上留指针。

## 五、展望与建议

**判断：长上下文不会杀死记忆，只会杀死"只做压缩"的记忆；两个季度内，同键冲突密度会成为独立指标。** 它可自测：每 key 统计 distinct 当前值数，>1 即缺陷——谁先做进面板，谁就拿到归约能力的可证明性。

**建议一：用四问决策，不用容量决策。** 是否超出实测安全预算？是否跨会话？是否存在同键多值？是否需要删除举证？四问全否就不要建库，此时记忆是纯负债。任一为是才进入选型。

**建议二：写入侧优先于检索侧。** 写入不可由提示诱导、纯 RL 会崩塌；检索侧在 QEMem 之后已入平台期（+7.6pp 需三 agent 级联）。预算从"更好的嵌入"挪到"更好的笔记"，回报更确定。

**建议三：按每美元得分采购。** 总分第一与性价比第一不是同一家（26.2 vs 48.8 分/美元）。同时要求披露 token 口径是否含抽取与巩固的 LLM 成本——向量存储便宜，抽取调用可能贵 10—100 倍。

**建议四：把治理权写进合同。** 上下文不可治理（无 delete、无 supersede、无溯源），这是记忆唯一无法被缓存与窗口扩容替代的护城河。delete 语义、历史链保留期、超阈值行为应作不可外包条款。
