# 记忆技术洞察 · 第161期（20261127-0700）

> 洞察范围：2026 年、尤其近 30 天，AgentMemory 发展趋势／技术现状／技术竞争力／技术挑战四维度。主线：arXiv 2611.34576（11-25 提交），与本地 C/E 双版索引及知识台账比对后确认未重复前期主题。最近 arXiv 批次仍停在 11-25、五项目无新主线版本，故按预案输出往期未覆盖的深度专题。

## 一、发展趋势
记忆正从"记住用户偏好"走向"学出用户的决策程序"。11-25《Procedure Inference as Memory》（arXiv 2611.34576，LinkedIn 四人，cs.AI）把跨项目可观察决策炼成自然语言判断规则，并将"证据不足时弃答"列为记忆能力。与 #159 划界：那是 agent 自身工具执行的成功／失败经验，本期学的是对方（招聘官）的决策模式；与 #160 衔接：那里问证据是否充分，这里问谁来选择证据、谁来解读。

## 二、技术现状
OKF 情景记忆拆为 index.md／events.md／lineage.md：先用 LLM 或 4B Jev 决策模型从轻量索引选 top40 锚点，再沿谱系展开依赖、BM25＋向量检索补全、按时间重放。程序记忆由前 5 天可观察互动学出：提示反思三轮（60% 用于修订、40% 用于挑选），或 GRPO 训练 Qwen3.8-27B（G=4，KL 系数 0.002，奖励＝与真实招聘决策的一致率，不用隐藏偏好标签），第 6—14 天冻结应用模型与程序；学到的规则如"仅地点不符先被拒、后又接受，则地点可放宽"。

## 三、技术竞争力
中／高项目重叠下低优先级偏好 F1 达 0.927／0.945（无记忆 0.866／0.838）；检索上下文 64,123→19,968 token（−69%），程序记忆再降至 18,285。提示程序轮数较无记忆少 34%—39%、较 OKF 少 23%—28%。PersonaMem-v2 上 OKF 49.4%、加程序 50.2%，对全史 48.6%、无记忆 29.0%，读者输入 token 少 90.5%。

## 四、技术挑战
第 15 天长程任务：RL 程序正确弃答 60%／字段命中 60%，OKF 为 30%／60%；Jev 快选 90% 弃答却 0% 字段命中，加程序仍仅 10%。四类记忆臂 40 个错误中 27 个（67.5%）是选择失误，119 条缺失引用全部在索引内——瓶颈不是覆盖率；对话类方法 31 个错误仅 3 个源于漏选，多数是长上下文误读。提升推理预算 none→low 只救回对话 8/17、搜索 4/11，OKF 0/7、RL 3/4。

## 五、需求分析
用户要助手懂"哪些要求其实可以放宽"且跨项目沿用；运营方要在证据不足时收到弃答而非猜测，并能判断失败源于漏选、误读还是记忆未存。

## 六、用户旅程
互动→抽取可观察事件与谱系→选锚点并展开依赖→按时间组证据→程序给出决策规则→推断优先级并给出候选→证据不足则弃答→用实际决策一致率回写程序。

## 七、具体实现方案
①事件索引与谱系分文件、只记可观察活动；②程序学习用行为一致率作奖励、隐藏标签不入环；③弃答与作答配对验收；④错误先做选择／推理归因，再决定是否加推理预算；⑤AML 补 decision-procedure 维度：一致率、弃答—字段配对、索引命中未选率、推理可救率。

## 本期新观点
1. **程序记忆的对象转向"他人的决策"**（划界 #159）——学的是用户判断规则而非 agent 执行路径；行为一致率可当奖励，绕过隐藏偏好标签。
2. **弃答是一等记忆能力**（接 #154／#158）——RL 60%／60% 对 Jev 90%／0%，只看准确率会奖励敢猜，须配对验收。
3. **覆盖不是瓶颈、选择才是**（深化 #160／#158）——119 条缺失引用全在索引内，Jev 臂 90.5% 错误源于漏选，LLM 导航仅 42.1%。
4. **记忆收益存在时间交叉**（新角度）——早期无记忆 F1 0.811—0.825 最高，后期 OKF 反超；早窗评测会误判记忆无效，与 #158 曝光冷启动不同，此处是判别信号不足。
5. **快选择要记"选择税"**（接 #5／#150／#156）——Jev 调用 1.725→0.916、轮数降 25%—31%，但 token 反升、长程字段归零；效率不能只算调用数。
6. **推理预算是诊断旋钮**——none→low 只救解释性失败、不救选择失败；五项目无新主线版本：OpenViking v0.5.6／Hy-Memory v2.0.17＋MemHub v1.0.8／TencentDB v2.0.4／dsh v26092802／ReMe v0.4.2.3，均无谱系选择、程序学习与弃答验收接口。
