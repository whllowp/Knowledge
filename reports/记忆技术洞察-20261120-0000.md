# 记忆技术洞察 · 第 124 期（20261120-0000）

**主题：记忆的「感知保真度」（memory perception）——记忆不只决定"取哪条"（#109）、"读多少"（#122）、"以什么形态存"（#121），还决定"每条以多清晰被看见"：把历史渲染成图，按其对下一步决策的相关度逐条调分辨率，视觉 token 随分辨率平方下降，省一半 token 而决策不变。**

> 洞察范围：2026 年（近 30 天为主）。四维度：发展趋势 / 技术现状 / 技术竞争力 / 技术挑战。

## 一、发展趋势

前 123 期把记忆拆成检索（取哪条、排第几）与压缩（留多少、带什么），共同预设"进上下文的内容以同样清晰度被读"。11-18 RAA: Resolution as Attention（arXiv 2611.24422，NTU＋阿里，Siqi Xiang 等 6 人，cs.AI/CV）立起第三维：感知保真度——每条历史被"看多清"可独立、随任务演进地调。与 #122 划界：那是同一来源内读整段还是读一句（文本粒度取舍），这是跨所有交互按决策相关度分配像素分辨率；与 #121 划界：那管以什么形态存，这管以什么保真度被看见。趋势是记忆从"存与取"走向"感知"。

## 二、技术现状

把每条交互 h_i=(推理、动作、观察) 渲染成一张规范图（全任务只渲一次），读取时按比例 s_i∈(0,1] 缩放；视觉编码器每 patch 出一个 token，故视觉 token 约 ∝ s²，越低越省。相关性估计器由 Qwen3-Reranker-0.6B 微调，以任务＋最新交互为 query 逐条打"对下一步决策有多关键"；可学习归一化 sigmoid 映射把相关度转成 s（g(0)=0、g(1)=1、保序）。关键设定：不设全局预算、各交互独立缩放（决策前不知需要多少信息，固定预算要么截断关键、要么留下冗余），总 token 随需求浮动。两阶段训练：教师标注相关度监督，再用强化学习奖励"保持原决策且少视觉 token"，agent 全程冻结，训练一次可迁移。

## 三、技术竞争力

ClawGym-Bench 三骨干（Qwen-3.8-27B 训练、Qwen-3.6-27B 与 Kimi-K3 训练时未见）。Qwen-3.8 上每任务 token 89733→38169（↓57.5%）、峰值 12561→6447，平均分 78.23→78.69 反升；两未见骨干分别 ↓51.5%／↓55.9% 且分数不降，证明可插拔迁移。对照 FIFO／LongLLMLingua／AgentOCR 均更费 token 且分更低；OCR-Memory 按新旧统一降采样，峰值 token 偶更低却多走 7–14% 步、多耗一成 token。等预算文本裁剪（按 RAA 比例删词）多走 14% 步、token 反增 33%、分低 0.97——连续分辨率优于离散删词。作感知层叠加 ACON／A-MEM／观察掩码，再省 22.5%／44.7%／54.1% token 而分不降。

## 四、技术挑战

①省 token 不省时间：端到端 326s，仅比原版慢 4.3%（估计＋渲染占 2.51%），因 decode 主导；收益落在峰值 KV cache ↓47.8%，而非墙钟——深化 #122 记忆税要算全链路。②保真度是"似然"非"正确"：训练目标是与全文本参考 agent 决策一致，作者自陈可能保留其错误。③依赖骨干 OCR 能力，字体/排版/高亮未测；逐步重设分辨率破坏前缀缓存复用。④五项目倒挂：OpenViking v0.5.5／Hy-Memory 2.0.16＋MemHub v1.0.7／TencentDB v2.0.3／dsh v26092802／ReMe v0.4.2.3 全做文本/结构化条目的取或压，零自适应感知保真度，AML 无 perception 维度。

## 五、需求分析

长程 agent（软件工程、网页研究、电脑操作）历史随轮次膨胀，全留则贵、剪枝则不可逆丢细节（#115）。用户要的不是"再压一点"，而是：无关交互粗到够用、关键交互清晰可读，同一条在第 5 步与第 50 步可被不同清晰度重看——不改权重、又能叠加现有记忆管理。

## 六、用户旅程

客服 agent 处理长工单。第 3 轮一条"订单号 8891"当时无关，被渲染成低清图只占少量视觉 token；到第 40 轮用户追问该订单，相关性估计器认出它、分辨率当步升高，号数重新可读——文本从未被删（非破坏），只是"看多清"随决策改变。另一条早期道歉话术则全程低清，不再挤占预算。

## 七、具体实现方案

三层契约：①表示层＝每条交互渲一次规范图、读取时按 s 缩放（∝s² 定价），非破坏、可重入，校正 #122 细视图丢支持的短板。②控制层＝0.6B 相关性估计器＋归一化 sigmoid 映射，教师监督→强化学习两阶段，各交互独立打分、无全局预算（深化 #109 相关度、接 #94 用决策一致性而非语义相似当监督）。③集成层＝感知层外挂于检索/压缩之上、agent 冻结一次训练多处迁移。AML 补 perception 维度（每任务视觉 token／决策一致率／感知叠加增益／峰值 KV cache）。反证：单基准、三骨干、依赖 OCR、似然目标不保正确，不作外推。

## 八、本期新观点

1. **记忆的第三维"感知保真度"**（接 #109/#121/#122 划界）：检索管取哪条、压缩管留多少，本期管每条以多清晰被看见，正交于二者的独立维度。
2. **分辨率即注意力**（深化人类视觉的精度分配）：把抽象 attention 权重落成可读的像素比例，各条独立、随决策演进，不设全局预算——与 softmax 固定总权重相反。
3. **连续感知胜过离散删词**（深化 #122）：等预算文本裁剪多走 14% 步、token 反增 33%、分低 0.97，因文本删词丢精确值不可恢复，图像分辨率可平滑调节。
4. **"看多清"要学、且与语义相似不同**（接 #94）：语义相似度与决策相关度不等价，须教师标注＋决策一致性强化学习两阶段才校准出分辨率分布。
5. **省 token ≠ 省时间、收益落在 KV cache**（深化 #122/#5）：token ↓57.5% 而端到端近乎不变，价值在缓存占用 ↓47.8% 而非墙钟，记忆税须按 decode/KV 分账。
6. **五项目倒挂＋AML 补 perception 维度**：五家零自适应感知、零非破坏可重入清晰度，打开"存—取—感"三分的新评测空位。
