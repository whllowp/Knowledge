# 记忆技术洞察 · 第145期（20261124-1000）

> 洞察范围：2026 年、尤其近 30 天，AgentMemory 发展趋势／技术现状／技术竞争力／技术挑战四维度。主线来源：arXiv 2611.28221（11-20 提交）。本期新观点均已与本地 C/E 双版索引及知识台账比对，未重复前期。

## 一、发展趋势
记忆研究的重心正从"存什么、取哪条"转向"谁写记忆、写进哪里"。11-20 提交的 Video-as-Weights（VaW，滑铁卢大学＋Google，cs.CV）把一段视频一次编译成冻结解释器的 LoRA 权重与 64 个前缀 token：编译器和解码器都不看问题，一份记忆供所有问题复用，且 32 层 9B 编译器可写给 24 层 0.8B 解释器。与 #141 的单模型按需解码、#143 的读者自训练快权重不同，本期首次把"作者"与"读者"彻底分开：记忆是一份由外部模型写好的、问题无关的参数制品。

## 二、技术现状
编译器按视频长度设 K≈n_v/ρ 个读出槽位，收集全部层的读出隐状态；权重解码器用交叉注意力读任意编译器层，用自注意力协调各 LoRA 站点、秩组与前缀查询，RMSNorm 固定生成向量幅度、只让解码器选方向。训练采用 λ=0.5 的双视图：同一份 ΔW 分别配"仅问题"与"前缀＋问题"，逼权重独自承载概要、前缀补细节。Qwen3.5-0.8B 解释器上，0.8B→0.8B 得 58.4，胜全视频上下阅读 56.7；9B→0.8B 得 61.0（+4.3），距全视频 SFT 仅 1.2 点，而输入只有 64 token，不是最多 8,192 token。

## 三、技术竞争力
同一 9B 编译器下，VaW 比只传 token 的压缩器高 3.9 点；同配方 tokens-only 训练低 5.1 点。全层解码比逐层深度对齐解码高 2.7—2.9 点，说明 Compiler 第 17—32 层的共享摘要比"层对层"更重要，也解除了两端深度必须相同的约束；强弱迁移再拿 +2.6 点。r=16、P=64 的每视频存储 20.6MB，比解释器视频 KV 缓存 112.4MB 小 5.5 倍且不随帧数线性增长。前缀 16／64／128 为 58.5／61.0／61.9；去掉 token −7.0、去掉 LoRA −13.8、换别的视频的 LoRA −3.0，两条通道各司其职。

## 四、技术挑战
机制分析显示有前缀时每个解释器层主要读编译器第 32、20 层，前缀读 24—32 层；权重主要改全注意力 query 与 MLP down，前缀主要拉升 OCR（+20.9）与物体识别（+13.8），长视频上 token 增益衰减，多段视频 LoRA 如何合成仍是开放问题。更关键的是编译制品无法逐条撤回或核验来源，回执门控（#138）与遗忘保真（#73）尚未覆盖"参数化记忆卡"。五项目 OpenViking v0.5.5、Hy-Memory v2.0.17＋MemHub v1.0.8、TencentDB-Agent-Memory v2.0.4、dsh-memory-evolve v26092802、ReMe v0.4.2.3 经标签核对无新主线版本，均未见问题无关的编译式权重记忆接口。

## 五、需求分析
端侧小模型要回答长视频问题，却付不起最多 8,192 个视觉 token 的 KV 缓存；把 token 剪短又只是让同一组固定权重去读更少的证据，能力缺口补不上。真正需求是：一次预编译、多问复用、每视频固定存储、可由强模型写给弱模型，且概要与细节能分工交付。

## 六、用户旅程
开发者上传视频→编译器生成 (ΔW, P) 记忆卡并入库→用户提问时冻结解释器只加载该卡与问题文本→按答案反馈决定扩 P／r 或重编译；跨视频问答前需先解决多卡组合与冲突撤回。

## 七、具体实现方案
建 compile-once 流水线：①按视频长度设 K 并读全部编译器层；②全层交叉注意力解码 LoRA＋前缀，双视图损失训练；③推理冻结主干、前缀可选；④验收四账：相对全上下文准确率、每视频 MB、前缀 token 数、跨尺寸迁移增益；⑤与外部检索记忆共存——token 管细节、LoRA 管概要，分别登记来源与撤回状态，防止"编译卡"成为不可审计黑盒。

## 本期新观点
1. **记忆生产权外移**：记忆由另一模型问题无关地写好再交给冻结读者，区别于 #141 读者自解码与 #143 读者在线自训练，新增"作者—读者"比较轴。
2. **参数记忆是制品而非轨迹**：一份 (ΔW, P) 固定存储、跨问复用、可强弱迁移；记忆税按每视频 MB 与编译次数计，不按每问 token 计（深化 #5／#141）。
3. **通道分工可测**：权重扛概要、前缀补 OCR 等细节，去通道与换视频消融给出 7.0／13.8／3.0 点的量化分工（接 #122／#144）。
4. **全层解码优于层对齐**：共享摘要取代逐层对应，异深度编译器—解释器组合成立，划界 #142 的同族 KV 映射。
5. **编译记忆带来新治理缺口**：无法逐条删除、无来源回执、多卡组合未验证，须补 compiled-memory 维度（接 #73／#138）。
6. **五项目逐家核对仍无编译式接口**：研究侧已到"写权重"，产品侧仍在条目／向量／图谱层，倒挂延续。
