# 记忆技术洞察 · 第164期（20261127-1100）

> 洞察范围：2026 年、尤其近 30 天，AgentMemory 发展趋势／技术现状／技术竞争力／技术挑战四维度。主线：arXiv 2611.33822（11-25 提交）。已与 C/E 双版索引及知识台账比对确认未重复；最近 arXiv 批次仍停 11-25、五项目无新主线版本，按预案输出往期未覆盖的深度专题。

## 一、发展趋势

程序记忆正从"存下成功流程"走向"与任务相对进度状态共同学习"。11-25《MetaDecomp: Adaptive Task Decomposition via Meta-Learned Procedural Memory》（arXiv 2611.33822，浙江大学／哈佛大学，cs.AI）把进度抽象 Σ 与状态间迁移 DAG 合成一份程序先验：状态只保留会改变后续操作的区分（"已持有"还要区分"是否已清洁"），具体实体绑定不进状态身份。与 #144 技能库、#159 来源极性、#161 他人决策程序划界；与 #148 任务经验、#163 外壳共演化衔接。本期新点是：状态模式一旦扩展，历史执行证据的程序归属必须被重算。

## 二、技术现状

外循环从成功轨迹提出新的角色、字段与取值，按更新后的 schema 重投影历史边界；若一条方法的支持轨迹散落到不同状态对，就拆开分别重评，只收有执行支撑的操作，并校验 DAG 引用有效且无环。内循环冻结 Σ／H，把角色绑定到当前任务，从匹配到的当前状态检索可达目标的最短路径与全部备选方法，结合停滞反馈改写初始分解，并允许补入记忆中缺失的步骤；测试期只跑内循环。

## 三、技术竞争力

ALFWorld 134 个未见任务上 Qwen3-4B 达 86.3%（MPO 79.9、SkillOpt 70.4），8B 达 94.5%；ScienceWorld 9B 69.5（SkillOpt 66.8）。每次推理 token 53.8K（4B）/42.6K（8B），低于 ReAct 57.2K/49.4K 与 SkillOpt 101.5K/86.7K；训练 23.02M 低于 SkillOpt 43.62M。消融显示完整 88.81/72.20，固定初始 schema 79.10/65.02，去历史重投影 82.84/62.92，去状态—程序链接 81.34/66.29，仅状态 80.60/53.40，去初始精化 79.10/56.92。

## 四、技术挑战

跨八个基准 480 任务的零样本迁移出现"部分覆盖低谷"：高覆盖 67.47→79.52（+12.05 点）、部分覆盖 70.19→67.17（−3.02）、低覆盖 27.27→28.03（+0.76），总体仅 +0.63 掩盖了 265 题的倒退。最长执行区间成功率跌到 7.69%，ScienceWorld 完整完成仅 9.52%；换初始化器而不重训由 86.3/69.5 掉到 77.6/57.6。

## 五、需求分析

用户要跨任务复用经验却不被半截流程带偏；运营方要能解释"这条程序凭什么属于这个进度状态"，并在状态定义升级后仍可追溯旧证据，同时控制训练与每次推理成本。

## 六、用户旅程

成功轨迹入账→提出进度区分→重投影历史边界→拆分/重组程序支持→冻结先验→绑定角色生成初始分解→执行停滞时按当前状态召回路径→改写分解→成功轨迹再入外循环；迁移前先核对前置条件覆盖度。

## 七、具体实现方案

①状态与程序同版存储，证据指针保留原始边界以支持重投影；②schema 变更触发支持分组重算，冲突程序并列而非覆盖；③召回须完整状态匹配＋前置条件门禁，部分覆盖时禁用长程序复用；④初始化器与记忆联合训练，分别登记训练 token、推理 token 与覆盖率分层增益；⑤AML 补 progress-state-reprojection 维度：重投影存续率、复用动作节点比、部分覆盖倒退率、跨初始化落差。

## 本期新观点

1. **程序记忆的索引键是任务相对进度，不是查询相似度或技能名**（划界 #144／#159／#161）——角色绑定可变、状态身份只看已确立的条件；新增"是否已清洁"这类区分才让同一实体在不同剩余工作下选对后续程序。
2. **schema 扩展是一种记忆重写事件**（新角度，接 #148／#151）——不是追加条目而是把历史轨迹按新状态对重新分组、拆分程序支持；去历史重投影掉 6—9 点、固定 schema 再掉约 3—10 点，证明"索引变了旧账必须重算"。
3. **部分覆盖低谷是独立的负迁移失效模式**（接 #160，划界 #140）——经验为真且被召回，却只覆盖前半流程，反而诱导提前放置；265/480 题 −3.02 点被总体 +0.63 抹平，准入须先看操作／前置条件覆盖率而非相关性。
4. **记忆质量改用"可重分配证据＋复用节点"计量**（深化 #144／#159）——1,442 个动作节点中 661 个有≥2 条成功轨迹支撑、963 个被测试复用、746 个复用≥2 次；去掉状态—程序链接掉 7.47／5.91 点，仅有状态在 ScienceWorld 掉 18.8 点。
5. **冻结先验不是即插即用，存在初始化适配税**（接 #147 兼容性矩阵／#150 摊销点／#163）——训练 23.02M 换推理 53.8K/任务；换初始化器不重训掉 8.7／11.9 点，说明程序记忆与规划起点须成对交付。
6. **产业倒挂与 AML 缺口**——五项目今日无新主线版本（OpenViking v0.5.6／Hy-Memory v2.0.17＋MemHub v1.0.8／TencentDB v2.0.4／dsh v26092802／ReMe v0.4.2.3）；均无进度 schema 学习、历史重投影与覆盖分层准入接口，AML 补 progress-state-reprojection 维度。
