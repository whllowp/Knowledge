**本期主题**：就绪面／上线闸门面（Readiness Gate）——扩量之前，先证明「出事时你接得住」；六道闸门，缺一道就是赌

---

## 题眼

把最近几期的事实摆在一起，会看到一个共同的形状：**146 期**——68% 的组织说对 Agent 高度可见，**82% 过去一年发现过未知 Agent**；**160 期**——43% 说要投 Agent 行为监控，**近一半自认完全没能力建基线**；**162 期**——CISO **100%** 说整套 IT 被攻破后工厂还能转，一线**只有 15%** 认为手动能撑 48 小时；**169 期**——Agent 产出可以 4 倍，**审阅容量不会自动 4 倍**。四组数字说的是同一件事：**组织对 Agent 的信心，普遍高于它对 Agent 的准备**。而扩量（更多 Agent、更大权限、更快发布）会把这种差距放大成事故。**就绪不是一句「我们准备好了」，是六道能拿出证据的闸门。** **闸门的反义词不是「没准备好」，是「以为准备好了」。**

## 一、发展趋势

**趋势一：从「能不能上」转向「接不接得住」。** 上线评审看功能；**扩量评审要看故障时的承接能力**。

**趋势二：闸门从单点变成组合。** 属主、基线、演练、回滚、审阅、合规——**缺一道，风险就从那道漏**。

**趋势三：证据成为闸门的通行证。** 「有流程」不算；**要拿出演练记录、基线覆盖、回滚演练、审阅容量**（164／169 期）。**没有证据的「已就绪」，和没有闸门一样。**

## 二、技术现状：六道闸门，通常只查两道

**属主闸：谁负责它的一生。** 四类属主（146）；**缺 owner 的 Agent 不进生产**。

**基线闸：它平时什么样。** 行为基线覆盖率（160）；**没有基线，异常检测就是噪音**。

**演练闸：坏了能不能发现、能不能止住。** 红队（149）与韧性演练（152）；**没演练过的第一次实战就是事故**。

**回滚闸：能不能回到可信点。** 记忆/配置/数据/会话四层（164）；**回滚不了，就只能硬扛**。

**审阅闸：改动能被审过来吗。** 审阅容量（169）；**产出 4 倍、审阅不变，等于没扩**。

**合规闸：能不能举证。** 告知与日志（166）；**举不了证，扩量就是把风险写进合同**。

**三种假通过，一种比一种像真的。** 勾了但没证据、有证据但过期、有例外但没到期；**三种都让闸门变成装饰**。

## 四、技术挑战

**一，闸门被当成清单。** 勾完就算过；**没有证据的勾选，是自我安慰**。

**二，缺一道就漏一道。** 有属主没基线、有演练没回滚；**风险总从最弱那道进**。

**三，扩量冲动压过闸门。** 业务要快；**闸门被「先上再说」绕过**。

**四，证据散在六个系统。** 属主在注册表、基线在监控、演练在文档；**审计时拼不起来**。

**五，例外没有到期。** 「这次特殊」变成永久；**例外要有 owner 与期限**（154 期）。

**六，闸门自身会过期。** 上个月过了，这个月模型换了；**闸门要随版本重跑**（127 期）。

**七，跨团队闸门会踢皮球。** 属主在业务、基线在安全、演练在 SRE；**没人对「六闸合计」负责**（146 期）。

## 五、需求分解、用户旅程与实现方案

### 5.1 需求（按优先级）

- **R1 `gate.*` 字段**：`agent_id`、`gate`（6 类）、`passed`、`evidence_ref`、`expires_at`、`exception_owner`。
- **R2 六闸合一**：属主/基线/演练/回滚/审阅/合规；**每闸有证据链接**。
- **R3 扩量前置**：新增权限、扩大流量、提高自主度，都要重过闸。
- **R4 例外管理**：例外有 owner、期限、补偿控制；**到期自动回到未过**。
- **R5 版本重跑**：模型/工具/配置变更触发相关闸门重跑（127 期）。
- **R6 指标**：六闸覆盖率、例外数、例外到期率、过闸后事故率。

### 5.2 用户旅程

- **平台工程师**：新 Agent 扩量 → 六闸检查 → 缺回滚演练 → 先补演练再扩 → 证据进注册表。
- **SRE**：季度复核 → 发现两闸过期 → 重跑 → 更新证据。
- **安全**：例外到期 → 通知 owner → 未处理则降权。
- **审计**：抽查一个 Agent → 六闸证据齐全 → 通过。

### 5.3 实现方案（90 天）

- **0–30 天：定义。** 六闸标准与证据格式；盘点存量。
- **30–60 天：卡口。** 扩量走闸门；例外管理；版本重跑。
- **60–90 天：度量。** 覆盖率与过闸后事故率；季度复核；闸门证据链接化。

**第 118 个市场空白（五项）**：六闸覆盖率、证据可链接率、例外到期率、版本重跑率、过闸后事故率——无一内建；`gate.*`／`readiness.*` 为**第 87 次无人提字段族**。本地 173／173-kb 连续第 78 期成组启用：周昕毅 10「白名单动作、危险动作需审批」＝全库唯一把「放行条件」写成硬规则的实践，本期首次当主线；配 146 期属主、164 期恢复。判词：**本地把放行条件写成白名单，联网侧 2026 年才量出「信心 100%、能力 15%」；两边都没把「扩量前六闸是否都能举证」做成一道门。**
