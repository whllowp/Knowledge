# AI-SRE 技术洞察 · 第 185 期（2026-11-13 16:00）

## 度量主权面／标尺自设面（Metric Sovereignty：当 SRE Agent 既当运动员又当裁判）

**题眼**：可靠性正在被"自己证明自己"——SLI、仪表盘、playbook、事故复盘、golden 评测集、乃至评测判官，越来越多由同一支智能体舰队生成；当度量者与度量是同一系统，"系统可靠"就退化成一个自指的声明。本期把**"谁握着标尺"**立为一等运维对象，与 #153（评测安全门禁：修的时候越界没）、#176（决策质量 SLI）、#164（知识复利）显式划界：本方只问"标尺是否独立于被评者"，不评修复质量、不评决策好坏。

### 一、发展趋势

1. **评测自证化**。Google 的 Nightly Evals 以"Golden Data + LLM-as-a-Judge"为闭环，评测判官本身就是 LLM；Anthropic 于 10/14 开放 Claude 平台 OpenTelemetry tracing 公测，把"先追踪后授权"写进治理原语而非产品话术；阿里 STAROps 发布 RCA-Bench 公开基准（103 例、6 类、28 故障型），把根因判定拆成"对象是否正确 / 原因是否正确 / 过程是否有证据"三维独立评分。
2. **度量内生化**。OpenAI 的 per-change autonomous SRE 由 Agent 自建监控仪表盘、自定成败信号；Google 的 Agent 持续监控并改写 playbook、从事故自动生成新 runbook；字节 DevOps Agent 招聘明确要求"建立模型训练的统一数据规范与评测体系"——评测体系由被评者自建。
3. **反向制衡成共识**。腾讯"用 AI 管运维，用可观测管 AI"、Google Actus 确定性执行层、Anthropic OTel 审计追踪、阿里 Agent 行为审计留痕，共同指向同一 antidote：以"外部可观测 / 确定性层"约束自证倾向，把裁判权从舰队里抽出来。

### 二、技术现状

- **Google**：推理（AI Operator）/ 执行（Actus）/ 评测（IRM Analyzer）三权分立，评测以"人轨迹 golden + LLM-Judge"为弹药，自治等级由评测输出而非一次会议决定。
- **OpenAI**：Sevbot 只建议不执行、Perf Factory 自定"真实回归"；度量主权完全内收，靠"人工三道关卡"兜底。
- **Anthropic**：不生产 SRE 平台，只给 OTel trace 这一"外部审计原语"，明确"信任始于追踪、权限随可靠度扩展"。
- **字节**：SRE-Copilot 多 Agent MoE（LogAgent / TraceAgent …）+ 自建评测体系。
- **阿里**：UModel 统一运维本体 + RCA-Bench 公开基准 + 反幻觉双重机制，是六家里唯一把"评测标尺"公开化的。
- **腾讯**：CloudQ 多维专家 + "用可观测管 AI"（用量 / 性能 / Token / 工具调用 / 任务质量全链路下钻），反向制衡最强。

### 三、技术竞争力（六厂商六维对比）

| 厂商 | 谁定义 SLI/仪表盘 | 独立评测基准 | 评测判官 | 独立真值 | 可观测反向管 Agent | 承认自证风险 |
|---|---|---|---|---|---|---|
| Google | Agent 自维护 playbook + 人轨迹 golden | Nightly Evals；ITBench 外部参照 | LLM-as-a-Judge + 人校验 | 半独立（人轨迹） | Actus 确定性层 | 是（安全三角） |
| OpenAI | 每变更 Agent 自建仪表盘 + 自定成败信号 | 无公开 SRE 基准；Perf Factory 自定"真实回归" | 内部自定 | 弱（自定信号） | 人工三道关卡 | 部分（Sevbot 不执行） |

### 四、技术挑战

1. **自指可靠性（Goodhart at fleet scale）**：当"达标率"由 Agent 自己定义指标、自己建仪表盘、自己判分时，数字越好看越可疑——这是 2026 年最隐蔽的退化通道，比"模型变笨"更难察觉。
2. **真值蒸发**：ITBench-AA（2026-05，Artificial Analysis × IBM；9 月榜单升至 56.2%）显示前沿模型根因定位仍低于人类级，但所有厂商内部"自报成功率"普遍远高于此——缺口恰来自自证闭环。
3. **LLM 判 LLM 的循环**：LLM-as-a-Judge 把"谁在判"也变成概率模型；golden 虽由人标注，但规模化后人标注被 Agent 生成物反哺，真值来源隐性偏移。
4. **度量主权不透明**：六家无一公开"本评测标尺是否独立于被评舰队"，用户无从区分"真可靠"与"会自证"，采购决策只能凭 demo 观感。

### 五、展望与建议

- 把"度量主权"列为 Agentic Ops 的一等 SLO 基元：要求每个自治系统声明 `ruler.ownership`（谁定义 SLI）、`eval.independent_of_actor`（bool）、`eval.ground_truth_source`（human_trajectory | synthetic | agent_generated | user_feedback）、`eval.judge_type`（llm | human | deterministic）。
- 推行"外部可观测为审计层"：腾讯"用可观测管 AI"、Google Actus、Anthropic OTel 是同一思路，应成为标配而非卖点。
- 本地 173 证据链合流：孙鹏"探测式评测管线"（独立探针而非自评）、施宏斌"金融 Agent Eval 从专家经验到可验证"、刘杨"Trace→实时评估"、周昕毅"生产闭环但度量由人守"，共同指出——把"越用越强"写进 Agent 学习闭环（袁彬航 AReaL / 肖汉松 Loop / 马云雷轨迹）时，评测必须外置为独立探针，否则闭环只闭环了自己。
- 第 130 个市场空白：`metric_sovereignty.*` 字段族（六家零公开）：`ruler.ownership` / `eval.independent_of_actor` / `eval.ground_truth_source` / `eval.judge_type` / `eval.goodhart_exposure`。
