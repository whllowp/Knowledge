# AI-SRE 技术洞察（第 209 期）

**生成时间**：2026-11-16 08:31（北京时间）｜**窗口**：2026 年，重点最近 30 天
**本期主题**：技能面／岗位能力（Workforce）——11.4% 的 SRE 岗位要求 Agent/LLM 技能；真正缺的不是「会调模型」，是「会验行为」

---

## 题记

07-06，一份对 **2,772 条 SRE 招聘**的分析给出了几个可用的数字：**11.4%（315 条）明确要求新一代生成式 AI 技能**（Agent、LLM、RAG、prompt，或 OpenAI/Anthropic 这类平台名）；把传统 ML/MLOps 也算上，**任何 AI 相关为 16.8%（467 条）**；两者重叠**只有 2.9%**，而**8.5% 只要新 AI、不要 ML 背景**。作者说，这**不是 AIOps 异常检测的延伸，而是一条新的招聘车道**。这组数字解释了一个日常矛盾：**团队招了「会写 prompt 的人」，却没人能回答「这个 Agent 这周的行为变了吗」**。**Agent 运维缺的不是模型知识，是行为验证能力——而招聘市场刚分开这条车道。** **招错关键词，比招不到人更贵。**

## 一、发展趋势

**趋势一：从「AIOps 延伸」变成「独立岗位」。** 新 AI 与 ML 重叠仅 2.9%；**两条车道在分开**。

**趋势二：从「会调模型」转向「会验行为」。** 评测设计、行为审阅、证据审计；**三种新技能**（169 期）。**「能调通」和「能证明调对了」是两门手艺。**

**趋势三：值班表开始要求 Agent 能力。** 会不会接 Agent 的告警；**决定夜里能不能处理**（147 期）。

## 二、技术现状：三种技能，通常只招一种

**Prompt/编排：最常招。** 会写、会调；**但不等于会验**。

**评测设计：最缺。** 会造题、会盲测、会统计；**决定「改好没改好」**（153 期）。

**证据/审计：最少。** 会留痕、会举证、会解释；**决定能不能过审**（166 期）。

**现状：岗位描述写「熟悉 LLM」。** 具体做什么；**入职才现学**。

**三种能力缺口，一种比一种难补。** 会写不会判（缺评测）、会判不会证（缺证据）、会证不会值班（缺演练）；**三种都补，才叫「能接 Agent」。**

## 四、技术挑战

**一，Prompt ≠ 验证。** 会写不等于会判；**写的人往往看不出自己写错**。

**二，评测没有课程。** 怎么造题、怎么盲测；**没有标准教材**。

**三，值班没培训。** Agent 告警来了；**值班不知道怎么读**（147 期）。

**四，证据岗没人设。** 审计要人对接；**平台/业务互相推**（177 期）。

**五，招聘写错关键词。** 招「prompt engineer」；**实际缺「behavior verifier」**。

**六，能力不可测。** 没有认证；**只能靠项目经历判断**。

**七，培训要时间。** 评测/证据课不是一天；**业务不会等人**（169 期）。

## 五、需求分解、用户旅程与实现方案

### 5.1 需求（按优先级）

- **R1 `skill.*` 字段**：`role`、`skills[]`、`level`、`verified_by`、`oncall_ready`。
- **R2 技能矩阵**：编排/评测/证据/值班四类；**每类分入门/独立/带队**。
- **R3 评测训练**：造题、盲测、统计；**用自家事故当教材**（207 期）。
- **R4 值班就绪**：Agent 告警读法；**演练通过才算**（149 期）。
- **R5 证据岗**：审计对接人；**写进 RACI**（177 期）。
- **R6 指标**：技能覆盖率、评测独立率、值班就绪率、审计对接率。

### 5.2 用户旅程

- **SRE**：入职 → 技能矩阵评估 → 补评测/证据两门 → 值班演练 → 内部认证。
- **经理**：招聘按矩阵写 JD；**不写「熟悉 LLM」这种空话**。
- **审计**：找到证据岗 → 要记录 → 一次拿到。
- **团队**：季度复评技能；**缺口进培训计划**。

### 5.3 实现方案（90 天）

- **0–30 天：矩阵。** 四类技能；存量评估。
- **30–60 天：训练。** 评测与证据课；值班演练。
- **60–90 天：认证。** 内部认证；JD 改写；季度复评；缺口进培训预算。

**第 147 个市场空白（五项）**：技能矩阵覆盖率、评测独立率、值班就绪率、证据岗设置率、内部认证覆盖率——无一内建；`skill.*`／`role.*` 为**第 115 次无人提字段族**。本地 173／173-kb 连续第 105 期成组启用：刘凯宁 05「结论/证据/待确认项三分」＝全库唯一把「证据随结论走」写进交付的实践，本期首次当主线；配 169 期审阅、177 期组织。判词：**本地把证据随结论走写成模板，联网侧 2026 年才量出「11.4% 的 SRE 岗位要 AI 技能」；两边都没把「谁会验 Agent 的行为」做成岗位字段。**
