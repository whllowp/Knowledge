# 记忆技术洞察 · 第 140 期（20261124-0400）

**主题：记忆的「经验反噬」（experience rot）——成功过的经验会让 agent 停止校验；工具静默变更后，同一份经验从最大资产变成最大负债。前 139 期优化存什么、取哪条、读多清、证据能否回来、信念是否此刻成立（#79／#122／#132／#126／#139），默认"经验被复用"总比"没有经验"好；11-16 提交的 Experience Rot（arXiv 2611.20922，Zhen Xu 等，cs.CL／AI／LG）用 agent 自己赚来的经验反证这一默认。与 #128 划界（那期靠自身预测—实测落差发现编辑失效，本期外部静默变更不产生任何错误信号）、与 #138 深化（写时回执只证 accepted，不证语义正确）、与 #75 划界（那期管记忆的运行时负债，本期负债来自成功经验本身）。**

> 洞察范围：2026 年（近 30 天为主）。四维度：发展趋势 / 技术现状 / 技术竞争力 / 技术挑战。

## 一、发展趋势

记忆评测的隐含前提正被拆掉：给 agent 更多自己的成功经历通常被视为提升，但这只在接口不变时成立。真实服务普遍静默失败——61 条散文约束 44 条静默失效、五个生产端点四个忽略未声明参数。MCP 工具可在会话中换掉定义而旧用法仍返回 ok:true，记忆任务从"保住成功"扩为"发现成功不再成立"。

## 二、技术现状

三服务各两版本、七种单点变更（字段名、结构、取值、优先级方向、星期与月份编号、单位），六模型、12,624 个 episode，三臂配无／有效／过期经验。定义总跟随现版本，未知字段忽略、未知值不改状态，读工具却显示真实状态。经验分置对话、记忆文件、检索记忆与可执行技能四种载体。

## 三、技术竞争力

文档不完整时无经验 63%、有效 100%、过期 23%（−0.40）。完整时无经验 88—100%、过期 26—49%，新字段就在眼前定义里仍只有 49% 成功。失败还被误报：完整文档 348 次失败中 347 次称"已完成"，不完整 92%。四载体全中招：对话代价 0.53，其余 0.20—0.30。

## 四、技术挑战

①经验越多越盲：1／3／10 次同类经验后过期成功率 46%→33%→26%，查文档率 4%→0。②有效与过期无法自辨：引用旧任务的措辞频率两臂相同。③补丁失灵：版本号加公告 0.46→0.50，系统提示"先读文档"末期遵守 4%、成功率反降至 0.29。④读回是可靠发现机制：97 次旧用法后纠正 94 次，但需 6.5—10.6 次调用；写接口回传对象后，77 个失败中 59 次见错不改。⑤合成小服务、单次变更，不作外推。

## 五、需求分析

用户以为"记住上次怎么做"就省心，实际遭遇静默假成功：会议建了没有参与人、紧急任务存成普通优先级，助手却报完成。产品要回答的不是"有没有相关记忆"，而是"这条用法在当前接口下还成不成立、失败会不会被我自己发现"，并在无错误返回时主动制造可核对的证据。

## 六、用户旅程

首次成功写入后，经验连同接口快照与读回结果入库，不只存调用模板；工具定义变化时条目标为待核，而非等 agent 起疑。新请求先按当前定义轻量校验，写入后读回逐字段比对，不一致则纠正再回复。面板并列有效／过期经验成功率、查文档率、读回率、假成功占比与每任务调用数。

## 七、具体实现方案

①条目携带接口版本、字段快照与读回凭证，定义变更触发失效广播（接 #74／#75）。②"写完读回并纠偏"做成写路径强制步骤；文档与校验指令贴近请求放置，实测 0.46→0.99，系统提示位仅 0.29—0.55。③验收必须用自赚经验＋不完整文档：手写历史含读回使代价 0.54→0.11、成功虚高到 0.88。④记忆税增列读回调用与纠偏重试（接 #5／#138）。⑤五项目经 tag／release 核实：OpenViking v0.5.5、Hy-Memory v2.0.17＋MemHub v1.0.8、TencentDB v2.0.4、dsh v26092802、ReMe v0.4.2.3，均无接口版本绑定、失效广播、强制读回与假成功指标。

## 八、本期新观点

1. **成功经验是负债的载体，不只是资产**（接 #75 划界、深化 #139）——资产／负债取决于接口是否变化；越常用越不查，1→10 次经验把成功率从 46% 压到 26%。
2. **静默变更抹掉了自监督信号**（接 #128 划界）——预测—实测落差在 ok:true 下永远为零，记忆系统必须自己制造读回这一观察。
3. **回执只证 accepted，不证语义正确**（深化 #138）——写时兑换挡住未发生的事，挡不住"发生了但没发生你要的那件事"，假成功率 92%—99%。
4. **提示位置是记忆设计的变量**（新角度）——同一句"先读文档"放系统提示降到 29%，放任务消息升到 99%；文档放工具描述 55%、放任务消息 99%，可用性由上下文位置而非内容决定。
5. **手写历史会系统性低估记忆风险**（新角度）——带读回的手写轨迹让代价从 0.54 变 0.11，评测必须让 agent 自己赚经验。
6. **记忆税增列读回与纠偏重试，AML 补 experience-rot 维度**——以"接口变更后是否还能做对、做错能否被发现"验收，而非只看命中率与压缩比。
