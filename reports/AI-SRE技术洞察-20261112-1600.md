## 主线

首次把「SRE Agent 自身产出的发现流（findings / 观测结论 / 假设 / 升级请求 / 自我告警）的信噪比——其中多少是真信号、多少是误报或低可操作性噪声——立为一等运维对象」。前 153 期问治理/审批/评测/韧性/模型/执行场/图谱/自改/编队/上下文，本期问一个被集体默认「已解决」却被悄悄转移的问题：**Agent 把人类的告警疲劳治好了，但它自己吐出来的海量发现，谁来判断真假、谁来看、有没有信噪比 SLO？** 负事件家族里唯一「指标在绿、Agent 在跑、人类不累了，可 Agent 自己发出来的发现里有多少是假阳性、多少是噪声，全不知道」的成员。

## 一、发展趋势

1. **叙事从「消灭告警疲劳」转向「噪声转移（Noise Displacement）」**。2026 年行业把告警疲劳从流程问题重分类为工程问题（Nova AI Ops 2026 手册、Adservio 11 月复盘）：Dynatrace Davis 以异常基线把假阳性降 60–80%、Nova 宣称总告警量降 85–95%、Adservio 称告警疲劳降 40–60%。但所有这些数字量的是「阈值/规则噪声」，不是「Agent 输出噪声」。
2. **评测重心从「做对没」滑向「发了多少噪声」**。LuminaByte（2026）把影子模式退出标准定为「推荐准确率 >80%、假阳性率 <15%」——第一次把 Agent 输出的假阳性当成可量化退出闸门；但这是训练期门槛，不是生产持续 SLO。
3. **自我告警回路出现**。Azure SRE Agent 的 Autonomous 模式、Google Actus 常驻子 Agent 会自己触发升级/自我告警，Agent 的输出开始反噬自己的 review 层，形成内部噪声正反馈。

## 二、技术现状

- **厂商都在「降人类噪声」**：Google Triage 把 500 万+ 告警压到 60 秒级、三层事实（Observed/Approved/Derived）；阿里 STAROps「证据不足不越界」；字节火山 RCA Harness 约束层；腾讯 CloudQ Harness 评测闭环；Anthropic OTel 智能体追踪公测。
- **但「Agent 输出信噪比」无一等对象**：Grafana 给 Agent 设了幻觉/达成/毒性/成本 SLO，却无「发现精度/误报率」；Dynatrace 降的是阈值噪声不是 Agent 噪声；confidence score（Nova 手册）≠ 精度——LLM 校准差，高置信常错。
- **incident.io 自曝 80% 水分在「已知类归并」**，但「未知类 Agent 假阳性发现」无人计量。
- **Cognition Devin Oncall 日产千级告警**——Agent 自己就在产告警，review 负担只是转移没消失（呼应第 21 期值班台空转）。

## 四、技术挑战

1. **噪声转移不可见**：人类告警疲劳下降的 KPI，与 Agent 输出噪声上升的成本，不在同一张表上。Cognition 千级告警证明负担只是挪位。
2. **置信度 ≠ 精度**：LLM 输出 confidence 高却错（校准缺口），Nova 的「低置信进队列」会漏真信号或积压。
3. **自我告警回路无闸门**：Autonomous Agent 自己升级自己，噪声在 Agent 内部正反馈放大。
4. **评测盲区（接 153）**：Incident-Arena / SREGym 量根因/修复/越界，没量「Agent 发了多少发现、其中多少是噪声」；假阳性发现续发成新噪声。
5. **review 负担无 SLO**：没有人把「人类 review Agent 输出的时长/占比」定义为可靠性指标，第 21 期值班台空转在此显形。
6. **第 107 个市场空白五项**（Agent 输出信噪比 / 发现误报率 / 自我告警可计量率 / 噪声转移可观测率 / 人工复核 Agent 输出占比），`agent_noise.*` / `signal.*` **第 74 次无人提字段族**。

## 五、展望与建议

- `agent_noise.*` 七字段：finding_id / precision_slo / false_positive_rate / self_alert_count / review_burden_ratio / noise_transfer_flag / confidence_calibrated。
- 把「Agent 输出信噪比」提为生产持续 SLO（复用 LuminaByte 影子模式 <15% 假阳性门槛，从训练闸门变生产 SLO）。
- confidence 必须校准：用真实后验替换模型自报置信（深化 153 双闸的「假阳性修复」）。
- 自我告警回路加闸门：Autonomous Agent 自我升级须带信噪比预算，超阈值自动降级为建议。
- 噪声转移看板：人类告警量↓ 与 Agent 输出噪声↑ 同屏，禁止只报一头。
- 评测扩展（接 153）：Incident-Arena / SREGym 增「输出信噪比」维度；信通院六维补「Agent 输出信噪比达标率」格。
