# 记忆技术洞察（第 28 期）：记忆的标准时刻——schema 即世界观

> 出品：AgentMemory 每小时洞察自动化 · 2026-11-08 09:00 · 范围：2026 年（近 30 天为主）

## 一、发展趋势

前 27 期反复记录同一类"口径缺口"：弃答、冲突、信用、规模、前瞻……评测合同均不设位，问题靠事故发现。本期给出行业真正的解法路径——**标准化先于评测**。三条线在 30 天内同时推进：**协议层**，MCP 2026-07-28 修订把新鲜度与缓存稳定性写进必填字段；**格式层**，MIF、Engram、MCP Memory Taxonomy 三个互操作格式并立竞争；**治理层**，Anthropic 于 10 月 22 日把 Agent Skills 标准连同名称、组织与域名捐给 Linux 基金会旗下 AAIF，存量约 100 万技能、2.8 亿安装进入共同治理。判读：竞争继"看分→看插座→看账单"之后进入第四档——**看 schema**；且标准化动力全部来自第三方而非厂商（详见第三节），本期为"倒挂"系列第十九次。

## 二、技术现状

**协议层：MCP 2026-07-28 修订吸收了前几期的发现。** tools/list 要求确定性排序，理由直接写明"提高 LLM 提示缓存命中率"——第 14 期字节稳定性定理进了协议文本；list/read 结果新增必填 ttlMs 与 cacheScope（public/private），第 11 期新鲜度账单获得协议级字段；资源订阅改走 subscriptions/listen。但修订同时**显式留白**：抽取什么、冲突如何合并、删除到底删什么，全部留给后端实现，协议只标注 destructiveHint 等行为提示——而多数记忆服务器根本不声明，按默认即"我的每个工具都可能销毁数据"。

**格式层：三格式并立，分类学第一次公开摊牌。** TotalReclaw MCP Memory Taxonomy v1（4 月，已部署 5 客户端）类型学取自 Searle 言语行为理论而非 Tulving 认知分类，provenance 设为一等字段——根因是 Mem0 审计 Issue #4573 发现 **97.8% 条目为垃圾**，源头是助手内容被误归属为用户事实。MIF v2 走最小主义：仅 3 个必填字段，自称"记忆的 vCard"，提供 mem0/CrewAI/LangChain/Markdown 互转工具。PLUR Engram Spec（3 月，Apache-2.0）用 YAML 承载 ACT-R 式衰减与强化模型，定义 learn/recall/inject/feedback 四操作。三者对"一条记忆是什么"给出三套不同答案——schema 即世界观，谁的分类被采纳，谁的本体论就写进所有人的系统。

**治理层：捐赠即中立化，也是承诺冻结。** Anthropic 将 Agent Skills 名称与商标、GitHub 组织、agentskills.io 域名移交 AAIF（Anthropic 与 Block、OpenAI 为共同创始方，MCP 早已捐入同一基金会）；维护者由 Anthropic、Google、OpenAI 工程师以个人身份担任，路线图含版本化发布与正式提案流程。台湾阿尔法实验室的评析点出捐赠的未决问题：技能写入了团队的工作经验，标准共同治理后**兼容性与安全的责任无人认领**——格式中立化了，但技能包的投毒面（第 15 期判读之四）随 2.8 亿安装同步放大，AAIF 路线图中的"安全指引"正是对此的迟来回应。

**许可证是隐形的第四条标准线。** OpenViking 选 AGPL-3.0，实质是把"对接其 viking:// 协议"变成强制互操作条款——商用托管必须开源，这是厂商用许可证代替格式委员会实施的标准策略；对照之下 Mem0/Graphiti/Letta/cognee 全部 Apache-2.0、TencentDB 元数据 NOASSERTION，许可证光谱本身构成采购变量。

**六个指定项目动态。** OpenViking 41,337★（周 +448、月 +2.2K），v0.5.3，AGPL-3.0；TencentDB-Agent-Memory 近期发布聚焦 OpenClaw 插件加固（activation.onStartup 声明、contracts.tools 注册契约、调度竞态与压缩卡死修复）并提供 v2→v3 迁移工具，Team Memory Beta 持续演进；Hy-Memory 2.0（10 月中）30B-A3B 专用写入模型（Apache-2.0）+ MemHub 本地优先应用，diff 链保留"为什么改"；dsh-memory-evolve 665★、7 日 +198（较前一周 +421%），生态第三变体 huahua-dsh-memory-os 的 Memory Sync 用代码仓专用分支存记忆、冲突三选（本地/远端/双存）；Mem0 定价 11-02 改为 Free/Custom 两档（自助 Starter/Pro 下架）；AML 二期 11-01 02:00 关投稿、11-04 23:59 关正式评测，官方榜单 11 月中发布，11-08 仍显示 "Cycle 2 is underway"。AML 首期全能力剖面已在官网公开：MemoraX 58.02 领跑，Cognee v1.4.0（42.61）位列第五。值得注意的是，AML 的评测合同本身做了数据版本化（textual-v1 套件），却只固定 Add/Search 接口、不固定记忆 schema——**评测的标准化与互操作的标准化是两条不相交的轨道**。

## 三、技术竞争力

标准主权分四层，各层归属完全不同：**协议层**单点（Anthropic 捐出后名义中立）、**格式层**无主（三格式竞争，无一家厂商背书）、**治理层**基金会共管、**事实标准层**归社区（DSH 生态的民间五轨 schema 装机量远超任何正式格式）。关键判读有三：其一，**能写标准的恰是无利益方**——TotalReclaw 自述"Mem0/Zep 有商业理由分歧，我们受益于收敛"，MIF 与 PLUR 亦为社区项目，头部记忆厂商在格式层集体缺席（倒挂第十九次）；其二，MIF 的"3 字段最小主义"对阵 Engram 的"理论负载型 schema"，更简单者先赢的判断（第 13 期）正在复验；其三，**捐赠换来中立性、付出承诺税**——2.8 亿安装形成棘轮，标准一经冻结即演进冻结，此后每一步都要走多边流程。

## 四、技术挑战

**schema 即世界观的三重代价。** 其一，分类学之争没有仲裁：Searle 派与 Tulving 派给出的类型集不兼容，closed enum 一经定错，错误本体论随格式扩散全网。其二，**留白即债务**：MCP 把删除/冲突/抽取语义标准化为"不标准"，第 2、8、9 期的注销、并发、闭环问题在协议层原样存在——互操作只到插座为止，插座后面仍是十种方言。其三，来源误归属是普遍病（Mem0 97.8%），provenance 一等字段的存储与校验成本将进入每个采用者的账单。此外，评测合同与互操作标准两轨不相交：AML 不测迁移性，第 13 期"迁移/连续性无分数回报"的缺口在标准化时代依旧无人回报。

## 五、展望与建议

第一，**协议是发现的汇聚点**：ttlMs、cacheScope、确定性排序说明协议修订正把研究侧共识固化为必填字段，节奏快于评测。据此预判，下一批进入协议的将是第 2 期墓碑三字段（valid_from/valid_until/superseded_by）与第 12 期 owner 字段——建议持续跟踪 MCP 规范仓的提案流。第二，**采购选型应把"schema 出口"列为硬指标**：导出格式、迁移工具、许可证之外，再看是否声明 provenance 与 scope 字段——这是第 13 期嵌入锁定之外的第二个锁定面。第三，格式层三格式并立的窗口期估计只有 6—12 个月，建议高校与评测组织（如 AML 团队）主动认领仲裁角色；TotalReclaw 已声明将 Taxonomy 作为 optional extension 提交 MCP 规范仓，其被吸收与否是格式层收敛的第一个信号。第四，AML 二期榜单 11 月中发布，为本系列下期最高优先事项；若榜单继续不设迁移/互操作维度，将是口径缺口第二十次。
