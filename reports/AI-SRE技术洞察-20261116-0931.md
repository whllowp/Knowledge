# AI-SRE 技术洞察（第 210 期）

**生成时间**：2026-11-16 09:31（北京时间）｜**窗口**：2026 年，重点最近 30 天
**本期主题**：接口面／外部 API（API Surface）——Agent 的能力一半来自别人的 API；限流、配额、弃用、契约，四件事都不在自己手里

---

## 题记

67 期说「我们的可用性是别人状态页的函数」，137 期说「工具契约会在版本 pin 下漂移」，138 期说「模型路由有降级」，180 期说「重试会放大」。这四件事在**外部 API** 上合成一个 Agent 特有的暴露面：**Agent 的能力一半来自别人的 API**——模型、搜索、地图、支付、邮件、工单。**限流、配额、弃用、契约变更，四件事都不在自己手里**；而 Agent 会把它们**放大**：**一次任务调十次 API，一次失败重试三次**。**API 不是「集成」，是「别人替你决定的生命周期」**；**你的 SLO 里，有一半是别人的排期——而排期不会发给你。**

## 一、发展趋势

**趋势一：从「集成一次」转向「持续跟踪生命周期」。** 弃用公告、配额调整、契约版本；**都要人盯**（150 期）。

**趋势二：适配层成为标配。** 统一接口、可替换供应商；**换 API 不改 Agent**（118 期）。

**趋势三：配额进入容量规划。** 不只是限流；**月度配额、并发配额**（161 期）。**配额是别人给的容量，不是自己买的。**

## 二、技术现状：四种风险，通常只测一种

**限流：最常测。** 429 有指标；**但重试放大没算**（180 期）。

**配额：最少测。** 月度/并发上限；**撞上才知道**（161 期）。

**弃用：最容易被忽略。** 公告发了；**Agent 还在调旧版**（150 期）。

**契约变更：最隐蔽。** 字段/语义变了；**契约测试没覆盖外部**（203 期）。

**现状：只监控错误率。** 429/5xx 有；**弃用倒计时、配额余量没有**。

**三种配额，一种比一种难算。** 速率（每秒）、并发（同时）、总量（每月）；**前两个能测，第三个要等月底**。

## 四、技术挑战

**一，弃用公告不推到人。** 发在开发者博客；**Agent 不会读**（150 期）。

**二，配额是月度的。** 月初撞上；**月中才发现**（161 期）。

**三，重试放大限流。** 429 后重试；**越重试越 429**（180 期）。

**四，契约变化不通知。** 字段还在、语义变了；**外部没有契约测试**（203 期）。

**五，适配层有成本。** 每接一个 API 写一层；**不写就被锁死**（118 期）。

**六，成本随配额走。** 提配额要加钱；**不提就限流**。

**七，区域与合规限制。** 某些 API 只在特定区域可用；**Agent 的部署区被 API 绑住**（140 期）。

## 五、需求分解、用户旅程与实现方案

### 5.1 需求（按优先级）

- **R1 `api.*` 字段**：`provider`、`endpoint`、`version`、`rate_limit`、`quota_left`、`deprecation_date`、`contract_ref`。
- **R2 配额余量**：月度/并发；**低于阈值告警**（161 期）。
- **R3 弃用跟踪**：公告入库；**到期前 90/30/7 天提醒**（150 期）。
- **R4 适配层**：统一接口；**可替换供应商**（118 期）。
- **R5 外部契约测试**：关键字段/语义；**变更即告警**（203 期）。
- **R6 指标**：支持期内依赖率、配额余量、弃用逾期数、回退演练通过率。

### 5.2 用户旅程

- **平台工程师**：接新 API → 登记版本/配额/弃用日 → 写适配层 → 季度复核。
- **SRE**：配额余量 10% → 告警 → 申请扩容或降级。
- **安全**：API key 轮换 → 适配层统一改（163 期）。
- **审计**：抽查依赖 → 全在支持期内 → 通过。

### 5.3 实现方案（90 天）

- **0–30 天：盘点。** 外部 API 清单；版本/配额/弃用日。
- **30–60 天：监控。** 配额余量；弃用提醒；外部契约测试。
- **60–90 天：适配。** 关键 API 加适配层；回退演练；区域限制核对。

**第 148 个市场空白（五项）**：外部依赖清单覆盖率、配额余量可报率、弃用跟踪覆盖率、外部契约测试率、适配层覆盖率——无一内建；`api.*`／`provider.*` 为**第 116 次无人提字段族**。本地 173／173-kb 连续第 106 期成组启用：余锦泽 03「上下文装配、工具调用、结果校验」＝全库唯一把「工具调用」写成流水线环节的实践，本期首次当主线；配 67 期上游、150 期生命周期。判词：**本地把工具调用写进流水线，联网侧 2026 年才承认「可用性是别人状态页的函数」；两边都没把「这个依赖还能用多久」做成清单字段。**
