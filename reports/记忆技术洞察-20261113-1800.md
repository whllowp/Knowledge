# 记忆技术洞察 · 第 84 期（20261113-1800）

## 本期主题：记忆的「学习化控制」——把"记什么/读什么/何时"从外部接口与启发式规则，训练进策略本身（policy-native memory control）

> 承接 #1 写入闸门（规则）/ #72 写时依赖筛选（启发式）/ #21 替代品（上下文归约）/ #22 信用分配（记忆不可读），用 2026-11 CAMP-II(arXiv 2611.14009v2, 11-12) 与 Coding Agent Memory Gym II 刷新；与 #79 决策效用（决策仲裁）/#15 动作性（技能即记忆）正交——本期管"记忆控制权本身是否应被训练进策略，而非外挂为服务"。

### 一、四维洞察

- **发展趋势**：记忆研究从"更好的外部记忆库"逼到"记忆行为是否该内化为策略"。百度百科将"启发式管道→RL 驱动控制"列为 2026 前沿方向；CAMP-II 是其实证落地——记忆的写/读/时机不再由 prompt 工具接口与 compaction 协议硬编码，而由策略在预训练文件操作先验上经 on-policy distillation 习得。竞争焦点从"谁的库更准"迁到"谁把记忆控制训进了权重"。
- **技术现状**：2611.14009v2 指出根本矛盾——外部记忆工具与 compaction 协议"落在双方预训练之外"：教师（通用 LLM）从没用过该接口，给不出有用梯度；学生又采样不到足够的记忆动作。解法是 CAMG-II 五环境（Shop/Coding/AutoResearch/General/Visual）提供 episode-persistent workspace 与原生 Bash，让策略"像用文件一样"自决创建/修订/检索/复用记忆跨上下文替换；CAMP-II 在冻结教师上异步 OPD，较最强 OPD 基线获 **2.97× 增益**，并泛化到 Terminal-Bench 2.1 与 SWE-Bench Pro V2。
- **技术竞争力**：六项目（OpenViking v0.5.4.1 / Hy-Memory 2.0.16+MemHub v1.0.7 / TencentDB v2.0.3 / dsh v26092802 / ReMe v0.4.2.2）全为外挂式 Add/Search 服务，零"记忆控制进策略"披露；AML Cycle 2 实时榜（进行中，MemoraX 58.02 领跑文本榜、按 A/B/C/D/E/G/H 能力剖面排）更进一步把"记忆系统=外挂 Add/Search API"固化成评测契约。倒挂延续：policy-native 记忆控制前沿在论文，产品缺席。
- **技术挑战**：①治理黑箱化——记忆控制进权重后，写/读决策不再有外部日志可审，与 #22"记忆不再可读"、#65 信念化、#69 治理元进化同源；②AML 契约盲区——固定答模型、只评外部服务，测不到"策略即记忆"的内化方案，是 #56/#79 口径缺口的新形态；③文件操作先验≠通用记忆先验，跨非文件域（对话/多模态）能否同样内化仍待证；④训练成本与可回滚性——权重里的记忆控制不可像外部规则那样一键回滚。

### 二、需求分析

长程 agent（尤其 coding agent）在上下文替换时反复"重写决定记什么"，现有外挂记忆把写/读时机交给 prompt 与 compaction 启发式，教师从未用过这些接口，指导信号稀薄。团队要的不是"更聪明的外部库"，而是一套能随任务学会"何时落笔、何时回读、何时丢弃"的策略，且落笔行为可观测、可审计。

### 三、用户旅程

1. **建环境**：以 episode-persistent workspace + 原生文件操作为记忆基底，替换纯 Add/Search 黑盒。
2. **训策略**：冻结教师、异步 OPD，让策略在长程任务中自决文件式记忆动作，奖励按"后序任务能否据此解出"反传。
3. **上线/泛化**：策略权重接管记忆控制，跨仓库/跨基准零样本复用（CAMP-II 已验证 Terminal-Bench/SWE-Bench）。
4. **观测**：把"记忆动作日志"（何时写/读/弃）从权重里抽取为可审计流，补治理黑箱（接 #22/#69）。

### 四、具体实现方案

- **文件即记忆基底**：复用 CAMG-II 思路，把记忆动作还原为模型已会的文件操作（create/revise/grep/reuse），绕开"未见接口"鸿沟。
- **OPD 接管控制**：把"写/读/时机"从 prompt 规则（#1 闸门/#72 筛选）改为策略内决策，奖励绑定后序任务成功率，使记忆控制可学习。
- **审计抽取层**：训练期强制记忆动作走可记录通道，权重固化后仍能回放"何时记/读"，缓解治理黑箱（接 #69 元政策回滚）。
- **AML 契约扩容**：主张评测纳"policy-native"类（策略即记忆），否则 #56 缺口将系统性漏掉内化方案。

### 五、本期权观点（新视角）

①记忆控制权的"学习化"是比"更好外部库"更深的拐点到——它把 #1 规则闸门/#72 启发式筛选重述为"从数据中涌现的写读策略"；②外部记忆工具落于预训练之外是行业隐性天花板，CAMP-II 用"文件操作先验"破局，揭示"记忆行为应建在模型已会的东西上"；③倒挂新形态——AML 把外挂范式固化成契约，反而可能屏蔽 policy-native 方案的评测（接 #56/#79）；④治理代价：控制进权重=审计盲区，权重里的记忆控制不可像规则一键回滚（深化 #22/#69）；⑤这是百度百科所述"RL 驱动控制"方向的首个强实证，标志记忆从"被调用的服务"走向"被训练的能力"。
