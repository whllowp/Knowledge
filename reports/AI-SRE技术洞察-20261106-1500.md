**本期主线（第八十条）**：降级面 / 兜底路径面——**高可用系统里最不高可用的是它的降级路径**：正常路径有 SLO、有演练、有 trace，降级路径三样全无，却恰在事故当天接管全部流量。

**与前作划界**：64 变通面是模型即兴找路，本期是**人写好却几乎从不执行的第二套代码**；82 缺省面是静态参数，本期是动态分支；81 弃权面把不判当交付，本期把它放回阶梯——**弃权是降级第四级**；20/56 期问练不练，本期问**练的是不是真会被执行那条分支**。视角落到 86/87/88 共用的正常路径之外。

## 一、发展趋势：准入条款上线了，运行态没有

**标准侧第一次写下这两个字，写的是动作不是状态。** 11-03 信通院《云上 Agent 基准度量模型》六维评估并"保留人工接管兜底机制"；云大所《迈向 Agentic Ops》要求"保留降级、撤销和人工接管""指标越界或证据不足时及时降级"，标准清单《训推作业保障能力要求》已含"降级熔断"；11-04 二十家单位《智能体发展自律公约》写进"异常熔断"；流量负载均衡标准把故障注入与渐进恢复列为测试场景。**上线的是"要求保留"，没有一行"要求观测降级态"。**

**商业侧"少看"可结算，"少做"零分母。** 11-04 LogicMonitor 一手稿：ANS 部署 Edwin AI 处理 170 万事件、去重近 29.7 万告警，噪声降 83%、事故量 7 月约 4,300→10-29 的 2,383、解决时长降 44%、SLA >97%，MCP 仍 private preview（厂商自述）。判词：**降噪减少输入，降级减少承诺**；前者有分子分母能算 ROI，后者连"少做了什么"都没有字段。

**平台侧替用户决定降不降级。** 11-03 火山 AgentKit 新增执行超时，"超时自动终止请求并返回错误"＝最粗一级兜底，而「使用限制」页仍写同步超时 30 分钟不可调；11-01 Claude Code 2.1.316 宣布 Opus 4.8 fast mode 于 11-30 下线后**不回落标准版、直接报错**。两者都只在 release note。触发者还有账号策略与相关性故障（9-03 多家模型同挂被指向共享区域，转述）。

**经典结论与当下方向对撞。** Google《SRE》把 degraded responses 定义为"更便宜、精度更低或数据更少的答案"；Amazon Builders' Library《避免在分布式系统中回退》判定 fallback 用**不同机制**达成同一结果（区别于同构副本的 failover），难测、自身会失败、给吃紧的下游带去不可预测负载；2001 年亚马逊缓存全挂、Web 层回源压死数据库，把"缺配送速度"变成全站故障。最实用的替代是**把回退转成故障转移**（双路径常态跑、随机选一，备用路径一直被演练）。三十年结论是"尽量别用 fallback"，Agent 侧却在加层：五级阶梯、备用模型、缓存答案、只读、转人工。

## 二、技术现状：四套语义，一个共同的观测空洞

**① 降级是承诺变更，答案形状却没变。** "A reduced answer formatted to look like a full one misleads the reader"——读者按全价给答案定价。模式须两处留痕：响应的自然语言＋trace 的事实，且 trace 回答三问：**哪个依赖失败、何时开始、停止做什么**；缺一即 "exists in the prompt and nowhere else"。这也修正 81 期口径：五态阶梯 full→reduced→deterministic→abstention→isolation 里，**弃权是第四级而非顶层开关**；不知处于哪一级就统计 `abstain_rate`，量的只是结果。

**② 多一层决策，且是模型那一层。** RPC 失败→结果给人；Agent 失败→结果**回填给模型**→模型决定下一步，"只读模式"可被读成"暂时查不到"。一份 2026 复盘：供应商变慢触发 fallback 后重复回复、跳过安全检查、日志显示成功却卡在处理中——**API 全绿、信任掉两天**（86 期的降级层镜像）。工程答案是显式状态机、禁止 `completed → fallback_attempt`，以及本期最该抄进规范的一句：**fallback 输出验证更严不是更松，降级不得绕过策略闸门**；事故响应 containment-first 先冻结版本。

**③ 降级是放大器，不是收敛动作。** 2001 案例已证备用路径放大故障；Agent 版是全 fleet 同切备用模型、带着更长上下文涌过去，检索失效退回模型记忆时"答案继续流出、已无依据、没人被寻呼"＝**失败安静下来了**。与 40 并发面划界：那期管不同的写同时发生，本期管**同一降级决策被复制到所有实例**，且触发恰在系统最脆弱时。

**④ 最需要证据时，证据管道最薄。** Anthropic 10-14 OTel 公测自认 best-effort、默认仅元数据、sampled flag 一关整条不发；OpenAI SDK 在 ZDR 下 tracing 不可用、阿里 CMS 2.0 插件默认关闭；OTel GenAI 11-02 仍全 Development、内容 Opt-In。**观测体系自己也在降级，且这次降级也没标签**；继 72 `identity` 至 88 `delegation.*` 十一族之后，规范仍无 `degraded.*` 字段族。

**⑤ 恢复段比进入段更没人管。** 依赖恢复后应自行回全模式、**挂起工作写回前重检**、陈旧内容转人工；多数产品只有进入开关、没有退出验收（86 期"恢复不可声明完成"的模式层复现）。"从最后一份好副本作答须把副本日期写进答案"是少数显式暴露 as-of 的正面案例，但规范无 `data.as_of`，副本年龄无法机器读出。

**⑥ 演练只练正常路径。** Google 警告 "the code path you never use is the code path that (often) doesn't work"；中文实践三条纪律：级别打进每条响应、**每级独立可用不可依赖上级产物**、换小模型须换模板，并直认"平时不走，真到用时才发现已经坏了"。网关侧补：记录**每个请求由哪个模型服务**、fail-closed、备用模型跑同一评测集、按计划屏蔽 provider 演练。

## 四、技术挑战：第四十三个市场空白

**降级是负事件家族里唯一"有代码"的成员。** 78 到期、81 弃权、82 缺省、83 采样都表现为"没有这条记录"；降级有明确分支与作者，却因只在故障时才跑，同样不进变更流、审计与 SLO。RCA 先验"找最近变更"依旧找不到它——**因为它不是变更，是同一份代码走了另一条分支**。

**四项指标无一内建**：降级态标签覆盖率、`degraded_interval_quality_delta`、降级路径演练通过率、恢复段复核率（挂起工作重检占比）；对比表"双标注""常态演练""恢复段复核"三列几乎全空。OTel GenAI 仍无 `degraded.level` / `reason` / `entered_at` / `stopped_doing` / `exit_verified`——第 12 次字段族提案无人提。

**与往期交叉处全是空白格。** 88 期：切备用模型＝换主体／供应商／合规域，79 期花名册与 `delegation.*` 没有"临时替代主体"这一格，scope 仍应取交集。87 期：降级期证据最薄、候选集最小却仍按 top-1 输出——**在证据最少时给出最肯定的结论**，应把证据降级与承诺降级绑定。83 期：备用模型更便宜，但重复查询与挂起重检更贵，计费单位分裂使这笔账无法归集。56 期演练目录缺"备用路径同时坏／挂起工作陈旧／同 region 假冗余"三型。

**本地 173 / 173-kb 连续第十期成组启用，升级为「降级治理原型」。** 快手 04 把题眼写成事故——"外部模型超时没有降级引起雪崩"，并立下最硬制度：**"单测必须覆盖兜底逻辑（限流／熔断／降级／超时／重试）作为上线门槛（准入＋准出＋自动化测试三道闸）"**。携程 10 给出进入—驻留—退出三段："结合行为上下文并**安全降级**""失败能够熔断或回滚"、**"保守阈值 宁可少治理，也避免误伤"**、"快速回热：访问恢复时自动回迁"。余锦泽 03 给出本期最缺的**标签契约**："只读问答可用，**答案须标明未确认**""独立复核只降级、不升级"＝单向状态机。刘宗明 06 把"**可降级**"写进动作协议；朱革 15 "自做 fallback → 默认高可用"；李东东 16 "端侧优先，云端兜底"＝**常态双跑**，与 AWS "回退转故障转移"同构；刘凯宁 05 "查询失败只能说明证据不可用"划出结论边界；casa 01 "不能只给最终结果"＝**只演示成功态正是失管起点**。判词：联网侧还在争论要不要降级，本地早做成带标签、带只读切换、带上线闸门、常态双跑的一等对象；连续第十期同一结论——仍是项目内约定，不可采购。

## 五、展望与建议

**立成一等运行态**：`NORMAL / REDUCED / READ_ONLY / DRAFT_ONLY / ABSTAIN / ISOLATED / RECOVERING` 七态，每态声明**禁止的动作集合**而非"能力降低百分比"，配 `degraded.*` 五字段、由确定性控制器设置。**两处留痕**：响应自然语言＋trace 事实（dependency / entered_at / stopped_doing / exit_verified），缺一即按未降级承担全价验收责任；**降级输出验证强度不得低于主路径**，`fallback_attempt` 仍须过策略闸门。**常态双跑**：把 fallback 转 failover，每周固定一小片流量强制走 read-only，备用模型跑同一评测集；演练新增三型，恢复段独立验收（挂起重检、陈旧转人工、T+1 复测）。**主体登记**：备用 Actor 进 79 期花名册与 88 期委托链。**采购三问**：级别能否导出／降级期动作能否单独计分／是否与主路径同频演练；建议信通院六维"可靠"补格，把"保留兜底机制"改写为可验证的"降级态可观测"。

**结论**：79 编制至 88 授权之后，本期是——**"少做的制度"也还没上线**。没有一家把"此刻少做了什么、少做的那部分有没有被验过"当成可验证、可采购、可 SLO 化的承诺。
