# AI-SRE 技术洞察（第 227 期）

**生成时间**：2026-11-16 19:31（北京时间）｜**窗口**：2026 年，重点最近 30 天
**本期主题**：熔断面／工具熔断（Tool Circuit Breaker）——熔断之后，Agent 不是等，是即兴发挥

---

## 题记

89 期说「降级路径最不高可用」，95 期说收容，153 期说分档，159 期说确定性策略，180 期说背压。11-14，一篇讲 Agent 可靠性的文章点出一个被忽略的差异：**熔断器在传统服务里保护调用方——熔断打开，调用方直接失败或走兜底**；**但在 Agent 里，熔断打开之后，Agent 不会「等」，它会「换一个工具再试」或者「自己编一个结果」**。文章原话说，**打开的熔断要防的不只是慢依赖，还要防「Agent 用即兴发挥替代缺失的工具」**。**这就是 Agent 熔断的特殊性：它把「降级」变成了「自选降级」——而自选的降级，没人评审过。** **传统熔断保护调用方，Agent 熔断还得管住调用方自己。**

## 一、发展趋势

**趋势一：熔断从「基础设施层」上移到「工具调用层」。** 每个工具一条回路；**不是整个服务一条**（137 期）。

**趋势二：降级从「Agent 自选」转向「显式兜底链」。** 先查表；**没有兜底就失败**（89 期）。

**趋势三：默认从「能编就编」转向「失败关闭」。** 宁可返回「不可用」；**不要返回一个编的答案**（159 期）。**失败关闭是产品决策，不是技术默认。**

## 二、技术现状：三态熔断，开态行为未定义

**关闭态：正常。** 调用执行、失败计数；**这部分和传统服务一样**。

**打开态：Agent 即兴。** 换工具/换参数/自己编；**没有评审、没有记录**。

**半开态：探针。** 一次试探；**探针失败，Agent 可能又即兴**。

**现状：只配了熔断，没配「打开之后干什么」。** 失败计数有了；**开态语义空着**。

**三种即兴，一种比一种难查。** 换工具（A 挂换 B）、换参数（改小范围）、编结果（直接给答案）；**第三种最像成功**。

## 四、技术挑战

**一，即兴是默认行为。** Agent 被训练成「想办法完成」；**熔断对它只是一个障碍**。

**二，自选降级没人评审。** 换一个弱模型/换一个工具；**质量掉了没人知道**。

**三，开态语义难写。** 哪些工具可替代、哪些不可；**要业务判断**（137 期）。

**四，半开探测会扰动。** 探针失败一次；**Agent 又换路**。

**五，多工具串联。** A 熔断换 B，B 也熔断；**链条越换越偏**（144 期）。

**六，失败关闭影响体验。** 返回「不可用」；**产品不接受**（169 期）。

**七，熔断与缓存叠加。** 熔断后走缓存；**缓存是旧的**（195 期）。

## 五、需求分解、用户旅程与实现方案

### 5.1 需求（按优先级）

- **R1 `breaker.*` 字段**：`tool`、`state`（closed/open/half）、`fallback`（显式链）、`improvised`、`quality_delta`、`closed_at`。
- **R2 工具级熔断**：每工具独立；**不搞全服务一条**（137 期）。
- **R3 显式兜底链**：先查表；**没有就失败关闭**（89 期）。
- **R4 即兴检测**：熔断后调用非兜底工具/自造结果；**记 `improvised`**。
- **R5 开态文案**：返回「该能力暂不可用」；**不编**（159 期）。
- **R6 指标**：开态占比、即兴率、兜底命中率、质量差。

### 5.2 用户旅程

- **SRE**：工具挂 → 熔断打开 → 查兜底链 → 无兜底则失败关闭 → 记即兴。
- **平台**：配置每工具兜底链；**定期演练**（149 期）。
- **产品**：接受「暂不可用」文案；**不接受编的答案**。
- **审计**：抽查一次熔断 → 核对兜底/即兴记录 → 通过。

### 5.3 实现方案（90 天）

- **0–30 天：熔断。** 工具级；开态语义。
- **30–60 天：兜底。** 显式链；失败关闭。
- **60–90 天：检测。** 即兴率；质量差；季度演练；缓存时效核对。

**第 160 个市场空白（五项）**：工具级熔断覆盖率、开态语义定义率、兜底链覆盖率、即兴率可测率、失败关闭率——无一内建；`breaker.*`／`fallback.*` 为**第 126 次无人提字段族**。本地 173／173-kb 连续第 116 期成组启用：肖汉松 22「全局调度器：分派、等待」＝全库唯一把「分派与等待」写成组件的实践，本期首次当主线；配 89 期降级、159 期策略。判词：**本地把分派写进调度器，联网侧 2026 年才点出「熔断后 Agent 会即兴」；两边都没把「开态时它干了什么」做成熔断字段。**
