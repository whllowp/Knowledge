# AgentMemory 技术洞察 · 第 78 期（20261113-1100）

> 范围：2026 全年（重点近 30 天，截至 11-13）｜固定四维：发展趋势·技术现状·技术竞争力·技术挑战
> 主题：记忆的"写入保真·读取裁决"范式——召回已饱和，"分辨"才是新瓶颈
> 新源：DISCERN（arXiv 2611.15729，NeurIPS 2026，11-11）、MIRIX-2.0（arXiv 2611.12068，11-09）

## 一、需求分析（对应·技术挑战）
企业 agent 跨数十会话积累记忆，事实彼此矛盾、被新值取代、同名实体在嵌入空间碰撞——记忆领域一直把它当"检索问题"在解。但 DISCERN 在 ENT-310（310 问，210 可答 / 100 不可答）上证明：一个朴素的 RAG 阅读器在 retention / currency 上已达 0.93–0.98，**召回这根支柱基本被填平**。真正的缺口是 **resolution（分辨）**：查询指的到底是哪个实体、哪个时间态是当前态、证据不足时该不该作答。这对产品提出新需求——记忆系统必须从"记得多/准"升级到"分得清/敢拒答"，否则高召回只会放大 #75 反噬（用错记忆更差）。

## 二、用户旅程（对应·发展趋势）
把一次"该不该信这条记忆"的旅程拆开：
1. **写入时**只做一件事——**保真（preserve）**：建立严格追加（strictly additive）的双时态溯源图，绝不合并易混淆实体、绝不丢弃被取代值。DISCERN 以"不可变 per-actor 事件日志"为唯一真相源，实体图 / 双时态事实库 / 情节层都只是可重建的派生视图。
2. **读取时**才做**裁决（resolve）**：零-LLM 工具面驱动 agentic 循环——先 orient（read_profile_summary），强制歧义检查（find_similar_entities），再按需取证据，最后提交**四个门控终态之一**（answer / update / clarify / abstain）。
这标志范式从"写时整理改写"转向"写时保真、读时裁决"，与 #71 自组织、#77 处方性整理呼应：**整理应发生在读取侧或旁路，而非破坏写入侧溯源**。

## 三、具体实现方案（对应·技术现状 + 技术竞争力）
- **写入保真 ≠ 写入闸门**（#1）：闸门管"放不放行"，保真管"放行后绝不合并/丢弃"——两个正交轴。
- **旁路整理**：MIRIX-2.0（11-09）用溯源超图（n-ary frames 引用原行）+ AutoDream 在**写路径之外**合并重复锚点、不重写任何记录，正是"保真写入"的工程实现。
- **读取裁决四终态**：EarnedAbstainGate 仅在"确证缺失"时拒答；DeclineRouter 在仍有混淆候选时转 CLARIFY、无候选才 ABSTAIN；citation-or-abstain 要求每个答案引用证据。这补齐 #75 反噬的对称面——不是"用对"，而是"不足时选择不下注"。
- **五项目断层（竞争力）**：OpenViking（后台提取 add/edit/delete，validator 改写）、Hy-Memory（30B 写入模型做去重合并）、TencentDB（L0→L3 蒸馏合并）、dsh（五轨提炼）、ReMe（wikilink 文档相对追加友好）普遍"写入即改写"，**零双时态溯源、零读取裁决、零拒答口径**——倒挂延续（接 #56/#69/#73/#74/#75）。
- **评测口径**：DISCERN 实体分辨 0.800 vs 基线 ≤0.40、拒答 F1 0.924 vs ≤0.802、LoCoMo 宏观 0.663 vs 0.638；AML 实时榜仍按 A/B/G（召回/治理/执行）排，**缺 resolution / abstention 维度**（接 #56）。

## 四、四维速览
- **发展趋势**：persistent memory 的竞争焦点从 retrieval ranking 转向 preservation↔resolution 的分工（DISCERN 核心主张）。
- **技术现状**：2026-11 连续两篇实证——DISCERN（NeurIPS）把"召回饱和"论坐实，MIRIX-2.0 给出"写路外合并"的可行实现。
- **技术竞争力**：DISCERN 是唯一"既准又可校准拒答"的系统；各基线以牺牲一轴换另一轴，它不。
- **技术挑战**：写入侧合并惯性难改、双时态溯源的存储/重建成本、拒答误杀（false-decline 0.029 仍有）、跨项目零 resolution 口径。

## 本期新观点
① 范式拐点：召回已饱和，"分辨力"取代"记忆力"成为记忆系统新护城河；② 写入保真是独立于写入闸门的一等 SLA——严格追加双时态溯源，合并/去重一律移到读取侧或旁路（MIRIX AutoDream 范式）；③ 拒答（abstain）是与 answer 对等的门控终态，是 #75 反噬的对称性安全兜底；④ 读取裁决须零-LLM 工具面 + 强制歧义检查 + 引用约束，与 #73 多形态拼装互补（彼管"检索→执行"表示，此管"多候选/时态冲突时怎么选"）；⑤ AML 须补 resolution / abstention 维度，否则继续误判"谁的记忆更好"。
