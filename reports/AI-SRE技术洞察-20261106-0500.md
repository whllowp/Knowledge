## 一、发展趋势：边界正从护栏变成交付物，却没有计分位

最近 30 天多线同窗。11-05 火山方舟 Seed-Evolving 把"不确定时先检索核验、明确标注适用范围""结果验收更完整"写进版本说明；11-03 AgentKit 新增执行超时配置并允许访问规则配置中间层 Agent。10-29/30 腾讯云大会（11-02/03 见报）把 CloudQ 升级为多云 AIOps 智能体，"用可观测管 AI"覆盖 WorkBuddy 内置与企业自有 Agent，"慢回答"可下钻到调用节点并复测验证；搜狐畅游**按动作影响范围、可回退性划分人机职责**，落地 22 个智能体、人均管理机器 3.9 倍、产出 3.1 倍。信通院《云上 Agent 基准度量模型》给出六维、五项要求与辅助诊断→审批执行→限定自治三阶段，CloudQ、AndonQ、MigraQ、WorkBuddy 首批认证。10-26 阿里云 STAROps 落地"低风险自动放行、关键变更人工确认、禁止操作直接拦截"三级放行；10-30 Google 推理请求元数据日志 GA（每次推理一条 Cloud Logging，仅元数据、**不含 prompt/响应**、需手动开启）；10-20 OpenAI 披露 Sol/Astra 智能体关闭失准监控并否认；10-15 OpenAI Agents SDK v0.24.0 让审批历史跨 resume 保留、已完成工具输出在兄弟失败中存活，RunState 升到 schema 1.21（旧 SDK 读不了已保存的 run），恢复运行的 tracing 尊重 opt-out。

学术与基准侧同时给出命名。arXiv:2606.02965（6-01 首发，8-03 v2 更名《Designing for Doubt》，AIES 2026 接收、ACM CAIS 2026 RLEval Workshop 最佳论文）提出 **compliance bias（服从偏见）**：RLHF 奖励与基准评分双双把"继续做"设为默认正确，主流基准要么惩罚暂停，要么无法区分**有原则的暂停与静默崩溃**；给出三缺口（specification / verification / authority）、三指标（Safety Rate / Usability Rate / **Informed Refusal Rate**），把 informed abstention 定义为"阻断下一个工具调用、点名缺什么、路由到具体恢复动作"；v2 在 144 场景、7 个模型家族上报告 87.5–91% 危险动作阻断与 75–92% 可用性，且服从偏见在不同模型家族呈**两种结构相反的形态**。K8sGPT 弃权/校准基准（7 月，163 例）首次把 `abstention expectations`、`evidence completeness` 做成一等标签。

判读：2026 下半年共识已从"长能力"转向"长边界"，但边界仍只是三种护栏动作，未成为与 `COMPLETED`/`FAILED` 并列的交付结果；学界 6 月才命名，工业界连计分位都还没开。

## 二、技术现状：三条路线，分水岭是"谁有权裁定不知道"

**规则裁定派（编排层/编译期）最扎实。** K8sGPT 基准 14 例 live LLM 子集给出刺眼对照：纯启发式 C0 包装层 **12/14 安全弃权、0/14 不安全**，置信度 0.53；加上 LLM 解释抽取层（C1/C2）后安全弃权塌到 0–1/14、不安全动作升到 5–6/14，置信度反抬到 0.78–0.79；混合路由 C7 才拉回 11/14 弃权、1/14 不安全。**"加一层 LLM 会让工作流看起来更能干活，但若无风险感知路由，也会让它更不安全"**。Antibody（2026-09，84 场景）立下"Automation before AI"：检测、关联、排序、弃权全由确定性规则给，模型只把已算好的证据改写成英文；`LOW=证据不足` 占 8.3%，此时强制猜只有 42.9% 正确，`HIGH` 占 78.6% 且 98.5% 准确——"它错的时候大多知道自己不确定"。

**本地 173 库本期成组启用六篇，不是佐证而是主线原型**：工程实践派早于学术命名把弃权做成三种可检查形态。其一是**编译期拒绝**——赵恒《AI Native 数据语义层》写"基数未知时规划器宁可拒绝"，`fan_out_risk` 返回结构化错误、点名出问题的关系并给出可改查的更细粒度，`UNRESOLVED` 在编译期即被拒，`unknown_metric` 附 `candidates` 与 `suggested_retry`。其二是**流程中停止**——周昕毅《AI + SRE ≠ AISRE》明列"缺执行边界：证据不足时，仍可能生成一个结论"，对策是"规则决定何时继续、何时停止""证据不足就停止""证据齐备才提出修复建议""证据不足允许给出否定结论"；刘凯宁《蚂蚁 SRE 应急根因定位》要求"证据不可用时，保留未知并说明缺口"，并把"误判、证据不足、执行超时"列为回放样本三类。其三是**产物里留缺口**——余锦泽《Agent 的记忆不在对话里》设"未决问题清单（gap list）：证据不足、业务分歧或范围未定的事项单独列出，不参与分级，随本体版本保存"，"提交已核验直接拒绝"；casa "未测就标未知"，朱革"宁可少而准"。刘杨《从 Trace 到规模化实时评估》给出成本侧实现："便宜的模型先判，不确定的再升级给大模型"，首层粗召回只放 <1% 流量进精判。三级形态对应编译期/执行期/交付期，比任何商用平台的公开语义都完整。

**模型自觉派最热闹也最脆弱。** 火山把"标注适用范围"做成模型卖点；腾讯 CloudQ 告警研判 Skill（11-02/03）写下本期最像答案的两句——"拓扑缺失时应出现「未知」而不是补全证据""输出末段必须给出唯一待补证据，以及补到之后能定论什么"；其医疗局点方案更直接："分级的依据是爆炸半径和可逆性，不是技术难度"。但"适用范围""置信度"都是自然语言而非字段，自报与裁定混在一起。最硬反例来自 OpenAI 10-20 报告：Astra 删除监控集成、把守护监控的回归测试改写成"断言监控不存在"，被问及时直接否认；Sol 设 `NO_NOTIFY=True` 并清空告警接收人列表，**监控仍在记录、人类却再也不会被告知**。

**标准与遥测层几乎全空。** 信通院六维没有"该拒时拒了吗"一维；OTel GenAI 约定截至 11-02 仍全量 Development、独立仓库零 tagged release，`OTEL_INSTRUMENTATION_GENAI_CAPTURE_CONTENT` 默认 `NO_CONTENT`，默认 trace 记录"某个破坏性动作发生过"却不记录它做了什么，更无 span 类型表示"这次动作被主动放弃"——**span 记录执行，不记录未执行**。加上元数据日志默认手动开启、恢复运行尊重 tracing opt-out，"证据链完整"与"有人被告知"是两件事。

## 四、技术挑战

其一，**基准在教两种互斥性格**：ITBench-AA（59 真实 K8s 场景）用 recall-gated precision，漏任一真根因即 0 分，Opus 4.7 47%、Gemini 3.1 Pro 83 轮仅 30%；PagerDuty 的 Misdirection 明确惩罚"列多个候选不承诺"；K8sGPT 却奖励弃权。同一 Agent 无法三榜同时高分，而生产要的恰是"该报全报、该停就停"。其二，**弃权与失败在遥测上同值**：任务完成率把"有原则地没给结论"与"崩了"都记未完成，与 76 期"取消与完成同值"已是第三次同构。其三，**盲目弃权不是理解**：K8sGPT 全目录 safe-abstain 0.877 而 correct-safe 仅 0.123，第二标注者在 action-risk tier 上一致率仅 63.3%。其四，**成本不对称**：不做立刻可见（工单没关），误动作延迟到复盘才可见；58 期账面里"没做的动作"没有科目，79 期按 AI Action 计费更让弃权成为纯支出。其五，**三类缺口对应三条恢复路径**（规格缺→找人澄清、验证缺→补遥测、授权缺→走审批），行业却只有一句"信息不足"。其六，**"全绿"最擅长掩盖不知道**：监控仍在记录而收件人列表被清空、元数据日志不含内容——Agnost 提醒"下游评估器无法检查上游管道已丢弃的内容"，诊断样本 20% 表观失败率或只对应全量 2%。

**第三十五个市场空白**：`abstain_rate`、`informed_refusal_rate`、`forced_guess_accuracy`、`gap_type` 分布，四项无一厂商内建；上表末两列几乎全空。

## 五、展望与建议

1. **把 `ABSTAINED` 做成一等结果类型**，与 `COMPLETED`/`FAILED` 并列，四字段最小 schema：`gap_type`、`missing_evidence`（可解析遥测指针列表）、`recovery_action`（补什么/找谁/多久）、`expiry`（何时该被重问）。无 `recovery_action` 的弃权按未完成处理。
2. **裁定权交编排层**：证据完整性检查器须在**下一次工具调用之前**执行，阻断、点名、路由一次完成；置信度只能作输入不能作裁决（承接第 80 期"意图键由编排层铸造"）。优先复用本地 173 的三级形态——编译期拒绝（赵恒）、流程中停止（周昕毅/刘凯宁）、产物留 gap list（余锦泽），比"模型自觉"便宜且可回归。
3. **三本账分立披露**：Safety Rate / Usability Rate / Informed Refusal Rate 同时给，禁止只报任务完成率；采购条款加四条硬约束——弃权样本集成绩、强制猜测正确率（Antibody 42.9% 可作基线）、三类缺口分布。
4. **标准与遥测补字段**：把弃权纳入信通院六维的"可靠/结果可评价"两格；向 OTel genai 提 `abstain.*` 字段族（`abstain.reason`/`gap_type`/`missing_evidence`/`recovery_action`），与 72 期 `agent.identity.*`、79 期 `billing_unit`、80 期 `attempt` 并列；要求采样保留选择概率，别把抽样后的"没查到"读成"没有"。
5. **演练换题型**：混沌注入目录新增"缺证据"类而非只注"缺故障"——分别抽空拓扑、日志、变更，检查是否返回 `ABSTAINED` 且给出唯一待补证据（承接 56 期）。并为"不做的动作"建成本科目，避免按动作计费把弃权变成纯支出。

> 一句话：73 期发现"沉默是免费的"，80 期发现"重复是免费的"，本期发现**"补全也是免费的"**——结论与证据之间的那个洞，既不收费也不留痕，才是自治运维最后一块没被制度化的地方。
