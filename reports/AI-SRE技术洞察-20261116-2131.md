# AI-SRE 技术洞察（第 231 期）

**生成时间**：2026-11-16 21:31（北京时间）｜**窗口**：2026 年，重点最近 30 天
**本期主题**：问责面／责任链（Accountability）——出了事，责任落在模型、平台、还是用它的人？

---

## 题记

11-16，一家行业媒体的周盘点写了一句很少被工程文章采用的话：**「AI 能力跑在问责机制前面」**——同一周里出现了**航空管制故障、数据泄露、企业收紧 Agent 权限**，作者呼吁建立**可追溯的自动化问责体系**。146 期说「Agent 没有主人就没人养老送终」，125 期说「99.99% 赔不了答错」，166 期说「说过不等于能证明说过」，189 期说「这句话从哪来」，199 期说「这个动作以谁的名义」。这五件事在**出事后**合成一个最难回答的问题：**责任落在谁头上？** **模型供应商说「我们只提供权重」，平台说「我们只提供运行时」，业务说「我们只按输出办事」——三方都没撒谎，但三方都没负责。** **「都合规」和「有人负责」是两件事。**

## 一、发展趋势

**趋势一：从「谁开发」转向「谁签字」。** 每个 Agent 一个具名责任人；**不是团队，是人**（146 期）。

**趋势二：从「日志」转向「责任链证据」。** 决策、动作、效果、审批；**每跳都要能对上**（189 期）。

**趋势三：合同开始写「责任分配」。** 谁承担错误修复、谁承担赔付；**不写就默认没人**（125 期）。**合同是最后的责任链，也是最容易被跳过的一环。**

## 二、技术现状：三方责任，通常无人认领

**模型方：提供权重。** 不保证输出；**"模型行为不可预测"是免责声明**。

**平台方：提供运行时。** 不审业务；**"我们只保证跑起来"**。

**使用方：按输出办事。** 不写代码；**"是它自己做的"**。

**现状：责任在接口处蒸发。** 三方各自合规；**合起来没人负责**。

**三种免责，一种比一种像理由。** 「模型不可预测」「平台只保证跑起来」「是它自己做的」；**三种都成立，三种都不担责**。

## 四、技术挑战

**一，责任扩散。** 三方都有份；**结果谁都不认**。

**二，模型方不透明。** 权重/版本/行为；**外部无法验证**（157 期）。

**三，日志不等于责任链。** 记了「调用了」；**没记「谁批的」**（166 期）。

**四，监管口径未定。** 各国要求不同；**跨境更乱**（140 期）。

**五，举证成本高。** 一次事故拼证据；**要跨五个系统**（189 期）。

**六，人是最后一道。** 具名责任人；**但他可能根本不懂 Agent**（177 期）。

**七，保险不保「答错」。** 只保宕机/数据泄露；**答错的损失没人兜**（125 期）。

## 五、需求分解、用户旅程与实现方案

### 5.1 需求（按优先级）

- **R1 `accountable.*` 字段**：`agent_id`、`named_owner`、`decision_ref`、`action_ref`、`effect_ref`、`approver`、`liability_party`。
- **R2 具名责任人**：一个名字；**进注册表**（146 期）。
- **R3 责任链证据**：决策→动作→效果→审批；**四跳可追**（189 期）。
- **R4 三方分工表**：模型/平台/使用方；**各写边界**（125 期）。
- **R5 合同条款**：错误修复、赔付、停用权；**写清**（125 期）。
- **R6 指标**：具名责任人覆盖率、责任链完整率、举证时延、合同条款覆盖率。

### 5.2 用户旅程

- **SRE**：事故 → 拉责任链 → 定位到决策/动作/审批 → 分配 → 记录举证时延。
- **法务**：按合同分工 → 找对应方 → 索赔。
- **审计**：抽查一次损害 → 四跳证据齐全 → 出具报告。
- **责任人**：季度确认自己名下 Agent → 更新范围。

### 5.3 实现方案（90 天）

- **0–30 天：具名。** 每 Agent 一个责任人；登记。
- **30–60 天：链条。** 四跳证据；跨系统关联。
- **60–90 天：合同。** 三方分工；赔付与停用权；保险条款核对。

**第 162 个市场空白（五项）**：具名责任人覆盖率、责任链完整率、三方分工清晰率、合同责任条款率、举证时延达标率——无一内建；`accountable.*`／`liability.*` 为**第 128 次无人提字段族**。本地 173／173-kb 连续第 118 期成组启用：周昕毅 10「白名单动作、危险动作需审批」＝全库唯一把「动作放行」写成硬规则的实践，本期首次当主线；配 146 期属主、189 期血缘。判词：**本地把动作放行写成白名单，联网侧 2026 年才说「AI 能力跑在问责前面」；两边都没把「这次损害该谁承担」做成登记字段。**
