- 核心框架（本系列长期使用）：
  - **记忆三权**：准入权（admission，谁决定值得记）/ 一致性权（consistency，冲突谁裁决）/ 授权权（authority，"记录"与"执行许可"是两份凭证）
  - **三轨不可能三角**：文件轨（可审计）/ 分层轨（可治理）/ 参数轨（写入质量）不可同时最优
  - **记忆即账本（ledger）而非数据库**：append-only、追加更正、逐条溯源、可冲正

- 判读：美国平台在开发者体验领先、国内三家在写入治理领先；参数轨仅腾讯一家（唯一把写入质量与框架解耦，可能催生"控制面/数据面"分离）；记忆开始按"条·小时"计费（持有成本出现）

## 第 2 期（2026-11-06 04:00）· 记忆的负空间——当"忘掉"成为必须被证明的事

- 产物：`记忆技术洞察-20261106-0400.md`（正文 3,003 汉字；五章 + 8 方案六维对比表 + 26 条来源）
- 与第 1 期的关系：第 1 期主线"写入侧独立化"只解决了"写得更准"。本期接续处理其必然引出的下一问——**写进去的东西，怎么证明它已不在**。不重复写入侧结论，转向负空间（失格 / 注销 / 举证）。
- 主线：**删除的三层语义**（L1 摘除 de-index / L2 擦除 purge / L3 卸载 unlearn）与"三轨"正交成 3×3 可行性格局；核心判断是**参数轨写入最强、注销完全失能**，属合规死路而非技术债。
- 新框架（本系列第二批长期工具）：
  - **记忆生命周期四态**：写入 → 生效 → 失格 → 注销。主流系统只实现前两态。
  - **注销三×三矩阵**（轨 × 删除层），见报告正文。
  - **墓碑优先于硬删**：`valid_from` / `valid_until` / `superseded_by` 三字段为"失效可判定 + 删除可举证"的共同前提。
  - **主权拆列**：把第 1 期的"治理与权限"拆为"权限（谁能读）"与"注销（谁能让它不存在）"两种独立权力。
- 时点事实（30 天窗口）：MemHarmBench arXiv:2611.01700（11-01，规则留存 59.38–76.39%，55.71% 无异常）、Auditable Unlearning arXiv:2611.05866（11-04，11 种方法无人满足四轴）、PINT arXiv:2611.03955（11-02，毒样本遗忘后仍可统计检出）；AML 二期 10-31 封榜 / 11-04 关队列 / 结果 11 月中，Coding 轨 150 任务 ×（相关+噪声）=300 次计分。
- 三个本期首见的结构性事实（已入台账）：①OpenViking peer = git identity（origin URL 归一化），作用域下沉到代码身份；②TencentDB GitHub 许可证标注 NOASSERTION；③DSH 生态 20+ 记忆插件共用一个 `sessionQuery` + unicode61 中分缺陷，中文召回被同一地基 bug 拖累；④两个项目同名 dsh-memory-evolve（205★ vs 606★）。
- 判读：竞争空位 = "Zep 的双时序（显式墓碑）+ ReMe 的 diff 可举证"从未在同一系统出现；谁会先产品化"删除举证 API"谁拿合规优势。
