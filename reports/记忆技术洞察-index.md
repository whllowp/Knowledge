## 本期新增（第 72 期，20261113-0400）
- 主题：记忆的状态化坍缩——把历史递推成可决策的小状态，越过 reader-dependent horizon 后显式状态胜过长上下文（挑战"记忆=可检索上下文"前提，承接第 70 期条件效用、第 71 期自组织）
- 新观点：①存在一个 reader-dependent horizon，256 事件后长上下文把 7–32B 从 72–86% 拖到 48–55%、读状态推理模型达 96–98%（arXiv 2611.02361，11-02）；②"该记什么"应在写入时按状态依赖筛选（write-time dependency filtering），query-time 检索反不如它；③记忆系统本质受速率限制（rate-limited）的递推滤波器，遗忘是滤波器的自然行为（重写第 19 期代谢）；④深化第 1 期写入闸门：闸门判"是否属于某可递推状态的依赖集"；⑤六家仅 Hy-Memory 30B 写入模型/TencentDB 决策服务把"写"做成决策，但无状态依赖筛选，倒挂延续；⑥AML Cycle 2 开放但七维度无"状态坍缩率"计量（接第 56/69 期）。
- 台账新增：六之四十三（状态化坍缩）+ 待验证 315–319。

## 上期新增（第 71 期，20261113-0300）
- 主题：记忆的自组织（Self-Organized Memory）——当记忆系统自己决定怎么整理自己（结构自组织权，第六项记忆主权）
- 新观点：①记忆 schema 由设计师冻结→应转为 agent 可学习的"结构自组织权"（继写入闸门/删除/可寻址/内省/携带权后第六项）；②SoMem 用链接文档+回链证据+运行时校验反范式，弃"摘要即压缩"；③自组织把 #66 整理风险升级为"结构损失"（比压缩更难审计），链回证据+运行时校验=自组织下的安全（接 #60/#19）；④深化 #59 携带权：可携带的不只是内容还有结构；⑤AML 无 schema-evolution 维度，治理缺口延续（接 #56/#69）；⑥六家产品零结构自组织披露，倒挂延续。
- 台账新增：六之四十二（自组织）+ 待验证 310–314。
