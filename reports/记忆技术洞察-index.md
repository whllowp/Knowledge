## 本期新增（第 127 期，20261120-0400）
- 主题：记忆的「不确定性传承」（uncertainty handoff）——上游把结论交给下游时若只传答案、不传"还可能有别的答案"，暂定假设就被当成事实一路传下去。11-19 LProp（arXiv 2611.23564，圣母大学 Kaiwen Shi 等 6 人，cs.AI）把不确定性做成可携带、可随新证据改写的潜在载体：既不像标量分数那样丢掉供修订的备择，也不像文本反思那样越传越贵。前 126 期把置信度当单条记忆的属性（#65 信念化校准），本期问的是"交接时这份不确定性保不保真、改不改得动"。与 #65（单条静态校准）划界：那期管一条记忆信不信，本期管判断交接时备择与支撑分布能否被下游证据改写。与 #115（带进度证据）/#94（判得准不准）划界——本期管判错后能否被纠正。
- 新观点：①不确定性是"可修订的传承载荷"不是标量附注（深化 #65：从单条静态校准到跨步保真与改写）——标量丢备择、文本反思涨成本，隐藏态潜在载体是第三选项；②"估风险"与"改信念"是两件事（接 #94/#75）——SAUP/TRACER/UProp 只聚合风险、AUQ 靠文本反思，风险高不等于知道改成什么，本期把修订做成一等机制；③继承内容本身就是纠错资源（匹配消融）——潜在内容贡献独立于答案概率与模型容量，冻结内容多救回也多引入回归故须选择性修订，接 #114 误删/误留非对称；④传承成本要算"载体税"而非只算 token（深化 #5/#122/#124）——省 61–71% token 的代价是隐藏态访问、载体存储与学习更新，token 省≠时延省；⑤不确定性应随证据先升后降（反直觉，接 #65/#95）——8.44%→23.07%→12.68%：旧高置信被松动先升、确认后降，单调下降的置信反而掩盖修订；⑥五项目倒挂＋AML 补 uncertainty-handoff 维度——OpenViking v0.5.5（11-19 子包更新）／Hy-Memory 2.0.16＋MemHub v1.0.7／TencentDB v2.0.4／dsh v26092802／ReMe v0.4.2.3 零跨步潜在载体、零证据条件修订、零继承内容保真；补传承风险 AUROC／纠错率与回归率分账／每问 token 三维，以"能否被下游纠正"验收而非单次答对率。硬指标：BoolQ Qwen3-8B F1 0.763(SAUP)/0.787(UProp)/0.748(AUQ)→0.831、AUROC 0.796；Mistral-7B 的 MMLU F1 0.468→0.589；八设定 F1 全最高、token 全最低，较 AUQ 省 61.2%／较 UProp 省 71.1%；36 个拒答点 35 个保留答案正确率高于 AUQ；案例初稿 D 91.56%→推导后 B 76.93%→复核后 87.32%，不确定性 8.44%→23.07%→12.68%。反证：依赖骨干隐藏态与答案分数、纯文本接口不可用、载体绑骨干表示换模型要重训、token 省≠时延省、四基准非真实长对话，不外推。

## 上期新增（第 126 期，20261120-0300）
- 主题：记忆的「凭证可迁移性」（warrant portability）——昨天跑通的技能，今天可执行不等于今天有理由复用。11-18 SCAFFOLD（arXiv 2611.23990，Columbia＋CMU，Nami Cho／Shailja Gupta，cs.AI／cs.MA／cs.SE）把信任单位从"技能的历史成绩"换成"针对某次目标调用、可撤回的保证主张"：证据须逐条判断换场景后能否作证。前 125 期都问"这条记忆有没有用、还新不新"（#95／#113／#114），本期问"当初证明它有用的那份证据，换了上下文还能不能作证"。与 #114 划界（那问何时删，本期问旧证据何时仍能作证）、与 #118 划界（那管反馈扩散多远，本期管证据对哪条主张仍成立）。
- 新观点：①信任单位从"历史成绩"改为"逐次调用的可撤回保证主张"（接 #95／#114 划界）——WRC=⟨s,c,φ,E,A,D⟩ 绑版本化技能、九维目标上下文、时间戳证据账本、假设与反驳项，不是永久标签。②证据可采信≠主张为真且必须有第三态（深化 #95 undetermined 到证据层）——App∈{1,0,?}，未知不是支持；失败证据单列反驳项，防靠过滤隐藏不利证据。③监控通过≠目标达成（深化 #94 评判偏差到预言机缺失）——C(τ)=1⇏G(τ)=1，测试只覆盖可观察契约条款、缺结果预言机、评估继承同一错误规格。④同一证据按主张分流、迁移非对称（深化 #118 作用域）——schema 证据可留、金额政策证据必废，只读验证不授权写权限；保留命题五条件中"R 完备"是未证重担。⑤独立通过未必独立（接 #88／#105）——一个模型写技能、推规格、造样例又判样例，多份有利证据共享同一错误解释，有效样本 n/[1+(n−1)ρ]。⑥五项目倒挂＋AML 补 warrant-portability 维度——OpenViking v0.5.5（11-19 子包更新）／Hy-Memory 2.0.16＋MemHub v1.0.7／TencentDB v2.0.4（11-19）／dsh v26092802／ReMe v0.4.2.3（11-17）零凭证迁移、零三值可采信、零反驳项账本；补可采信率／反驳项命中率／误放行率／选择性重验成本。硬指标：12 项义务四族只改税务依赖，留九重三，节省 9k−h 仅当 h<9k 为正；退款案例中 schema 保留、≤$100 对 $150 失效、"无需审批"在 v2 新地区失效、跨法域结算未决。反证：8 页立场论文、无实验、R 完备性未证、强版本感知契约／增量保障基线获同一依赖图可能打平，不作已验证结论外推。

## 上上期新增（第 125 期，20261120-0200）
- 主题：记忆的「元记忆对齐」（metamemory alignment）——前 124 期都站 agent 一侧追问"存什么/取哪条/读多少/看多清"，11-18 MemoSync（arXiv 2611.24165，港科大＋北大＋中科院软件所，Baiqiao Zhang 等 9 人，cs.HC/cs.SE）换到开发者一侧：真正卡住长程协作的不是记忆算法，而是人对"该记什么"的元层判断与 agent 存/取/用的对象层操作被人机边界劈成两半，监控与控制两条回路都断了。把对齐从"系统侧检索质量"重定义为关系属性：开发者心智模型 vs agent 真实记忆状态的一致度。与 #117 划界（那问 agent 有没有用一个规则，本期问人知不知道它存了什么/用了哪条/是否生效）、与 #106 划界（那是治理价值可观测化，这是监控—控制回路本身）。
- 新观点：①对齐是关系属性非系统属性（接 #106/#117 划界）——评测须报"开发者心智模型 vs agent 真实状态"一致度，与检索质量正交。②瓶颈是监控而非控制（反直觉，深化 #117）——N=123 中介显示对齐优势主要经监控准确率（对 Static +20.2pp，CI[9.18,30.63]），经控制准确率间接效应不显著（−1.14/−0.67）；监控动作 70.3 次（Auto 7.3／Static 8.7，IRR≈9.6/8.1）、控制 25.3 次（＜1，IRR 30–101×），但"看见"比"操作"更驱动对齐。③影响审计必须独立于 agent 自报（深化 #94/#105）——agent 会声称遵循却违反，须独立分叉分支逐条判 violated/shaped/not applicable/no visible effect。④感知—实际应用差距可量化（深化 #117/#120）——1–5 分量表 MemoSync 0.19 对 Auto 0.42／Static 0.38 不到一半，"以为用了 vs 真用了"落差本身是一等指标。⑤scope 是记忆迁移的一等字段（深化 #101）——跨项目"抽象→本地化→三形态留审"，项目边界 MemoSync scope 对齐 68.0% 只胜 Static 未胜 Auto（两项目同栈），反证范围机制价值取决于上下文差异度。⑥五项目倒挂＋AML 补 metamemory 维度——TencentDB v2.0.4（11-18，会话逐调用记录＋L0–L3 分阶段日志）是可观测性一步，但五家仍零人机共管；补内容对齐／scope 对齐／监控准确率／感知—应用差距／控制精确率五维。硬指标：N=132 组间，内容对齐 88.0%(SD13.9)＞Auto 77.6%(p=.002)＞Static 66.2%(p<.001，H(2)=35.86,ε²=.26)；任务完成度 59.8%＞Static 51.1%＞Auto 47.7%(H(2)=35.57,p<.001)；末会话 P2S1→P2S2 MemoSync +3.8pp 而 Auto −9.3pp(p=.010)。反证：单论文、两项目同栈、scope 边界差不显著、抽取依赖模型、仅个人非群体记忆、无法拆分单机制贡献，不作外推。

## 上上上期新增（第 124 期，20261120-0000）
- 主题：记忆的「感知保真度」（memory perception）——记忆不只决定"取哪条"（#109）、"读多少"（#122）、"以什么形态存"（#121），还决定"每条以多清晰被看见"：把历史渲染成图，按其对下一步决策的相关度逐条调分辨率，视觉 token 随分辨率平方下降，省一半 token 而决策不变。前 123 期把记忆拆成检索（取哪条、排第几）与压缩（留多少、带什么），共同预设"进上下文的内容以同样清晰度被读"；11-18 RAA: Resolution as Attention（arXiv 2611.24422，NTU＋阿里，Siqi Xiang 等 6 人，cs.AI/CV）立起第三维：感知保真度——每条历史被"看多清"可独立、随任务演进地调。与 #122 划界（那是同一来源内读整段还是读一句的文本粒度取舍，这是跨所有交互按决策相关度分配像素分辨率）；与 #121 划界（那管以什么形态存，这管以什么保真度被看见）。
- 新观点：①记忆的第三维"感知保真度"（接 #109/#121/#122 划界）——检索管取哪条、压缩管留多少，本期管每条以多清晰被看见，正交于二者的独立维度。②分辨率即注意力（深化人类视觉的精度分配）——把抽象 attention 权重落成可读的像素比例，各条独立、随决策演进，不设全局预算（与 softmax 固定总权重相反，决策前不知需多少信息）。③连续感知胜过离散删词（深化 #122）——等预算文本裁剪多走 14% 步、token 反增 33%、分低 0.97，因文本删词丢精确值不可恢复，图像分辨率可平滑调节。④"看多清"要学且与语义相似不同（接 #94）——语义相似度≠决策相关度，须教师标注＋决策一致性强化学习两阶段才校准分辨率分布（未训练中位 scale 0.98 近乎全清、只监督压到<0.5 看不清、只 RL 分不出，合用最优）。⑤省 token ≠ 省时间、收益落在 KV cache（深化 #122/#5）——token ↓57.5% 而端到端 326s 仅慢 4.3%（估计＋渲染占 2.51%），价值在峰值 KV cache ↓47.8% 非墙钟，记忆税须按 decode/KV 分账。⑥五项目倒挂＋AML 补 perception 维度——五家（OpenViking v0.5.5／Hy-Memory 2.0.16＋MemHub v1.0.7／TencentDB v2.0.3／dsh v26092802／ReMe v0.4.2.3，本期无新版本）全做文本/结构化条目取或压、零自适应感知保真度、零非破坏可重入清晰度，打开"存—取—感"三分的新评测空位。硬指标：ClawGym-Bench 三骨干（Qwen-3.8-27B 训练、Qwen-3.6-27B 与 Kimi-K3 未见），Qwen-3.8 每任务 token 89733→38169（↓57.5%）峰值 12561→6447、分 78.23→78.69 反升，两未见骨干 ↓51.5%／↓55.9% 分不降；叠加 ACON／A-MEM／观察掩码再省 22.5%／44.7%／54.1% token。反证：单基准、三骨干、依赖 OCR、一致性似然目标不保正确，不作外推。

## 第 123 期新增（20261119-2300）
- 主题：记忆的「晋升门控」（promotion gate）——自进化记忆不缺"从失败里长出经验"，缺的是"经验何时够格晋升为常驻规则"：微记忆（逐条纠错、可检索）经留出集准确率门才转成 ≤K 条常驻宏规则，默认拒绝、证据够了才升。前 122 期谈经验自进化都在"怎么生成"（#89 写时证伪管单条经验准入、#119 演化策略发现管用哪个算子改结构），默认"生成即入库"；11-17 ARISE（arXiv 2611.23588，Amazon 15 人，cs.AI/MA）换问一层：经验→规则这一步此前无人设门。与 #89 划界（那是单条经验写入判据，本期是经验→规则的晋升判据）；与 #104 划界（那是知识退场门，这是入场门）。
- 新观点：①晋升是独立于写入的一等门（接 #1/#89 划界）——准入判据从"单条经验可证伪"推进到"整组规则须在留出集严格转正"，宏门 Acc_v(R*)>Acc_v(R)+ε_m、ε_m=max(2pp,50/|D_val|) 把统计置信度写进门（深化 #56/#94，小样本"涨一点"不算数）；②默认拒绝即自进化常态（补 #119/#104 的"不改"侧）——32% 训练轮次零晋升、91.5% 第 3 轮后不再接受、规则集平均仅 3.4 条，记忆价值不在长多少而在挡住多少伪晋升；③双层是"原料—产品"非并行通道（深化 #107/#121）——微记忆仅 +0.7pp（87.4 对 86.7，修 186 破 118）、宏规则扛 10.2pp，经验层退化为规则归纳的训练数据，但产物是可逐条审阅文本而非黑箱权重；④准确率门 ≠ 安全门（深化 #105/#54）——唯一准入标准把安全/策略检查外置、微门跨不同任务集比无法隔离微检索净效（作者自陈），是五项目共同盲区；⑤教师是可选加速非必需（接 #84/#96）——ARISE-Self 自归因全模型 +8.4pp、距 Teacher 仅 1.4pp，强教师只在跨轮工具场景多值 3.2pp（SOP +0.9／τ +3.2）；⑥准确率与成本同向、晋升不增记忆税（深化 #5）——服务侧 −4.0% 调用／−5.2% token／−1.0% 成本，适配 $17.46/域·模型≈322 SOP 任务、复用回本点可算。硬指标：14 域 5 模型（Opus 4.6/Sonnet 4.6/Haiku 4.5/DeepSeek v3.2/Qwen3-32B），ARISE-Teacher SOP 87.4／τ 62.3（+10.9／+5.8pp 对基线、+1.4／+4.5pp 对 GEPA），ARISE-Self +10.0pp；τ 四项 pass^4 电信 44.5→60.7／零售 34.0→38.0／航空 41.0→44.3；纠错归因把条目 673→281 字符、检索时成本 −6.0%；20% 错标签仍保 7.2pp、仅 pass/fail 反馈 +3.1pp。反证：须可验证成败结果、部分模型×域回退、安全治理未评、单论文不作外推。

## 第 103 期新增（20261116-2200）
- 主题：记忆的「遗忘精确性」（forgetting precision）——执行了删除 ≠ 真的忘了 ≠ 只忘该忘的。前 102 期谈遗忘都停在存储侧（#74 遗忘保真度立"用户说删→系统真忘"为 SLA、#60 可逆性、LinEra 谱系密码擦除管派生记忆残留），默认删除是二值动作、执行即忘。本期把视角下沉到权重层：两篇 11-11 论文揭示遗忘的两种相反失败——"表面擦除、潜在仍在"（漏忘）与"误删未请求的敏感实体"（误忘），遗忘从"是否执行"升维为"双侧精确率"（真忘对目标 ∧ 未误伤非目标）。与 #74（存储残留）划界并深化，接 #94 评判者偏差（直接查询是被 gaming 的表面）、#68 栖居之争（权重可分离删除的物理上限）。
