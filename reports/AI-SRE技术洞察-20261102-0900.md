# AI-SRE 技术洞察（2026-11-02 09:00 期 · 总第 26 期）

## 本期主线：进化面运维——当 Agent 在生产中自我改写

前 25 期管过治理、结果、证据、人、记忆、供应链、路由与承诺，本期管一个更根本的问题：**系统不仅在被运维，还在被自己改写**。当智能体把经验写回记忆、改写自己的技能文件、甚至每天多次发布新权重时，"自进化"就从研究课题变成了一类新的运维对象。经验回写（experience write-back）应当被当作一等变更来管理——这是本期与第 22 期"记忆面运维"的分界：那期管"记什么"，本期管"怎么改、谁批准、怎么退"。

### 一、发展趋势

三条线在本月同窗聚拢。其一，学术界把自进化的瓶颈从算法转向系统：蚂蚁、清华与港科大 7 月发布的立场论文（arXiv 2607.01120）明确"自进化不等于盲改权重"，并指出缺的是三件基础设施——轨迹数据协议、全链路数据代理、演化控制平面；QCon 2026 上海站上，AReaL 2.0 作者袁彬航给出同构判断："企业级 Agent 自我进化的瓶颈，并非模型规模、提示词技巧或缺少新的强化学习算法，真正缺少的是支撑在线强化学习的系统底座。"其二，产品侧跨过了"文件自写"的门槛：Nous Research 的开源 Hermes Agent（10 月 12 日 25 万 star）默认在复杂任务结束后自动生成 SKILL.md 写进自己的技能目录，"无人审批"是出厂设置；Anthropic 的 Claude Managed Agents 10 月上旬为智能体配上内置跨会话记忆（文件形态、可导出、API 管理、带权限隔离与审计回滚），Rakuten 实测首轮错误率下降 97%。其三，最激进的一条线来自 Cursor：3 月起把在线强化学习接入生产，以真实用户交互为奖励信号，**每天多次**发布改进后的模型检查点——变更流速的竞争对象已经从代码（第 11 期）转移到权重本身。此外，记忆型强化学习路线（MemRL、JitRL）证明"冻结权重、只改记忆"也能持续进化：训练无关的运行时学习在 HLE 上达到 61.3%，ALFWorld 69.7% 较最强记忆基线提升 53%，JitRL 以非参数方式在部署时做策略优化、成本较微调路线降 30 倍以上。

### 二、技术现状

当前生产环境的"自进化"呈现清晰的四层形态。**第一层：文件即进化。** Hermes、Prime Agent（Continual Harness，arXiv 2605.09998）把提示词、技能、记忆、子智能体规格统统当作智能体可增删改查的状态；Prime Agent 在 ARC-AGI-3 上拿到 95.5%，超过人类专家基线 95.4%。**第二层：记忆即策略。** 温睦宁（上海交大）在 QCon 给出的 MemRL 架构把学习目标从"大脑参数"搬到"记忆效用值"，用意图-经验-效用三元组结构化经验池、蒙特卡洛式更新 Q 值；其衍生系统 EvoKernel 在昇腾算子生成上达到 80%+ 正确率——而今年 7 月该任务的公开 SOTA 仅 2.5%，说明垂域冷启动最缺的不是模型而是可回写的经验。**第三层：权重即流水线。** Cursor 的实时 RL 是唯一把权重更新做成"每日多班次"的公开案例；AReaL 2.0 则给出通往该形态的三支柱：ATDP 轨迹协议（观测/隐状态/动作/结果/奖励/元数据六元组，可审计、支持贡献归因）、跨框架数据代理（脱敏、持久化、确定性重放）、演化控制平面（按轨迹统计选择改记忆、技能、Harness、工具接口还是权重；每步设准入检查）。**第四层：门禁即科学。** 多租户平台 Scalably 的生产实验最有参考价值：他们先按直觉微调了一版 LoRA——目标行为确实变好，但干净决策的正确率从 49 降到 45，未能通过**预先注册的非劣性门禁**，被自己的门禁否决；转而采用"快慢双环"：快环只写可归因、可回滚的记忆规则（当前维护 433 条规则、经溯源日志退役 37 条），慢环只消化反复验证的模式。结论朴素而锋利：**生产样本量下，单次权重更新的收益与损失无法被廉价区分，也无法被分别回滚。**

### 三、技术竞争力

| 方案 | 进化对象 | 反馈来源 | 门禁与回滚 | 人类角色 |
|---|---|---|---|---|
| AReaL 2.0（蚂蚁/清华/港科大） | 记忆/技能/Harness/工具/权重五分支 | ATDP 标准化轨迹 | 演化控制平面，准入检查；回滚是常规动作 | 设计控制平面 |
| Cursor 实时 RL | 模型权重 | 真实用户交互 | 生产灰度、每日多检查点 | 消费侧隐式投票 |
| Claude Managed Agents 记忆层 | 跨会话记忆（文件） | 会话经验 | 可导出、API 管理、审计回滚 | 管理员审批 API 操作 |
| Hermes Agent | 自写 SKILL.md 与记忆 | 任务后自评 | **默认无人审批写** | 无（可选关闭） |
| Scalably 快慢双环 | 记忆规则（快）+ LoRA（慢） | 溯源日志、预注册评测 | 非劣性门禁、影子部署、规则退役 | 写门禁、批晋升 |
| MemRL/JitRL | 记忆效用值（冻结权重） | 环境奖励 | Q 值自然衰减、遗忘机制 | 无直接介入 |

判读有三。第一，**商业化程度与激进度成反比**：默认无人审批的 Hermes 最激进但非企业级；企业产品全部把"写"关在可审计的 API 后面。第二，**闭环无人真正打通**：独立分析（Ena Pragma）核验后确认，今天所有可验证的生产"自改进"全部有人类门控——Arize 的飞轮靠评测门禁晋升、Sierra 只给建议由人一键应用、Databricks 持续学习由人反馈驱动；而两个试图全闭环的产品，一个滞留私测且有企业客户公开承诺关闭自主路径，一个（TensorZero）已停止维护。第三，**国内路线押注记忆而非权重**：MemRL/温睦宁、快手经验召回（第 19 期）、阿里 Hologres 长记忆（第 22 期）共同构成"把学习搬到廉价记忆读写"的保守而务实的路径。

### 四、技术挑战

**反馈饥饿是第一瓶颈。** World Programming 对自家生产记忆引擎的实测（35.9 万概念图边、57 个真实租户）显示：被显式反馈触达的边占比，基准租户 94.8%，真实租户最好 12.8%、读多写少的租户仅 0.6%——智能体不停读记忆，却几乎从不回报"这条记忆帮上忙没有"。按三因子学习规则，没有结果信号门控，记忆图就在共现噪声上生长；更尴尬的是，Mem0 有反馈 API 但从未公布使用率，Anthropic 的记忆工具给了六个文件命令却没有打分命令——**全行业没有一个厂商公布其反馈通道的真实使用率**。第二，**文件即变更，却绕过了整条交付流水线**：合并一个 PR 有 diff、有评审、有检查、有版本；而智能体写下的 SKILL.md 下一次运行即被当作事实读入，"被修改于原处"。Hermes 式默认是 2026 年版的"直接改生产配置"。第三，**干预面选择仍未工程化**：立场论文的干预面映射（缺事实写记忆、路由错改工具 schema、流程错补技能、规则失守收紧护栏、跨任务持续失败才动权重）被公认为最实用的设计，但截至 10 月，AReaL 2.0 只实现了权重分支，控制平面还是"带数学草图的提案"。第四，**进化的归责空白**：一条自写技能在生产造成事故时，责任落在写它的智能体、读它的运行时，还是批准架构的团队？第 17 期的身份凭据面与第 25 期的承诺面都未覆盖"被改写的策略本身"这一归责对象。第五，基准与生产的反馈分布断裂：基准租户 94.8% 的反馈触达是评测 harness 刻意制造的，用它验证过的进化机制搬到 0.6% 反馈密度的生产环境，结论不可迁移——这是第 20 期"三层证据错配"在进化场景的复现。

### 五、展望与建议

其一，**把自写文件纳入变更管理**：修订历史、评审流、版本 pin 三件套一个都不能少——智能体写 SKILL.md 应当走 PR，哪怕是自动开、人合并。其二，**反馈通道进 SLI**：反馈完成率、反馈触达边占比应成为记忆型智能体的一等指标（衔接第 25 期承诺面），没有结果信号的学习闭环不应允许开启强化。其三，**干预面决策树写进 runbook**：先用便宜的可逆面（记忆→技能→Harness→工具 schema），权重是最后手段且必须过预注册非劣性门禁——Scalably 用 53.88 美元的训练费买到这条教训，远比事后回滚便宜。其四，**进化准入复用演练证据**：第 20 期的 pass^k、故障目录与反事实验收，应作为"允许进化"的前置门禁；被进化的对象（技能/记忆/权重）与评测集、模型版本一起进入三元 pin（衔接第 17 期）。其五，为"进化"设立退役机制：规则要能像 Scalably 那样经溯源日志退役，经验池要有第 22 期所说的三态生命周期——**不会遗忘的系统不是在进化，是在淤积**。
