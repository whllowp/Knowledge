# AI-SRE 技术洞察（第 192 期）

**生成时间**：2026-11-13 20:31（北京时间）｜**窗口**：2026 年，重点最近 30 天
**本期主题**：语音面／通话面（Voice）——Agent 开始接电话；ASR 错一个字，动作就错一件事

## 题眼

158 期说「计算机使用」让 Agent 直接操作界面，166 期说「说过不等于能证明说过」，187 期说「PII 在五处复制」。语音 Agent 把这三件事同时放大：**它先听（ASR）、再想（LLM）、再说（TTS）**——**ASR 错一个数字，动作就错一件事**；**通话录音与转写又是最敏感的个人数据**；**而「客户在电话里同意过」在审计时最难举证**。大多数团队把语音 Agent 当「文本 Agent 加个麦克风」：**只记文本日志、只看端到端成功率**。**语音不是输入方式，是一条独立链路：听错、想错、说错，三种错法，三套指标。** **而端到端「通话完成」会把三种错一起盖住。**

## 一、发展趋势

**趋势一：语音从「客服 demo」进入「运维一线」。** 值班电话、告警确认、现场报修；**语音 Agent 开始接真电话**。

**趋势二：延迟从「能听懂」变成「像对话」。** 抢话、停顿、打断；**端到端 1 秒以上就不像人**。**延迟是语音的第一体验指标。**

**趋势三：转写成为证据。** 通话内容要能回放、能检索、能举证；**只存录音不够**（166 期）。

## 二、技术现状：三段链路，通常只测一段

**听（ASR）：错误最致命。** 数字、姓名、工单号；**错一个字，动作全错**。

**想（LLM）：和文本一样。** 但输入是转写，**转写错则推理全错**（96 期）。

**说（TTS）：错误最轻。** 但**读错金额/时间**同样造成误解。

**现状：只测端到端。** 通话「完成」就算成功；**没人拆开看是听错、想错还是说错**。

**三种延迟，叠起来才是体验。** ASR 首字、LLM 首 token、TTS 首音；**只优化一段，另外两段会吃掉收益**。

## 四、技术挑战

**一，数字与专名最易错。** 工单号、金额、时间；**ASR 错一位，动作全错**。

**二，延迟与准确率打架。** 大模型更准但更慢；**用户等不了 2 秒**。

**三，抢话与打断。** 用户打断，Agent 还在说；**没有 barge-in 就像和机器吵架**。

**四，口音与方言。** WER 在标准普通话与方言间差几倍；**平均值掩盖长尾**。

**五，录音同意。** 各地要求不同；**没说就录，是合规事故**（166 期）。

**六，转写与录音不一致。** 转写错、录音对；**以哪个为准**（116 期）。

**七，多语言/方言切换。** 同一通电话中英混说；**ASR 语言检测错，整段就废**。

## 五、需求分解、用户旅程与实现方案

### 5.1 需求（按优先级）

- **R1 `voice.*` 字段**：`call_id`、`asr_conf`、`wer_proxy`、`intent`、`latency_ms`、`consent`、`transcript_ref`。
- **R2 分段指标**：ASR/意图/TTS 分开测；**端到端成功不算三段都对**。
- **R3 数字校验**：金额/工单号/时间回读确认；**关键数字必须复述**。
- **R4 延迟预算**：首字/整句/打断；**分档设定**。
- **R5 同意与留存**：录音前告知；**转写与录音同留存策略**（187 期）。
- **R6 指标**：WER 代理、意图准确率、P95 延迟、同意覆盖率。

### 5.2 用户旅程

- **值班**：语音 Agent 接告警确认 → 复述工单号 → 确认 → 记录 → 转写入库。
- **SRE**：通话失败 → 查 ASR 置信度 → 发现数字听错 → 加回读。
- **合规**：抽查通话 → 听录音对转写 → 确认同意与留存。
- **客户**：打断 Agent → barge-in 生效 → 不重复。

### 5.3 实现方案（90 天）

- **0–30 天：埋点。** 分段指标；转写与录音关联；同意记录。
- **30–60 天：校验。** 数字回读；延迟预算；barge-in。
- **60–90 天：质量。** WER 长尾；方言；季度抽检；多语言检测。

**第 134 个市场空白（五项）**：分段指标覆盖率、数字回读率、延迟达标率、同意记录率、转写-录音一致率——无一内建；`voice.*`／`asr.*` 为**第 103 次无人提字段族**。本地 173／173-kb 连续第 93 期成组启用：肖汉松 22「全局调度器：分派、等待」＝全库唯一把「等待」写成组件的实践，本期首次当主线；配 158 期界面、166 期合规。判词：**本地把等待写进调度器，联网侧 2026 年才让语音 Agent 接真电话；两边都没把「这次通话听对没有」做成通话字段。**
