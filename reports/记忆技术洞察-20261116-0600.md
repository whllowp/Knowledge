# 记忆技术洞察 · 第 91 期（2026-11-16 06:00）

> 主题：记忆价值的「主体间异质性」（Inter-Personal Heterogeneity of Memory Value）——同一条记忆动作，对用户 A 是增益、对用户 B 可能是损害；"什么值得记"没有跨用户统一答案，评价标准本身必须按人定制。
> 洞察范围：2026 年，聚焦最近 30 天（2026-10-17 ~ 2026-11-16）arXiv 论文与五个指定开源项目动态。
> 固定四维度：发展趋势 · 技术现状 · 技术竞争力 · 技术挑战。

---

## 一、四维度扫描

**发展趋势**：记忆的价值判据正在从"任务条件化"（#70）与"决策中心化"（#79）再推一层——价值不仅随任务、随决策状态变，还**随人变**。PMR（arXiv 2611.14017，11-10，WSDM 2027）实证：同一个"增/改/弃"记忆动作，在不同 user persona 上产生相反效果。此前 #90 讲的是"角色不对称"（用户说的 vs 助手说的），本期讲的是"主体间异质性"（用户 A vs 用户 B）——两者正交：前者是一条对话内的说话者分野，后者是跨用户的价值分野。

**技术现状**：PMR 把评价拆成两层——通用层（universal layer，捕获跨用户的共性失败模式、五维记忆质量：完整/及时/一致/简洁/相关）与逐用户自适应层（per-user adaptive layer，建模个体 traits 作为对通用基线的 delta）。通过"量表引导的信用分配"把终端 QA 反馈细化为 per-step、per-user 的 token 级信用；量表与记忆策略在闭环中**共进化**并带反循环保证；部署时零推理开销、不依赖外部 judge。四基准 12 个设置全部最优，PersonaMem 128K 达 69.45（最强基线 MemCoE 58.67，+10.78pp），32K 76.76（+9.29pp），PERMA N-M 比 MemCoE 高 5.15pp。

**技术竞争力**：竞争焦点从"谁的评价分更高"转向"谁的量表会随用户成长"。消融揭示关键反直觉：去掉跨用户共享下降最巨（−21.27pp），去掉逐用户量表仅 −4.56pp——**共性底座比个性补丁更重要**；且 preference 稳定的用户反而从个性层获益更多，volatile 用户因失败模式已被通用层覆盖而获益少（volatile+高频组甚至 −4.4pp）。五项目（OpenViking v0.5.4／Hy-Memory 2.0.13＋MemHub v1.0.6／TencentDB v2.0.3／dsh v26092802／ReMe v0.4.2.2）均用全局统一抽取/重要度标准，零逐用户量表披露，倒挂延续。

**技术挑战**：①反循环的脆弱性——量表只调制信用"幅度"、方向仍由真实 QA 结果决定（w_t 限幅 [0.72,1.28]、bracket [0.86,1.14]），失败轨迹回退标准 GRPO，否则归因不可靠（去掉 positive-only 降 16.75pp）；②样本效率——逐用户 inducing 需 423 训练实例、8×A100，长尾用户冷启动存疑；③量表可解释性与隐私刻画之间的张力；④AML C2 无 inter-personal heterogeneity 维度（接 #56/#69）。

## 二、需求分析

用户真正怕的是"我的记忆系统用别人的标准评判我"。当下记忆系统对所有人套同一套重要度与抽取规则：爱折腾的用户嫌它记太多噪声，偏好稳定的用户嫌它漏掉个体特有的关注点。需求本质是：把"什么值得记、记得多严"的**评价标准本身**当成需要按人学习的一等对象，而非全平台写死；同时这套标准不能自说自话——必须与真实结果锚定、可审计、且不增加线上推理成本。

## 三、用户旅程

①冷启动：新用户先用通用量表 R_uni，不强行个性化（避免 over-personalization 噪声，去掉 coverage test 降 17.71pp）；②画像累积：系统比对成功/失败轨迹，失败率超阈（θ_active=0.3）的维度才激活个体 delta；③共进化：个体检查若在 ≥40% 用户出现（θ_flow=0.4）则提升进通用层并从各人量表剪除，防膨胀；④记忆写入：按本人量表做 token 级信用分配，放大已验证决策；⑤部署：量表 amortize 进策略权重，推理时不注入、无 judge；⑥纠错：某用户偏好漂移导致量表失准，走重归纳回退。

## 四、具体实现方案

1. **双层量表数据契约**：记忆 schema 增 `rubric_uni`／`rubric_spec(user)` 字段，五维（完整/及时/一致/简洁/相关）各含 universal goal＋user-specific standard＋diagnostic check（深化 #28 schema，本期 schema 是"评价尺"而非"世界观"）。
2. **反循环信用门**：复用 PMR 的 Ā_t = A^traj·[1+λ·g^dir·m^ent·(w_t−1)]，方向由 QA 结果定、量表只调幅度；失败轨迹回退 GRPO，封堵量表自证（接 #89 证伪准入，彼管经验能否入库、本期管"用谁的尺"评价入库动作）。
3. **流量闸门与覆盖测试**：θ_flow=0.4 促个体规则上升通用层，coverage test 防 per-user 噪声；stable 用户优先分配个体量表预算。
4. **评测补维**：AML 增 inter-personal heterogeneity——同一动作跨用户价值方差、通用层覆盖率、个体量表净增益、反循环失守率。

## 五、本期新观点（六之六十二）

①价值判据补第三轴：任务条件（#70）／决策条件（#79）之外，主体条件是第三维——"重要度"应是 f(内容,任务,人)，把 #1 写入闸门从"谁写的"扩展到"对谁重要"；②与 #90 划界：角色不对称管一条对话内用户 vs 助手，主体间异质性管跨用户，二者正交且可叠加；③反直觉深化 #77/#89——共性底座 >> 个性补丁（−21.27pp vs −4.56pp）、稳定用户比易变用户更需个性化，挑战"越个性越好"直觉；④量表与策略共进化＋反循环，把 #69 元进化从"治理政策"推广到"评价标准"，且把 #89 verifier 独立性要求前移到评价尺设计；⑤AML 应补 inter-personal heterogeneity 维度，接 #56/#69。
