# AI-SRE 技术洞察（第 198 期）

**生成时间**：2026-11-16 01:31（北京时间）｜**窗口**：2026 年，重点最近 30 天
**本期主题**：泄漏面／资源泄漏（Leaks）——Agent 不关的东西，最后都变成故障

---

## 题眼

95 期说「收容与剩余授权」、121 期说「共享池边界」、178 期说「锁」、197 期说「工作区文件」。这四件事在**资源泄漏**上合成一个最不显眼的故障：**Agent 为了干活，开数据库连接、开 HTTP 连接、开浏览器上下文、读大文件进内存**——**正常路径会关，异常路径不会**。而 Agent 的异常路径特别多：**工具超时、模型报错、任务取消、重试**——每一次跳过 `finally`，就漏一个句柄。**泄漏不会立刻报错，它只会让系统「越来越慢、越来越贵、最后连不上」**。**而大多数 Agent 栈只监控内存，不监控句柄**；**连接池满了，看起来像「工具变慢」，其实是自己没关。** **泄漏的代价不在当下，在「某一天突然连不上」。**

## 一、发展趋势

**趋势一：从「靠 GC/连接池兜底」转向「作用域清理」。** 谁开谁关；**异常路径也要关**。

**趋势二：最大存活时间成为标配。** 连接/上下文不无限复用；**到点强制回收**。**「池子大」不如「活得短」。**

**趋势三：泄漏检测进 Agent 栈。** 按任务统计句柄增长；**泄漏率进看板**。

## 二、技术现状：四类泄漏，通常只测一类

**数据库连接：最致命。** 池满即全挂；**报错像「数据库慢」**（121 期）。

**文件句柄：最隐蔽。** 打开不关；**inode 耗尽才报错**（197 期）。

**浏览器上下文：最贵。** 每个上下文几百 MB；**不关就 OOM**（158 期）。

**内存：最常测。** 但**内存涨了不一定看得出来是泄漏**（长上下文也会涨，151 期）。

**现状：只监控内存。** 句柄、连接、上下文数量；**都没有指标**。

**三种症状，都像别的病。** 变慢（像下游慢）、池等待（像流量大）、OOM（像内存不够）；**三种都会把排查引向错误方向**。

## 四、技术挑战

**一，异常路径不清理。** 工具超时、模型报错；**跳过 `finally`**（95 期）。

**二，重试叠加。** 每次重试开新连接；**旧连接没关**（40 期）。

**三，长任务累积。** 跑几小时的任务；**句柄慢慢涨**（120 期）。

**四，池共享。** 多 Agent 共用一个池；**一个漏光，全体等**（121 期）。

**五，内存与泄漏难分。** 长上下文也涨内存；**要看句柄才能区分**（151 期）。

**六，泄漏不可见。** 没有句柄指标；**只能等「连不上」**。

**七，GC 会掩盖泄漏。** 内存回收了，句柄没回收；**内存正常，连接没了**。

## 五、需求分解、用户旅程与实现方案

### 5.1 需求（按优先级）

- **R1 `leak.*` 字段**：`task_id`、`open_handles`、`open_conns`、`contexts`、`closed`、`leaked`。
- **R2 作用域清理**：开/关配对；**异常路径也执行**。
- **R3 最大存活时间**：连接/上下文到点回收。
- **R4 泄漏检测**：任务结束对比开/关；**差值即泄漏**。
- **R5 池隔离**：按 Agent/租户分池；**防一个漏光全体**（121 期）。
- **R6 指标**：句柄增长、池利用率、泄漏率、回收时延。

### 5.2 用户旅程

- **平台工程师**：任务结束 → 对比开/关 → 发现漏 3 个连接 → 修清理。
- **SRE**：池等待飙升 → 查泄漏 → 回收 → 加最大存活时间 → 记录泄漏率。
- **安全**：浏览器上下文残留 → 清 cookie/缓存 → 回收。
- **审计**：抽查任务 → 开/关配对 → 确认无泄漏。

### 5.3 实现方案（90 天）

- **0–30 天：埋点。** 句柄/连接/上下文计数；开/关记录。
- **30–60 天：清理。** 作用域清理；最大存活时间。
- **60–90 天：检测。** 泄漏率；池隔离；季度演练；GC 掩盖排查。

**第 139 个市场空白（五项）**：句柄统计覆盖率、泄漏率可测率、作用域清理覆盖率、最大存活时间覆盖率、池隔离率——无一内建；`leak.*`／`handle.*` 为**第 108 次无人提字段族**。本地 173／173-kb 连续第 98 期成组启用：肖汉松 22「全局调度器：分派、等待」＝全库唯一把「等待」写成组件的实践，本期首次当主线；配 121 期池边界、197 期工作区。判词：**本地把等待写进调度器，联网侧 2026 年才承认「异常路径不清理」；两边都没把「这次任务漏没漏」做成运行时字段。**
