# 记忆技术洞察 #74 · 记忆删除保真度："遗忘"为何是 AgentMemory 的隐形 SLA

> 时间：2026-11-13 06:00｜期数：第 74 期｜四维：发展趋势 / 技术现状 / 技术竞争力 / 技术挑战
> 新增角度：记忆的"遗忘保真度（Forgetting Fidelity）"——把"用户要求删除后，信息是否真的不可恢复"立为记忆系统的一等 SLA（与 #55 状态协调、#66 无丢失合并并列）。本期与 #19 代谢、#54 投毒、#60 回滚、#66 压缩、#67 共享投毒显式划界：彼管"自然衰减/恶意注入/可回滚/整理风险/共享爆炸半径"，本期管"合规遗忘——用户说了删，系统是否真的忘了"。

## 一、四维速览

**发展趋势**：2026 下半年"记忆可控性（memory control）"由边缘话题跃升为 NeurIPS 2026 主流议题。Bemula（arXiv 2610.18052，10-13）首个记忆遗忘基准、MemCtrl 与 Deleted-Is-Not-Forgotten 与 MemLeak 三篇 NeurIPS 2026 同台，评测重心从"记得住"转向"忘得掉"。

**技术现状**：删除普遍是"记录级假删除"。MemLeak 显示删文本+关联图后 VLM 仍能凭保留图的隐式视觉线索恢复 12.0% 已删事实；内容感知语义删除才压到 2.0%。Deployment-Time Memorization（arXiv 2606.10062）测得"只删原文"在 LongMemEval 留约 20% 残留（FRS）。

**技术竞争力**：学术侧已形成 IPG 溯源图、MemLeak/MemCtrl/Bemula 三基准、trajectory audit 方法论；产品侧六家（TencentDB v2.0.3 / Hy-Memory 2.0.14 / OpenViking v0.5.4.1 / dsh v26092802 / ReMe v0.4.2.2）零"遗忘保真度"承诺、零跨层联级删除，倒挂延续。

**技术挑战**：删除是"轨迹性质"而非"快照性质"——Deleted-Is-Not-Forgotten 证明依赖感知删除仅留 7% 即时残留，但 93% 事实在 5 个常规非对抗会话内被"复活"（恢复 92% / 工具产物 77% / 同伴副本 71%），85% 写回存储；仅源撤销不删保留 99%。

## 二、需求分析

企业部署长期记忆 Agent 面临 GDPR 第 17 条"被遗忘权"与数据最小化刚需。Bemula 实测六系统+三主干无一个端到端通过超 1.5% 的遗忘请求，多数零通过——要么留可提取残留，要么多删无辜记忆。MemCtrl 指 ChatGPT/Claude 在受控场景仍泄露受限信息 77.4%–83.3%。缺口真实且合规级。

## 三、用户旅程

用户："请忘掉我上周说的住址。" → 系统删文本记录并回"已遗忘"。但（1）衍生摘要/嵌入/图谱边仍含该事实；（2）无关图含隐式视觉线索；（3）5 次后续正常对话后，检查点恢复/同伴副本/工具产物把事实"复活"；（4）源系统撤销权限却从不触发删除。用户以为删了，审计却发现仍可恢复——信任崩塌。

## 四、具体实现方案

1. **删除作用域图（Deletion Scope Graph）**：扩展 #1 origin_id，把单事实血缘扩成跨"表征层（文本/嵌入/图/视觉特征）+ 副本（同伴 agent/检查点/工具产物）+ 未来复活通道"的作用域图，每节点标 deletion affordance（addr/link/unreach，源自 IPG）。
2. **联级删除带回执**：删除请求触发对所有 addr/link 节点重摘要、丢弃或 tombstone 红化，返回"删除保真度收据"（含残留上界）。
3. **轨迹审计 + 复活抑制**：定期重扫可达状态；对检查点/同伴副本/工具产物设写时来源标注与防写回闸门；把"源撤销"设为删除触发器。
4. **新增 forget_fidelity 计量**：建议在 AML 增"遗忘保真度"列（接 #56/#69/#73），以 Bemula/MemLeak 为口径。

## 本期新观点

①**删除是轨迹不变式而非快照断言**：当下审计量错不变量——应在每个后续时刻、每个可达状态都不可恢复，而非"删完那一刻不可恢复"。②**遗忘保真度应成记忆一等 SLA**：与召回率对称，记忆价值 = 能记住什么 ∪ 能证明忘掉什么。③**隐私-效用-可删三角**：摘要提隐私(−60% 提取)却破坏可删(衍生副本幸存)，而复活机制使即便清掉衍生副本仍被同伴/检查点复活——可删性 = min(所有表征 × 所有副本 × 所有复活通道)。④**IPG 须跨 agent**：单 agent 内溯源不够，需跨 agent/检查点/工具的删除作用域图。⑤**产品倒挂 + AML 缺口延续**：六家零 unlearning 承诺，AML 无 forget_fidelity 维度。
