# 记忆技术洞察 · 第 127 期（20261120-0400）

**主题：记忆的「不确定性传承」（uncertainty handoff）——上游把结论交给下游时若只传答案、不传"还可能有别的答案"，暂定假设就被当成事实一路传下去。11-19 LProp（arXiv 2611.23564，圣母大学 Kaiwen Shi 等 6 人，cs.AI）把不确定性做成可携带、可随新证据改写的潜在载体：既不像标量分数那样丢掉供修订的备择，也不像文本反思那样越传越贵。前 126 期把置信度当单条记忆的属性（#65 信念化校准），本期问的是"交接时这份不确定性保不保真、改不改得动"。**

> 洞察范围：2026 年（近 30 天为主）。四维度：发展趋势 / 技术现状 / 技术竞争力 / 技术挑战。

## 一、发展趋势

#65 把置信度确立为单条记忆的静态属性——可衰减、可累积、可触发闸门，但预设"记住一条、判一次信"。LProp 把镜头移到多步任务的手递（handoff）：前一步判断是后一步前提，只传结论不传不确定性，等于把"暂定"伪装成"确定"。趋势是记忆从"条目属性"扩到"跨步传承载荷"：既保留答案，也保留候选备择及支撑分布，并能被后续证据改写。与 #115（带进度证据）、#94（判得准不准）划界——本期管判错后能否被纠正。

## 二、技术现状

两个部件。①潜在不确定性估计器：从冻结骨干隐藏态构造特征，经条件滤波读出固定答案错误风险，用"答案是否错"的二分类监督训练，不改答案。②答案索引载体 C=⟨答案、源内容潜在向量 h、支撑权重 w⟩，K 个候选权重归一，初始取自源答案分数，构造不用未来证据与金标，域外质量由残差类兜底，体量仅 O(Kd)。LProp 交接时把继承分布与公开证据按门控 α 混合、再乘逐候选残差更新权重；内容按"当前证据减参考证据"有界差分修订，不采样轨迹、不生成反思。

## 三、技术竞争力

四基准（BoolQ／StrategyQA／MMLU 数学／HotpotQA）×两骨干。Qwen3-8B 上 BoolQ F1 从 SAUP 0.763、UProp 0.787、AUQ 0.748 提到 0.831，AUROC 0.796；Mistral-7B 的 MMLU F1 从 0.468 提到 0.589。八个传承设定 F1 全最高、推理 token 全最低，较 AUQ 省 61.2%、较 UProp 省 71.1%；36 个拒答点中 35 个保留答案正确率高于 AUQ。案例：统计题初稿答 D（91.56%），公开推导后 B 升至 76.93%，复核后 87.32%；不确定性 8.44%→23.07%→12.68% 先升后降，关掉更新则锁死在 D。

## 四、技术挑战

①估风险≠改信念：SAUP／TRACER／UProp 只聚合或区分风险，不说明如何修订；AUQ 存文本再反思，文本会陈旧且要额外生成，风险高不等于知道改成什么。②选择性修订难：匹配消融中"冻结内容"在 StrategyQA 反而多救回几条错题，却引入更多回归——会改与改对是两件事。③载体税：需骨干隐藏态与答案分数，纯文本接口用不了；载体与骨干表示绑定，换模型要重训；省 token 不等于省时延。④五项目倒挂：OpenViking v0.5.5、Hy-Memory 2.0.16＋MemHub v1.0.7、TencentDB v2.0.4、dsh v26092802、ReMe v0.4.2.3，零跨步潜在载体、零证据条件修订、零继承内容保真。

## 五、需求分析

长程 agent 里前一步草稿是后一步前提。把"分位差"误判成偏度的初稿若当确定事实交接，下游会沿错方向推理。用户要的不是给记忆贴分数，而是：判断传下去时连同"考虑了哪些备择、各有多少支撑"可携带；新证据到达能就地纠正，不必重跑轨迹或写长反思；且纠正可审计——知道哪条证据把权重从 D 挪到 B。

## 六、用户旅程

数据分析 agent 答统计题。私有求解器出初稿 D（91.56%），把候选内容与支撑打进载体交给公开求解器；公开推导指出分位差衡量离散度，门控判证据有变，把 B 抬到 76.93%、D 压到 21.72%，不确定性先升到 23.07%——旧高置信被松动；复核后 B 升至 87.32%、不确定性回落到 12.68%，交付 B。全程未重采样、未写反思；关掉更新则锁死 91.56%，错到底。

## 七、具体实现方案

三层：①载体层＝每条交接挂 K 候选的 ⟨答案、潜在内容 h、支撑 w⟩，h 由隐藏态投影、w 由源分数初始化，禁看未来证据与金标，残差类收容域外质量；配条件滤波供闸门用。②修订层＝交接处 w̃=(1−α)·继承+α·公开，再乘逐候选残差 ρ；内容按"当前证据−参考证据"有界差分更新，目标 −log w(y)+λ·Brier，多头平均取最大质量答案。③读出层＝不确定性＝1−选中项概率，独立于错误风险。AML 补 uncertainty-handoff 维度（传承风险 AUROC／纠错率与回归率分账／每问 token）。反证：隐藏态依赖、跨模型要重训、token 省≠时延省、非真实长对话。

## 八、本期新观点

1. **不确定性是"可修订的传承载荷"，不是标量附注**（深化 #65：从单条静态校准到跨步保真与改写）——标量丢备择、文本反思涨成本，隐藏态潜在载体是第三选项。
2. **"估风险"与"改信念"是两件事**（接 #94／#75）——SAUP／TRACER／UProp 只聚合风险、AUQ 靠文本反思，风险高不等于知道改成什么；本期把修订做成一等机制。
3. **继承内容本身就是纠错资源**（匹配消融）——潜在内容的贡献独立于答案概率与模型容量；冻结内容多救回也多引入回归，故须选择性修订，接 #114 误删／误留非对称。
4. **传承成本要算"载体税"而非只算 token**（深化 #5／#122／#124）——省 61–71% token 的代价是隐藏态访问、载体存储与学习更新，token 省≠时延省。
5. **不确定性应随证据先升后降**（反直觉，接 #65／#95）——8.44%→23.07%→12.68%：旧高置信被松动先升、确认后降；单调下降的置信反而掩盖修订。
6. **五项目倒挂＋AML 补 uncertainty-handoff 维度**——五家零跨步潜在载体、零证据条件修订、零继承内容保真；补传承风险 AUROC／纠错率与回归率分账／每问 token 三维，以"能否被下游纠正"验收而非单次答对率。
