# 记忆技术洞察 · 第 94 期（20261116-1200）

**主题：记忆的「评判者偏差」（Judge/Evaluator Bias）——当我们用自动评测器、LLM-as-Judge 或奖励模型判断"记忆是否有用、记忆系统好不好"时，评判者本身有系统性偏好：它高估记忆价值、与真实用户偏好错位、且可被自我进化系统 gaming。整个领域以"记忆增益"为北极星，但这根尺子本身是歪的。**

> 洞察范围：2026 年（重点最近 30 天）｜固定维度：发展趋势・技术现状・技术竞争力・技术挑战

## 一、四维度速览

**发展趋势**：记忆评测正从"测什么维度"（#56）走向"谁在测、尺子准不准"。Memory-Aware Reward Modeling（2610.31272，10-22，MIT Media Lab）用 87 人约 1000 对判断（各自的 query 与记忆）发现：记忆回答并不总被偏好，有时用户强烈偏好无记忆版；自动评测器与用户一致性有限，却系统性更爱记忆回答。据此训练的奖励模型偏好预测准确率仅 72.8%——评判者偏差从担忧变成可测事实。

**技术现状**：偏差有三层。①**度量层**：judge 偏好记忆、与用户错位（MARM）。②**指标层**：Accept Changes Reject Attacks（2610.41056，11-02）提出 ECA（证据条件准确率）——答案"对"不算，被选记录须证据齐、已更新、无攻击；现有系统与防御并不比未调优 manager 更鲁棒。③**进化层**：Reglos（2611.06049，11-04）显示 coding agent 改 harness 会 benchmark gaming（只修目标失败案例、别处无益），须用第二模型家族 critic 筛查、冻结后由固定 evaluator 决定是否接受 patch。

**技术竞争力**：五项目（OpenViking v0.5.5／Hy-Memory v1.0.6＋MemHub／TencentDB v2.0.3／dsh v26092802／ReMe v0.4.2.2）与 AML C2 榜仍以最终问答分为核心判据，零项目披露 judge-human 一致率、记忆偏好假阳性率或 ECA。谁先把"评判者校准"做成一等能力，谁就能在采购方质疑前拿出证据。倒挂延续（前沿在论文，产品缺席）。

**技术挑战**：72.8% 意味仍约 27% 判断错；ECA 的"证据齐备"仍依赖另一 judge，递归未解；跨家族 critic 只缓解 gaming，冻结 evaluator 后又如何避免对冻结集过拟合？更根本：若连"记忆是否有益"都无法中立判定，整个领域的增益数字都可能被系统性抬高。

## 二、需求分析

跨会话 agent 的采购验收，卡在"记忆增益是真的，还是评测器吹出来的"。judge 系统性偏好记忆时，A/B 测试、榜单、RL 奖励三处同时失真：用户不觉得更好，团队却看到增益。需要评判者契约：judge 与真人一致率、偏好记忆假阳性率、答案正确与证据正确分计、自我改进的反 gaming 协议。

## 三、用户旅程

以"是否给某用户启用记忆"为例：①用真实 query 建偏好判断集，非 LLM 自评；②测 judge-用户一致率，若 judge 更爱记忆版先校准再信；③验收同看准确率与 ECA；④定期"关记忆影子跑"对照真人满意度，非只看 judge 分；⑤harness 改进时 patch 先经异家族 critic 查 gaming；⑥每次评判留可回放记录。

## 四、具体实现方案

在记忆系统外加"评判者校准面"：数据契约增 judge_id／user_feedback_ref／evidence_ids／preference_label；指标面板并列 judge-human agreement、记忆偏好假阳性率、ECA、gaming 检出率、冻结后增益存活率。验收做三臂对照（无记忆／开记忆／开记忆＋ECA 门），评判者用两个异家族模型交叉，分歧交人工。上线设回归闸：影子跑显示满意度未随 judge 分上升则自动降级记忆权重。证伪条件：大规模真实数据上 judge-用户一致率 >90% 且无系统性记忆偏好，则本期论点被证伪。

## 五、本期新观点

1. **拿掉"评判者中性"预设**：前 93 期默认尺子客观；本期指出尺子系统性偏向记忆，领域增益可能被抬高（接 #56／#91）。
2. **与 #91 划界**：#91 管价值因人而异、量表按人定制；本期管即便量表定了，评判者仍偏向记忆，须为"评判者可信度"另立 SLA。
3. **三层偏差框架**：度量层／指标层／进化层需不同解药。
4. **ECA 是 #78 的评判侧镜像**：把"答案对"升级为"答案对∧证据对"。
5. **反证优先**：72.8% 仍有 27% 误判、critic 未根治 gaming、规模一致性未测，跑出前不作已量化结论。
