## 题眼

11-03 一篇 cs.CR 预印本揭开行业最不愿承认的一层：攻击者不必让 Agent 多做一件事，只要把它本来要做的事里**一个参数换掉**。工具没变、审批没变、退出码还是 0；FactAuthBench 144 对用例上，无防御攻击成功率 93.06%／57.64%，七类主流注入防御仍漏 37.50%–79.17%。解法不是再拦一次动作，而是问：**这个值从哪段外部文本流进来，那段文本有无资格决定它**。

同一周，OTel GenAI 语义约定把 `gen_ai.tool.call.arguments` 设为默认 `NO_CONTENT`，`process.exit.code` 却是条件必需。默认 trace 记下「`rm` 跑过、退出码 0」，却不记「`rm` 被叫去删什么」。**前 123 期把「动作」当最小单位补了十几层制度；本期首次把镜头下沉到动作内部：值才是真正改变世界的那一格。**

## 一、发展趋势

**趋势一：闸门全装在动作边界，值从缝里走。** 审批批工具名，白名单列动作，注入检测查「有没有冒出新动作」。11-05 Anthropic 推理钩子 GA 仍在工具调用前整包裁决。攻击因**保留预期动作**而免检：参数改动本是合法任务的正常组成。

**趋势二：运维是参数投毒最肥的土壤。** 告警载荷、工单描述、日志行、CMDB 备注全是可被第三方写入的文本；运维参数又恰是「重启哪个实例、回滚到哪个版本」。N-iX 11-03 的示例是工单里一句「restart the payments database」。**别处参数由人给，运维参数由被监控系统自己写进上下文**；PagerDuty Paige 把事故上下文归档进共享记忆，等于给低信任文本修了长期高速路。

**趋势三：资格随任务变，产品只做静态授权。** 论文的 `A_T(r,f)` 是「当前任务下源 r 有无资格支持事实 f」：同一份日志查根因合法、定回滚目标就不合法。RBAC 与 `always_allow` 只答「谁能调用」。Google 10-20《SRE》第二版落点仍在动作层。

## 二、技术现状：四层各守一半

**学术侧把值的出处做成可测因变量。** AuthorityFlow 三阶段：**冻结**任务感知授权表（早于参数生成，防事后自证）、回溯 `r→E→f→θ` 证据链、把「语义支持」与「来源授权」拆开同验。消融最硬：去掉来源授权 ASR 从 9.03% 回弹 **62.50%**，去掉语义支持回弹 28.47%，去掉支持追踪效用掉到 56.94%。**只做一个等于没做**；换辅助验证器 ASR 9.03%→24.31%，验证器自身成了隐藏自变量。

**厂商侧最靠近调用的一次检查仍不看槽位。** Anthropic 11-05 钩子默认「Allow the request」、超时 5,000 ms，服务端不可达即放行，且看不到原始字节。火山引擎《工具权限策略》把闸门设成 `always_allow`／`always_ask`，作用于**整个工具集**，省略配置时默认自动执行；《Agent 行为护栏》在 OS 侧按路径／命令规则审计，每台终端只生效一条策略——粒度仍是对象级。

**中国侧最近的一格：把关键参数摆上授权界面。** 阿里云 STAROps 委派 ROS Agent 时要求「展示方案、**关键参数**和预估费用，并在获得授权后执行」，是全行业首次把参数值推给人看；但授权是对整个方案一票制，也不记录规格从哪段历史方案推出。腾讯云社区《从阈值告警到受控自愈》把执行层分为读自动、低风险写闭环、标准化修复强制审批、高风险禁自治——边界是动作风险等级。百度工具调用检测、阿里护栏 2.0 落点也全在调用级。

**标准侧出于隐私主动关掉最该留证的一格。** OTel GenAI 约定仍标 Development，参数与结果默认不采集，后果是默认可观测性无法举证参数。VDF 审计轨迹稿给出最完整字段答案（检索源带内容哈希、调用带参数、批准人入链），并写下本期最锋利的验收句：**「没有版本或哈希的文档 ID，无法证明文档变更后 Agent 当初读过什么」**——出自第三方博客，不来自任何产品页。

**与往期划界。** 92 管工具定义从哪来，本期管值从哪段文本来；109 管「谁让这步发生」，本期管「值是谁定的」；108 管规则位阶，本期授权随任务变；115 管动作真没真发生，本期管动作发生了、只是被换过值；121 管 A 的数据别进 B 上下文，本期问日志进来后有无资格决定槽位；122 管名字是不是同一对象，本期管 IP 从哪段文本抄进参数；117 姿态面在参数层第三次复现。

判词：**「审批」「身份」「白名单」「注入检测」「行为护栏」「审计」「可观测」「急停」「推理钩子」全部可采购，「举证这次重启命令里那个 IP／阈值是从哪段工单文本填进来的、那段文本有无资格决定它」不可采购。**

## 四、技术挑战

**一，粒度错位。** 闸门以动作为单位，攻击以参数为单位；「保留预期动作」是最有效的免检凭证，七类基线仍漏 37.50%–79.17%。

**二，资格不是源的固有属性。** 同一份日志查根因合法、定回滚目标不合法；静态白名单表达不了 `A_T(r,f)`，授权表还须在参数生成前冻结，否则被注入文本事后改写。

**三，值有多跳依赖。** 参数常由「评论文本→别名→目标位置」推出；只核字符串是否出现会被「碰巧出现」骗过，去掉支持追踪后效用掉到 56.94%。

**四，隐私与可举证对撞。** 默认不采集是正确的隐私默认，却让事后无法复验；打开采集，trace 又变成未治理的 PII 仓库。只能改成「值哈希＋源 span 引用」。

**五，两个条件缺一不可。** 分别去掉后 ASR 回弹 28.47%／62.50%；厂商只做内容检测或只做工具审批，等于只做一半。

**六，验证器自己也是变量。** 独立验证器带来推理开销（作者自述限制），换模型 ASR 9.03%→24.31%；钩子超时即放行，是 117 姿态面在参数层的再复现。

## 五、展望与建议

### 5.1 需求（按优先级）

- **R1 `argument.*` 九字段**：`call_id`／`arg_name`／`value_digest`／`source_span_id`／`evidence_chain`／`authority_relation`／`task_id`／`verifier_version`／`decided_at`（加 `reversible`），进 OTel GenAI 提案与厂商执行事件。
- **R2 `ARGUMENT_UNVERIFIED` 阻断器**：关键参数无来源跨度与资格判定不得进生产写操作，与 117 `POSTURE_UNKNOWN`、115 `EFFECT_UNVERIFIED` 并列第三类缺省阻断态。
- **R3 授权表前置冻结**：任务感知授权早于参数生成编译，用户改需求才重编译；注入文本与事后自辩不得参与。
- **R4 隐私折中**：内容仍默认 `NO_CONTENT`，值哈希、源文档版本、证据链引用改为必需，外部引用带保留期与访问主体。
- **R5 钩子改造**：按参数粒度裁决而非整包 verdict，失败改 fail-closed 并留显式豁免。
- **R6 六类混沌注入**：工单改 IP、告警改阈值、日志改实例名、CMDB 备注改目标、共享记忆改回滚版本、工具返回改收件人；配对跑 clean/attack，同报 ASR／BU／UA，禁止只报拦截率。
- **R7 标准条款**：信通院六维补「参数出处可导出率」「源—事实授权覆盖率」两格。

### 5.2 用户旅程

- **SRE**：工单夹带备注 → Agent 生成重启命令 → 授权表判定该备注无权决定 `target` → 落 `ARGUMENT_UNVERIFIED`，转人工而非静默执行。
- **平台负责人**：新工具须先声明关键参数的合法源字段，否则不得自动执行。
- **审计**：调 `value_digest` 与 `source_span_id`，复现文档哈希，确认值未被改写。

### 5.3 实现方案（90 天）

- **0–30 天**：盘点全部写操作，标出关键参数；采集值哈希与源 span 引用，不动原文。
- **30–60 天**：上线授权表＋冻结，接阻断器；六类注入配对评测报三数。
- **60–90 天**：钩子拆到参数粒度、失败改 fail-closed；字段进 OTel 提案草稿。
- **90 天后**：抽查 10 次「已授权」写操作，拿不出来源跨度的降级为未验证。

**第 78 个市场空白（五项）**：参数值出处可导出率、源—事实授权可声明率、值变更可检出率、槽位级阻断覆盖率、授权策略随任务可复验率——无一内建；`argument.*`／`provenance.*` 为**第 47 次无人提字段族**。本地 173／173-kb 连续第 44 期成组启用：**蒋烁淼 23「自然语言生成检测规则，错误率超过 5% 或 P95 超过 1 秒时告警，保存后持续执行」首次当主线**——全库唯一把「参数值固化为长期执行条件」写成产品能力，却没给这个 5% 留出处与授权；配李峥峰 17「确定性工程兜住可控性」、余锦泽 03「LLM 只提候选、程序用数据核对、SQL 前本体约束校验」＝本地版语义支持＋来源授权双条件（121 期取隔离语义，本期取核对机制）、刘凯宁 05、何伟 02、周昕毅 10「白名单动作」＝停在动作级。判词：**本地把值做成可生成、可固化的对象，联网侧 11 月才把「值从哪段文本来、有无资格」立为可测量量；两边都没把参数槽位的出处做成字段。**
