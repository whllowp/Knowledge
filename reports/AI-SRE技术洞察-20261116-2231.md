# AI-SRE 技术洞察（第 233 期）

**生成时间**：2026-11-16 22:31（北京时间）｜**窗口**：2026 年，重点最近 30 天
**本期主题**：交易面／代理支付（Agentic Commerce）——Agent 替人花钱；限额、授权、退款、对账，四件事都没标准

---

## 题记

11-16，博报堂与博报堂 DY ONE 发布「Data Enrichment on Shopify」，面向 **agentic commerce**——**AI Agent 自主完成从搜索、比价到支付的全程，代表消费者**。11-11，Cequence/KPMG 的报告说，**Agent 已经在代客户登录、预订、购买**（211 期）。125 期说「99.99% 赔不了答错」，143 期说「一次循环能在账单来之前烧掉三天」。这四件事合起来，是 Agent 走进**真钱**之后的新问题：**替人花钱的 Agent，限额多少、谁授权、退款算谁的、账怎么对？** **模型答错只损失一次对话；Agent 付错是直接损失钱。** **支付不是又一个工具，是唯一一个「错了不能重放」的工具**（229 期）。**而「不能重放」的东西，恰恰最需要幂等。**

## 一、发展趋势

**趋势一：从「推荐」到「代付」。** 不只给建议；**直接下单付款**（11-16）。**推荐错了是体验问题，代付错了是资损。**

**趋势二：从「账号密码」到「委托凭证」。** 不是共享卡号；**是带范围与限额的委托**（199 期）。

**趋势三：从「退款」到「争议」。** 谁举证、谁承担拒付；**支付网络规则还没为 Agent 写**。

## 二、技术现状：四种控制，通常一种都没有

**限额：最少。** 单笔/日累计/商户白名单；**多数 Agent 拿的是完整卡**。

**授权：最模糊。** 用户说「帮我买」；**买到什么算越权**（211 期）。

**退款：最乱。** Agent 发起退款；**重复退款、退给谁**（229 期）。

**对账：最缺。** 每笔 Agent 交易；**对不上订单/发票/预算**（165 期）。

**现状：给了卡，没给边界。** 能买；**不知道买了多少、买了什么**。

**三种付款方式，一种比一种激进。** 共享卡（最危险）、虚拟卡（可限额）、委托凭证（范围+限额+有效期）；**多数 Agent 还在第一种**。

## 四、技术挑战

**一，支付不可重放。** 退款重试＝退两次；**幂等键必须进支付**（229 期）。

**二，没有 3DS。** Agent 过不了人机验证；**要么绕过、要么失败**。

**三，拒付责任不清。** 持卡人说没授权；**商户找谁**（125 期）。

**四，退款循环。** 退到错误账户；**再退一次**（229 期）。

**五，对账断链。** Agent 订单与发票/预算对不上；**财务不认**（165 期）。

**六，额度被刷。** 循环购买；**账单来才发现**（143 期）。

**七，跨境与税。** Agent 买海外商品；**税/汇率/合规**没人算（140 期）。

## 五、需求分解、用户旅程与实现方案

### 5.1 需求（按优先级）

- **R1 `commerce.*` 字段**：`agent_id`、`mandate`（范围）、`limit`、`merchant`、`amount`、`receipt_ref`、`dispute_ref`。
- **R2 委托凭证**：范围＋限额＋有效期＋可撤销；**不是共享卡**（199 期）。
- **R3 支付幂等**：任务级键；**重试不重复扣款**（229 期）。
- **R4 退款规则**：谁能发起、退到哪；**幂等**。
- **R5 对账**：订单↔发票↔预算；**三方对上才算完成**（165 期）。
- **R6 指标**：限额覆盖率、支付幂等率、对账一致率、争议率。

### 5.2 用户旅程

- **用户**：设定预算与商户范围 → Agent 下单 → 收据进账 → 可随时撤销委托。
- **财务**：对账 → 发现异常单 → 冻结该 Agent 委托。
- **SRE**：支付失败 → 查幂等键 → 重试不重复。
- **审计**：抽查一笔 → 委托/限额/收据齐全 → 通过。

### 5.3 实现方案（90 天）

- **0–30 天：凭证。** 虚拟卡/委托；限额。
- **30–60 天：幂等。** 支付/退款键；对账字段。
- **60–90 天：争议。** 举证模板；季度演练；跨境税核对。

**第 163 个市场空白（五项）**：委托凭证覆盖率、限额覆盖率、支付幂等率、对账一致率、争议举证率——无一内建；`commerce.*`／`mandate.*` 为**第 129 次无人提字段族**。本地 173／173-kb 连续第 119 期成组启用：朱革 15「统一权限、审批、回滚」＝全库唯一把「权限与回滚」写成治理闭环的实践，本期首次当主线；配 125 期赔付、229 期重放。判词：**本地把权限回滚写进治理，联网侧 2026 年才让 Agent 代付；两边都没把「这笔钱在不在授权内」做成支付字段。**
