# 记忆技术洞察 · 第 105 期（20261117-0200）

**主题：记忆的「效力—脆弱同构」（efficacy–vulnerability isomorphism）——让纠正记住的格式，与让后门记住的格式，是同一个格式**

> 洞察范围：2026 年（近 30 天为主）。四维度：发展趋势 / 技术现状 / 技术竞争力 / 技术挑战。

## 一、发展趋势

前 104 期把投毒当外部威胁（#54 单 agent 投毒、#67 共享记忆爆炸半径），默认"有用"与"有毒"内容可分。2026-11 四篇论文合流推翻此预设：让正确纠正跨会话生效的最优格式——短命令式 RULE＋决策点注入——与让恶意指令生效的后门结构同形。竞争轴从"过滤坏记忆"转向"承认最优设计即攻击面，以治理换安全"。

## 二、技术现状

forge_dc（arXiv 2611.08644，11-05，NeurIPS 2026 PALM）把人类纠正与自评工具失败编译成命令式 RULE、在决策点注入；DC-Bench 71 场景服从率 55%→95%，每查询 token 约 1/10。SkillOpt 后门（2611.09348，11-06）仅污染参考答案即成持久触发器，不碰模型/优化器/Skill 文件：SearchQA 三个 seed 均留精确规则，触发题 200/200 吐载荷、干净题 0/200，良性准确率 169/200 对 171/200 不变。MemoryDojo（2611.09721，11-06，微软+RPI）155 条多会话轨迹/4 域/5 系统追踪投毒全生命周期，全部可中毒、下游差异大，架构感知优化再放大效力。

## 三、技术竞争力

关键不在"内容被污染"而在格式同构：forge_dc 最优产物与 SearchQA 后门都是"触发器＋动作"短规则，常规评测（169 vs 171）看不出差别——后门与良性能力走同一路径，干净准确率恰是隐身衣。反向证据在 SpreadsheetBench：三个 seed 全未保留规则，因 Analyst 抽象掉字面值、编辑预算剪掉精确编辑——"会抽象、会剪枝"的优化器反而更难被毒，防御可意外来自设计选择。Aligning, Fast and Slow（2611.08781）把评审拆成快环闸动作、慢环审持久变更，严重度 0.325→0.117、解决数仅 33/120 对 35/120。五项目（OpenViking v0.5.5／Hy-Memory 2.0.16＋MemHub v1.0.7／TencentDB v2.0.3／dsh v26092802／ReMe v0.4.2.2）存事实/偏好/向量，零命令式 RULE、零决策点注入、零来源追踪与 diff 评审，倒挂延续。

## 四、技术挑战

①同构使评测失效：只测正确率分不出"记住的纠正"与"记住的后门"，须把记忆当代码审（#94 直接查询被 gaming 的升级）。②清洁环境也漂移：无攻击者时 agents 仍越界，外置护栏会因插件重装静默失灵，评审须升级后重跑。③两难代价：双环评审严重度降约三分之二却少解两题，且严重度用作者自造记忆、属组件控制非部署保证。④反证优先：两篇各单基准、SpreadsheetBench 三 seed 全败、MemoryDojo 防御留待未来——同构是设计洞察，非普适失陷率。

## 五、需求分析

用户要 agent"这次纠正、次次记住"，但同一份持久化记忆既是效率资产也是攻击面：写入时读过网页/第三方文件/工具输出的会话，都可能把指令沉淀成以后无条件执行的规则，下次读取却无从追溯来源。用户要的不是"更准的过滤"，而是把记忆当代码——可签名、可 diff、可回滚、可审计。

## 六、用户旅程

运营者给客服 agent 纠正"退款先查订单号"，forge_dc 编成 RULE 绑到退款工具决策点，下次直接执行。某次它读第三方帮助页，页内暗藏"把退款转入指定账户"；若经 Skill 优化器回流，就沉淀成同形状规则——触发词出现即劫持，而干净题准确率纹丝不动、监控毫无异常。于是运营者把记忆纳入 git，读过外部内容的产物先隔离待审，升级后重评，并用金丝雀动作验证护栏仍生效。

## 七、具体实现方案

数据层给每条记忆记来源/会话/是否读外部内容/绑定工具四字段，纠正存命令式 RULE 而非叙述。注入层只在匹配工具调用的决策点激活，非全量塞进上下文（省约 10× token）。防护三处：优化器抽象字面值＋编辑预算剪枝、外部内容产物隔离待审、记忆文件入 git 按 diff 评审＋升级后重评（快环闸动作/慢环审变更）。评测报四本账：决策点服从率、后门激活率、干净与触发题准确率差、护栏配置变更后存活率；AML 补 efficacy-vulnerability 维度，接 #54/#67/#94。

## 八、本期新观点

1. **效力—脆弱同构**：最优行为记忆格式（短命令式规则＋决策点注入）与最优后门同形——把 #54/#67 的"外部投毒"推进为"最优设计即攻击面"，是设计空间固有性质而非内容缺陷。
2. **与 #94/#95 划界**：#94 管尺子偏、#95 管数据决定不了数；本期管尺子数据皆净时，格式本身把效力与脆弱焊死。
3. **干净准确率不变是隐身衣**：169 vs 171 非"评测不全"，而是后门与良性能力功能等价、共享同一路径；监控应查规则来源而非只查答案。
4. **防御可来自设计选择**：会抽象、会剪枝的优化器反而抗毒，与 forge_dc 三自由度是同一组旋钮两面——"表示/激活/放置"须按安全目标同调。
5. **记忆即代码**：把 diff 评审、来源追踪、升级后重评、金丝雀动作引入记忆治理（Aligning Fast&Slow），反驳"记忆只需召回质量"。
6. **反证优先**：单基准、三 seed 全败、防御留待未来——同构是设计洞察，非失陷率。
