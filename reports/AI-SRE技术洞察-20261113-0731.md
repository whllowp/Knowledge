# AI-SRE 技术洞察（第 172 期）

**生成时间**：2026-11-13 07:31（北京时间）｜**窗口**：2026 年，重点最近 30 天
**本期主题**：环境一致性面（Environment Parity）——预发跑得好、生产就变；因为预发没有那个 MCP server、那份数据、那个权限

---

## 题眼

「预发是好的，生产就坏了」是运维最老的一句话；但在 Agent 身上，它变成了四个具体的差：**模型版本差、工具集差、数据/索引差、权限差**。59 期说「智能体的考场正在成为生产资产」——考场本身有价值；本期问的是下一个问题：**考场和生产之间差着什么？** 118 期量过「换一个 harness，成绩差 7.13 个点」；127 期说 prompt/skill/model 的更新没有发布流水线；137 期说工具会在版本 pin 下漂移；142 期说数据契约会变。**四个差叠加起来，预发的「通过」就不再预测生产的「通过」——而团队还在用预发的绿灯做上线决定。** **预发的绿灯，只对预发有效。**

## 一、发展趋势

**趋势一：环境从「配置项」变成「依赖集合」。** 模型、工具、索引、权限；**任何一项不同，行为就不同**。**12-factor 的 dev/prod parity 在 Agent 时代要加两维：工具与权限。**

**趋势二：预发从「缩小版生产」变成「另一种系统」。** mock 工具、采样数据、宽松权限；**越省事，越不像**（158 期）。

**趋势三：影子流量开始替代预发。** 用真实工具、真实数据、只读权限跑影子；**比 mock 更接近，但成本更高**。

## 二、技术现状：四个差，通常只对了一个

**模型差：版本/精度/路由。** 预发用小模型、生产用大模型；**或者反过来**（128 期）。

**工具差：集合与版本。** 预发少接三个 MCP server；**或者版本不同**（137 期）。

**数据差：索引与快照。** 预发用上周快照；**生产是实时索引**（134／168 期）。

**权限差：能做什么。** 预发能写、生产只读；**或者生产多了一个危险工具**。

**三种假一致，一种比一种贵。** 清单一致但版本不同、版本一致但数据不同、数据一致但权限不同；**只对清单，等于只对了第一层**。

## 四、技术挑战

**一，mock 工具与真工具行为不同。** mock 永远返回成功；**真工具会超时、会限流、会报错**（115 期）。

**二，数据快照会过期。** 预发索引落后生产几天；**检索结果自然不同**（168 期）。

**三，权限不对齐。** 预发宽松、生产严格；**上线才发现少权限**。

**四，模型路由不同。** 预发直连、生产走网关；**网关有降级、有重试**（138 期）。

**五，成本压制保真度。** 全量影子很贵；**采样又丢长尾**。

**六，环境清单没人维护。** 新工具上线不更新清单；**清单过期比没有更危险**。

**七，多环境矩阵爆炸。** 开发/预发/灰度/生产四套；**两两比对是 6 组**，没有自动化就没人做。

## 五、需求分解、用户旅程与实现方案

### 5.1 需求（按优先级）

- **R1 `env.*` 字段**：`env_id`、`model`、`tools[]`、`index_snapshot`、`permissions`、`parity_score`。
- **R2 环境清单**：模型/工具/数据/权限四项；**版本化，随发布更新**。
- **R3 差异检测**：预发 vs 生产逐项比对；**差异超阈值阻断晋升**。
- **R4 影子流量**：真实工具＋只读权限跑影子；**对比输出差异**。
- **R5 晋升闸门**：四项一致才允许晋升；**例外要有 owner 与期限**。
- **R6 指标**：一致率、差异阻断数、影子差异率、上线后回滚率。

### 5.2 用户旅程

- **平台工程师**：新版本上预发 → 差异检测 → 发现少两个工具 → 补齐 → 再晋升 → 清单入库。
- **SRE**：生产回滚 → 查环境清单 → 发现模型路由不同 → 修预发。
- **安全**：预发多了一个写工具 → 阻断 → 移除。
- **审计**：抽查一次晋升 → 核对四项清单 → 确认一致。

### 5.3 实现方案（90 天）

- **0–30 天：清单。** 四项清单；版本化；盘点差异。
- **30–60 天：检测。** 差异检测；晋升闸门；例外管理。
- **60–90 天：影子。** 影子流量；差异对比；季度复盘；多环境矩阵自动比对。

**第 120 个市场空白（五项）**：环境清单覆盖率、四项一致率、差异阻断率、影子差异可测率、上线后回滚率——无一内建；`env.*`／`parity.*` 为**第 89 次无人提字段族**。本地 173／173-kb 连续第 80 期成组启用：余锦泽 03「上下文装配、工具调用、结果校验」＝全库唯一把「装配」写成流水线环节的实践，本期首次当主线；配 118 期可迁移、137 期工具契约。判词：**本地把装配写进流水线，联网侧 2026 年才量出「换壳差 7.13 个点」；两边都没把「预发与生产四项一致」做成晋升前置。**
