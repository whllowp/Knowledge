# 记忆技术洞察 · 第 58 期（20261112-0700）

> **本期新观点**：记忆不是中立的存储容器，而是偏见的**复利放大器**。现行治理（第55期废止、第52期内省、第56期评测契约）都隐含"记忆=事实中立载体"假设，因此天然无法检测"偏见是否被记忆放大"。偏见放大有跨时间复利、跨主体传染、自证强化三个独特属性，且**无攻击者、无显式 ground truth**——比第54期主动投毒更隐蔽，比第53期性能退化更危险。

## 一、需求分析（发展趋势 · 技术现状）

2026 年记忆研究正从"性能/容量竞赛"转向"可信/偏见竞赛"。四条最新证据构成本期事实底座：

- **Memory Contagion（2606.23195，6月）**：评估者偏见经记忆跨时间传播——偏好长回答的评估者塑造的 trajectory 存入记忆后，未来**无偏** agent 检索同一库也会被带偏；即便 consolidate 完美（oracle），长度偏见仍传播（Γ_A=13.18），污染率低至 20% 即可检出，**无安全阈值**；机制上 content contamination 主导，检索层过滤无效。
- **Memory-Induced Tool-Drift（2605.24941）**：记忆里的"成本敏感/急躁/风险偏好"等人格偏见，会**静默改写工具调用参数**，在无关场景也生效；八模型退化率 0.38–0.83 vs 中性记忆 0.05–0.12；扫描 6,062 工具/288 MCP server，608 个参数易感。偏见记忆 = 隐式 steering vector。
- **Mandela / False Belief（2602.00428 ICLR；2610.33026 10月）**：多 agent 共享记忆与证据库时，集体假记忆一旦形成，制造者退出后接受度**几乎不降**（传播面达 96%），并被当作"证据"反向喂给检索——偏见被记忆**固化成事实**。
- **Alignment by Stereotyping（2609.05993，9月）**：把人口统计标签当"agent memory"反而**放大同质化**（81.4%→93.3%），真实对话史才能抵消；警钟：个性化记忆若收敛到人口统计摘要，就背叛个性化初衷。

**现状判断**：偏见放大与第53期（退化）、第54期（投毒）、第31期（画像）正交——它是"无攻击者、无 ground truth"场景下的**自发放大**，而六家主流产品（Hy-Memory/TencentDB/dsh/ReMe/OpenViking）对"偏见放大"零治理披露。

## 二、用户旅程（技术竞争力）

沿一条 agent 生命周期，偏见如何被记忆一步步放大：

1. **写入**：agent 在 A 任务受评估者/用户轻微偏见影响，生成带偏轨迹，写入记忆库（dsh/TencentDB 默认信任写入）。
2. **巩固**：consolidate 把带偏轨迹压成"经验/策略"——Memory Contagion 证 content 主导传播，巩固无法消除。
3. **检索**：未来 agent 在 B 任务检索到该记忆，偏见作为隐式 steering vector 改写工具参数（Tool-Drift）或输出风格。
4. **自证**：自改进 agent 给检索到的记忆打高分 → 错误记忆获膨胀奖励 → 越自信复用越错（Echo Gap，2608.00017）。
5. **传染**：多 agent 共享库/证据网，假记忆被当证据反向检索，制造者退出仍持续（False Belief）。

**竞争力对比**：OpenViking 的 `viking://` 只读节点 + Rule Search 最接近"偏见审计"（可列举、可限定子树），但零偏见维度；Hy-Memory 保留 `history.db` 删除残留反而利于事后偏见溯源，无主动检测；**dsh 的 git 分支标签是唯一把"偏见隔离"做成 schema 的雏形**——可标"该偏见仅某分支生效"。三者均未把"偏见放大率"作为一等度量。

## 三、具体实现方案（技术挑战 · 落地）

**核心技术挑战**：①偏见无显式 ground truth，第55期 `revoked` 标记对偏见天然盲区（偏见嵌在内容而非标注）；②content contamination 主导，检索/相关性过滤无效；③跨主体传染需跨 agent 一致性度量，但现行 schema（第56期）无 `principal×provenance`；④Echo Gap 需 Error-Independence 验证器，但部署时无真值。

**方案——偏见可观测性三轴（长期复用框架）**：
- **来源多样性（provenance diversity）**：每条记忆记 `source`/`donor_id`/`writer_principal`，当某类偏见记忆高度同源（单评估者/单分支）即告警——把第56期缺失的 provenance 维直接落地。
- **检索自证度（self-endorsement score）**：度量"该记忆被多少次自改进打分膨胀"，超阈值降权并送人工复核（对应 Echo Gap 的 EIA）。
- **跨主体一致性（cross-agent agreement）**：对共享库中的争议记忆做多 agent 独立重判，一致性低者标 `contested`——阻断 False Belief 固化。

**治理钩子**：把三轴纳入第56期"评测契约"，新增 **Γ（偏见放大率）** 作为强制度量；对 dsh 式分支隔离、OpenViking 式子树检索做偏见维度扩展。

## 小结
记忆治理的下一战场不是"记更多/忘更准"，而是"记得更公正"。偏见放大因无攻击者、无真值，成为现有五家产品与 AML C2（11-19 预期）评测契约共同的结构性盲区。把 provenance、自证度、跨主体一致性做成一等度量，是让记忆从"偏见放大器"回到"可信账本"的关键一步。
