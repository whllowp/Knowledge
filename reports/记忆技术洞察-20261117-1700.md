# 记忆技术洞察 · 第 109 期（20261117-1700）

**主题：记忆的「间接可召回性」（indirect retrievability）——有用的记忆不必像问题：相似度检索的结构性盲区，与全池效用打分对它的替换**

> 洞察范围：2026 年（近 30 天为主）。四维度：发展趋势 / 技术现状 / 技术竞争力 / 技术挑战。

## 一、发展趋势

前 108 期在检索侧默认"相似＝相关"（#73 利用鸿沟管取到→用上、#78 读取裁决、#92 激活可用性、#79 决策效用、#95 可识别性），都在"召回集合给定后"做文章。11-16 Jetriever 指出更前置的裂缝：相似检索在"间接查询"上系统性漏掉有用记忆——"坚果过敏"与"要马卡龙食谱"无一重叠，"家里有百合"与"想养猫"无文本交集，关联只活在世界知识里。竞争轴从"召回得像"转向"召回得有用"，把检索第一性问题重新摆上台面。

## 二、技术现状

Jetriever（arXiv 2611.21478，11-16，中科大 Ruizhe Li 等）用全池效用打分取代相似度检索：把每条记忆 (q, mᵢ) 单独送进 Jev（LLM 派生的 System One 决策模型，经 RLCD 训成输出结构化二元决策与概率、不解码自由文本），直接取效用分排序，π＝argsort(−s, id)，id 破两位小数同分；无 ANN 索引、N 条记忆做 N 次独立决策。InMind 125 个间接查询上把金交换排第一 84.8%（106/125），同样 241 候选池 BM25 仅 1.6%、MiniLM 0.0%（索引用户轮次）。原始协议里 backbone 直接拿到金记忆能答对 84.0%，六个记忆系统端到端最多 14.4%——知识常在，记忆没到。

## 三、技术竞争力

关键在拆开"找到"与"排第一"：20 题对照中 Jev 与 Qwen3.5 9B 都在 rank50 命中 18/20（90%），rank1 却是 17/20（85%）对 8/20（40%）；BERT 打分器 Laya（421M ModernBERT）rank50 仅 30%。三者揭示打分器的两维能力：世界知识（BERT 缺）与排序校准（chat LLM 答案 token 概率不对齐效用），Jev 二者兼有。代价是全池 N 次决策：InMind 每问 0.00834 美元、MAB 每问 0.03103 美元（均 1258.2 候选），6,446 对 100 并发 90.16 秒；MAB 60 题四维分 55.4% 对 ReFind 44.3%（系统级对照）。五项目（OpenViking v0.5.5／Hy-Memory 2.0.16＋MemHub v1.0.7／TencentDB v2.0.3／dsh v26092802／ReMe v0.4.2.2）仍是相似度/关键词/向量召回，零全池效用打分、零世界知识桥接，倒挂延续。

## 四、技术挑战

①反证优先：20 题小样本、MAB 仅 60 题抽样、ReFind 为系统级非打分器级对照，作者明言 full-pool 只证"在测试规模可用，非任何规模免费"。②全池随库大小与长度线性增长，更大库更贵更慢、在线 p95 延迟未测。③"更便宜的第一级过滤"是陷阱——lexical/embedding 预筛恰好剪掉间接有用记忆。④分数校准未直接测，两位小数同分需 id 破局。

## 五、需求分析

用户要助手"记得自己没明说的顾虑"：说要烤马卡龙时主动避开坚果，说想养猫时提醒百合有毒，而不必每次把全部禁忌与常识重述一遍——这些人没说过、也不该要求他们说出口。

## 六、用户旅程

用户是过敏体质，只在初见时提过一次坚果过敏。数周后问"推荐马卡龙食谱"，检索只按"马卡龙/食谱"取回甜点做法，没带上过敏事实，助手热情推荐杏仁粉——恰好踩雷。若召回阶段逐条问"这条对回答有多大用"，靠世界知识连起坚果与马卡龙，过敏记忆被排到第一，答案自然避开。

## 七、具体实现方案

读侧加全池效用打分：对候选集每条并行求 s(q,mᵢ)（世界知识决策模型、二元决策＋概率、两位小数），按 (−s,id) 排序取 top-k 送答案模型，答案侧看不到分数与理由。写侧不变、仍靠抽取／巩固入库。成本控两处：按候选分批并发、设每问候选上限并报每问美元与 p95。评测三本账：间接查询 recall@1、"rank50 找到但没排第一"比例、每问检索成本，与相似基线同池对照。AML 补 indirect-retrievability 维度（间接 recall@1／找到-排第一差／桥接命中率／全池成本），接 #73/#79/#94/#96。

## 八、本期新观点

1. **检索第一性从"像不像"改为"有没有用"**：相似只是效用的廉价代理，显式查询成立、间接查询归零（BM25 1.6%／MiniLM 0.0%）。
2. **关联预设前移到召回层**：不再让 agent 先猜关联再搜（空间无穷猜不全），改为逐条裁决真实存在的记忆——把 #1 写入闸门推广到读侧。
3. **"找到≠排第一"独立成指标**：世界知识与排序校准是打分器两维能力，把 #94 评判者偏差从"打分偏"扩为"打分器能力矩阵"。
4. **全池打分＝以成本换召回完备性**：相似检索的 ANN 剪枝与全池完备间藏着"省索引费＝丢间接记忆"的隐性交易，接 #96。
5. **更便宜的第一级过滤是陷阱**：预筛剪掉间接记忆，级联须同测 recall@1 与端到端成本，接 #93/#96。
6. **倒挂延续＋AML 补维度**：五项目零全池效用打分；补 indirect-retrievability 维度（间接 recall@1／找到-排第一差／桥接命中率／全池成本）。
