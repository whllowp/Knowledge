# AI-SRE 技术洞察 · 第 163 期（2026-11-13 02:00）· 经济性护栏面（Economic Guardrail / 成本-效能可计量自治）

> **题眼**：我们已把 SRE Agent 的"能不能做"（159）"根因对不对"（160）"信号还是噪声"（156）"人信的分量对不对"（161）"连它做了什么都不在一根 trace 里可看"（162）逐一立为一等对象。还差最隐蔽的一块：**自治的经济性可计量**。当 Agent 凌晨三点花 X token、Y 分钟、Z 美元处置一起事故，这笔账算在谁头上？有没有预算闸门？成本异常有没有被当成"行为漂移的领先指标"？答案几乎全是空白——六家 SRE Agent 平台能报 MTTR 下降、能报成本账单，却无一公开"每次成功处置的成本"这个一等 SLO。本期把"成本-效能可计量自治"立为一等运维对象：自主处置可以快，但不能是一笔无法归因、无法封顶、无法预警的糊涂账。

## 一、发展趋势

成本正从"财务科目"被重定义为"可靠性 SLO"，这是 2026 年最被低估的范式迁移。

**成本成为一等 SLO，且 token 用量是领先指标。** Turion 提出的"Agent Reliability Engineering（ARE）"把 `cost_per_task`（单任务平均 token 成本）与 `decision_quality`（不被用户推翻的决策占比）列为代理系统专属 SLO，并给出关键判断：token 成本趋势是行为异常的**领先指标**——代理单任务 token 成本上升 40% 而完成率持平，常在输出质量可见劣化前 24–48 小时就发出预警。烧钱与烧误差预算同源。

**误差预算成为自治油门。** Azure SRE Agent（2026-03 GA）据误差预算消耗动态调节自治级别（降并行、插人工检查点、暂停自主动作）；Google Actus 以"Bad Customer Minutes"误差预算门控 L3→L2 降级。自治级别不是乐观时刻设的 config flag，而是度量的输出。

**Agent-native 基础设施把 tokens 当 compute。** chiefintech 预言 2027 年统一 AgentOps 看板（可观测＋成本＋策略一屏）；BCG/EY 推 AI 控制面，在**网关层**强制 token/工具限额，而非在提示词里劝导节俭——提示词说"省着用"是建议，网关拒掉一个 20 万 token 的请求才是决定。

**计费模型倒逼架构。** OpenAI Codex 2026 全量 credit 化，cached input 仅 1/10 价，动态定价与代理信用池在路上；"每次成功业务结果的成本"被推到架构层而非事后账单。

## 二、技术现状

**编码助手侧已成本可见，处置 Agent 侧仍是黑箱。** Codex/Claude Code 已把 token 成本导出为 span；prompt caching 是最大杠杆（稳定前缀走缓存，最高降 90% 重复上下文成本）；模型分级路由＋步数上限（20–40 次调用/任务）成为常规 practice。但六家 SRE Agent 平台几乎不公开"每次事故处置的 token 成本 / 成本归因 / 预算闸门"——成本只在事后账单出现，不是 SLO、不是护栏。

**反模式已定型。** "少 token→多重试→墙钟更长"（162 提过）；更隐蔽的是"单价便宜≠任务便宜"——陶炳哲实测 Sonnet 5 单价便宜 1.7×，但每任务 $2.09 vs $1.94、完成率还低 6pp，同两模型在 Hermes/Kilo/Claude Code 上贵 32%/57%/便宜 16%，成本弹性受 harness 显著影响。

**本地实践已跑通降本闭环。** 08 刘杨（蚂蚁）：混合 AI 评估（小模型＋正则粗筛 99% 流量，<1% 进大模型）做到 90%+ token 成本降低；30 陶炳哲（阶跃星辰）：智能路由本质是"执行方案匹配"（模型＋harness 联合评测，部分场景成本差 2× 而质量不变）；23 蒋烁淼（观测云）：统一数据湖支撑成本复盘；31 马云雷：轨迹资产化＝成本可计量。

## 四、技术挑战

- **概念错配**：成本被当"财务科目"而非"可靠性 SLO"。自治烧钱与烧误差预算同源，却无人把 token 成本当领先指标。
- **反模式无护栏**：少 token→多重试→墙钟更长；单价便宜≠任务便宜（harness 影响达 2×）。
- **归因断链**：成本在厂商私有账单、不在动作 trace，无法回答"这次事故处置花了多少、值不值"。
- **预算油门缺失**：多数平台自治级别是 config flag，不是误差预算的输出（Google 最佳但处置层成本闸未公开）。
- **网关 vs 提示词**：提示词劝导节俭无效，网关强制限额才 decisive（BCG/EY），六家少有网关层 token 限额。
- **评测盲区**：基准只考成功率/MTTR，不考 `cost_per_resolution`；信通院六维无成本维度。
- **第 113 个市场空白五项**（cost_per_resolution / token_cost_attribution_rate / budget_burn_leading_indicator / cost_anomaly_block_rate / cheap_model_fallback_coverage）；字段族 `cost.*`（cost_per_resolution / token_cost_attribution_rate / budget_burn_leading_indicator / cost_anomaly_block_rate / cheap_model_fallback_coverage / step_cap_enforced / cached_input_rate）第 80 次无人提字段族。

## 五、展望与建议

1. **字段 schema**：`cost.*` 七字段（cost_per_resolution / token_cost_attribution_rate / budget_burn_leading_indicator / cost_anomaly_block_rate / cheap_model_fallback_coverage / step_cap_enforced / cached_input_rate），提 OTel GenAI 提案，纳入 SRE Agent 处置层。
2. **成本进 SLO**：`cost_per_task`＋`decision_quality` 双 SLO，超 1.5× 告警（Turion ARE）。
3. **误差预算油门**：自治级别由预算消耗输出（非 config），预算将尽降并行/插检查点/暂停（Azure 范式，深化 159 确定性闸门、162 trace）。
4. **网关三阈值**：50% 预警 / 80% 升级 / 100% 拦截非关键 Agent（BCG/EY）。
5. **模型分级路由＋步数上限**：简单任务路由便宜模型，复杂任务才上旗舰；步数上限 20–40（陶炳哲路由方法论）。
6. **cached input 优先**：稳定前缀走缓存（降 90% 重复上下文成本）。
7. **成本归因到 trace**：每动作 span 带 token 成本（Aegis-Observe on SigNoz 范式）。
8. **接本地四原型**：08 的 90% 降本混合评估＋30 的智能路由＋23 统一数据湖成本复盘＋31 轨迹资产化，先把"算清自治账"做进生产闭环。
9. **评测扩展**：Incident-Arena / SREGym 增 `cost_per_resolution` 维度；信通院六维补"自治经济性达标率"格。
