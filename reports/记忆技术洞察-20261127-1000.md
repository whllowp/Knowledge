# 记忆技术洞察 · 第163期（20261127-1000）

> 洞察范围：2026 年、尤其近 30 天，AgentMemory 发展趋势／技术现状／技术竞争力／技术挑战四维度。主线：arXiv 2611.34675（11-25 提交）。已与 C/E 双版索引及知识台账比对确认未重复；最近 arXiv 批次仍停 11-25、五项目无新主线版本，按预案输出往期未覆盖的深度专题。

## 一、发展趋势

记忆系统正从"外部外壳辅助策略"走向"外壳与策略互哺共演化"。11-25《RoboEvo²: Recursive Robot Self-Improvement via Harness–Policy Co-Evolution》（arXiv 2611.34675，港大／浙大／南科大等，cs.RO）把外壳 H＝（技能库 L、持久经验记忆 M、路由 ρ）与神经策略 π 同时作为演化对象：策略失败驱动外壳搜索修复，修复轨迹反哺策略训练，升级后的策略又改变下一轮失败分布。与 #156（只优化 harness）划界，与 #153（自改权重）、#144（程序技能）衔接：本期新增"双向递归"与"记忆毕业进权重"闭环。

## 二、技术现状

每轮先由冻结策略 rollout，任务级校验分成功／失败两流。P2H 对失败并行探索 Code、Code+ICL、Code+Policy 三路，隔离分支、从失败态或匹配重置出发，每路至多留一个验证成功的程序—轨迹对，按最小归一化运动 jerk 择胜；可复用修复写回技能库新版本或路由规则，任务经验记适用条件、动作与所用技能，跨任务成立者晋升通用记忆。H2P 把成功 rollout 与验证修正入监督池，把同起点同条件的成功／失败续接配成反事实对，用 CPD 的 gap＋非对称 prox 损失训练，失败加权采样 w=(1−ŝ)^γ。候选只在匹配开发任务、初始态与预算下以 standalone／hybrid 双模式验收，胜者留、败者回滚。

## 三、技术竞争力

LIBERO-PRO 八轮 standalone 11.0→84.1%、hybrid 30.4→90.5%，单轮 API 支出 430.63→98.92 美元；RoboTwin C2R 五轮 46.0→77.5%／48.8→87.4%，支出 719.05→323.84 美元。以 2.5K 干净示范起步，自主采 5K 验证轨迹即 77.5%，同量随机数据仅 67.2%，需 27.5K 才 76.8%——仅用 27.3% 数据追平。三轮消融：完整共演化 52.3／68.3，冻结策略 hybrid 46.1、冻结外壳 33.6／49.0；单轮三路中 Code+Policy 净救 14.8 点最大，合用 49.1%。

## 四、技术挑战

内化并不消灭外壳：八轮后 hybrid 仍高于 standalone 6.4 点，PPO 后才 94.8／96.8；CPD 拆分 20.1→29.9→32.1，配对监督比单纯堆轨迹更关键。跨本体冻结外壳 45.8→42.5→41.0 有损；真实 G1-D 上 120 条自动示范达 85.0%（200 条遥操作 80.0%），加固定外壳 95.0%，但失败后需人工近似复位。

## 五、需求分析

用户要少给人示范也能适应扰动、执行时少调用昂贵推理；运营方要可追溯的失败—修复—内化链、按轮下降的代理成本，以及可跨本体复用的经验。

## 六、用户旅程

策略执行失败→定位失败步骤→检索技能与记忆→三路并行修复并验证→写回技能／路由／经验→同起点配成对→训练策略→双模式守门→下一轮针对新失败搜索；成熟能力由外壳"毕业"进策略。

## 七、具体实现方案

①外壳三件套分离版本：技能只存可执行码，经验存适用条件—动作—技能，路由为规则集，修复回写保留旧版且旧成功不回退；②同一失败只留 jerk 最小验证对，状态不匹配者仅进监督池不进偏好池；③CPD＝gap＋非对称 prox，配 (1−ŝ)^γ 失败加权；④每轮双模式＋匹配初始态守门并记 API 支出；⑤AML 补 harness-policy-coevolution 维度：晋升率、配对成品率、每轮代理成本、hybrid-standalone 落差、跨本体留存。

## 本期新观点

1. **记忆与策略互为上下游，闭环方向反转**（划界 #156／#153）——#156 只优化外壳，#153 只自改权重；本期失败轨迹写外壳、修正轨迹训策略、新策略再定义失败面，两侧交替冻结、成对守门，递归收敛才是新机制。
2. **记忆有"毕业"路径，寿命终点是内化**（接 #5／#150／#158）——任务经验跨任务成立后晋升通用记忆，验证修正再经 CPD 进策略权重；API 支出随轮次从 430.63 降到 98.92 美元、719.05 降到 323.84 美元，记忆税应记摊销与毕业率而非只记存储量。
3. **反事实配对是记忆写入的质量门**（划界 #159 来源极性）——只有同起点、同条件的验证成功／失败续接才进偏好池，不匹配者仅作监督；CPD 消融 20.1→29.9→32.1，说明可回放的配对比经验条数更决定收益。
4. **路由是记忆的调用接口，必须与技能／记忆同版提交**（接 #152）——路由只是指令中的规则集而非独立模型，三路隔离分支与 jerk 择胜构成可审计选择；跨本体冻结外壳只改控制接口，技能／记忆／路由一体留存 45.8→42.5→41.0，可移植的是三件套而非策略。
5. **hybrid-standalone 落差是内化进度的读数**（新角度）——八轮后仍差 6.4 点，说明外壳尚未完全毕业；把两模式成功率差、每轮代理成本、晋升率并排披露，可识别"记忆堆得多但没进策略"的伪进步，接 #144 覆盖与效率分账。
6. **产业倒挂与 AML 缺口**——五项目今日无新主线版本（OpenViking v0.5.6／Hy-Memory v2.0.17＋MemHub v1.0.8／TencentDB v2.0.4／dsh v26092802／ReMe v0.4.2.3）；ReMe 11-26 仅公告 HoMe harness 搜索文档，无失败→外壳→策略双向闭环、毕业与配对验收接口；AML 补 harness-policy-coevolution 维度。
