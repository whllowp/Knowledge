# AI-SRE 技术洞察（第 177 期）

**生成时间**：2026-11-13 11:31（北京时间）｜**窗口**：2026 年，重点最近 30 天
**本期主题**：编成面／组织形态（Operating Model）——Agent 归平台管还是归业务管？选错了，属主、审阅、值班全乱

---

## 题眼

146 期说 Agent 有四类属主（产品/平台/值班/预算），169 期说审阅是吞吐上限，175 期说属主走了要有人接手。这三件事都指向一个更前置的问题：**这四类属主，到底该由哪个组织来出？** 答案通常有三种：**中心化平台团队**（统一建、统一管）、**嵌入式**（业务团队自己建、平台只提供工具）、**联邦/CoE**（平台定标准、业务自己跑）。三种都有人用，**但多数组织是「混着来」**：平台管运行时不管行为，业务管行为不管运行时，**出事时两边都指向对方**。**Agent 的运维形态不是组织架构图上的一个格子，是「谁有权改、谁必须审、谁半夜被叫」的三张表。** **三张表对不上，就是组织级的技术债。**

## 一、发展趋势

**趋势一：从「谁建」转向「谁负责运行」。** 建 Demo 的人不一定是能值班的人；**运行责任要单独指派**（146 期）。

**趋势二：平台从「工具提供者」变成「标准与闸门持有者」。** 平台定基线、闸门、审阅容量；**业务定行为与优先级**（170 期）。

**趋势三：组织形态开始随 Agent 数量演进。** 少时集中、多时联邦；**但演进要有触发条件，不是拍脑袋**。**没有阈值，组织调整就变成政治。**

## 二、技术现状：三种形态，三种断层

**中心化：统一但慢。** 平台懂运行时、不懂业务；**行为变更要排平台的队**（169 期）。

**嵌入式：快但散。** 业务懂场景、不懂运维；**基线、演练、回滚各做各的**（160／164 期）。

**联邦：标准统一、执行分散。** 平台出标准、业务执行；**标准没人检查就退化**（110 期）。

**现状：责任在「平台/业务」之间悬空。** 平台说「行为是业务的」；业务说「运行时是平台的」；**出事时两边都指向对方**。

**四种断层，每种都能拖垮一次事故。** 属主断层（没人认）、审阅断层（没人会审）、值班断层（找不到人）、成本断层（没人付）；**四种断层常常同时出现，因为它们是同一个组织问题的四个面**。

## 四、技术挑战

**一，双头管理。** 平台管运行时、业务管行为；**改一个 prompt 要两边点头**。

**二，升级路径不清。** 业务解决不了找平台；**平台说「不在服务范围」**（139 期）。

**三，审阅容量错配。** 平台审所有变更，**业务场景知识不够**；业务审，**安全知识不够**（169 期）。

**四，成本归属打架。** 平台付 token、业务付人力；**没人看合计**（165 期）。

**五，人才稀缺。** 既懂 Agent 又懂运维的人少；**中心化会把它变成瓶颈**。

**六，演进无触发。** 什么时候从集中转联邦？**没有指标，只有争论**。

## 五、需求分解、用户旅程与实现方案

### 5.1 需求（按优先级）

- **R1 `om.*` 字段**：`agent_id`、`model`（central/embedded/federated/vendor）、`owner_map`（四类）、`decision_rights`、`escalation_path`。
- **R2 四类属主映射**：每类属主落到具体组织；**空缺即标 UNOWNED**。
- **R3 决策权**：行为变更谁批、运行时变更谁批；**写进 RACI**（176 期）。
- **R4 升级路径**：业务→平台→厂商；**每级有 SLA**。
- **R5 审阅分工**：平台审安全/合规、业务审正确性；**按 tier 分**（153 期）。
- **R6 演进触发**：Agent 数/变更量/事故率到阈值，评估换形态。

### 5.2 用户旅程

- **业务团队**：新建 Agent → 填四类属主 → 平台提供基线/闸门 → 业务负责行为。
- **平台**：维护标准与闸门；**不替业务做行为决策** → 季度评审标准有效性。
- **SRE**：值班按 `escalation_path` 找人；**找不到就是 UNOWNED 事故**。
- **审计**：抽查一次变更 → 核对决策权与审阅记录 → 确认没有双头签字。

### 5.3 实现方案（90 天）

- **0–30 天：映射。** 四类属主落到组织；标 UNOWNED。
- **30–60 天：RACI。** 决策权与升级路径；审阅分工。
- **60–90 天：演进。** 触发指标；季度评审形态；UNOWNED 清零。

**第 124 个市场空白（五项）**：属主映射覆盖率、UNOWNED 率、决策权清晰率、升级路径可达率、审阅分工覆盖率——无一内建；`om.*`／`raci.*` 为**第 93 次无人提字段族**。本地 173／173-kb 连续第 84 期成组启用：朱革 15「统一权限、审批、回滚」＝全库唯一把「权限与审批」写成治理闭环的实践，本期首次当主线；配 146 期属主、169 期审阅。判词：**本地把权限审批写进治理，联网侧 2026 年才量出「68% 可见 vs 82% 未知」；两边都没把「四类属主由哪个组织出」做成登记字段。**
