# AI-SRE 技术洞察（第 211 期）

**生成时间**：2026-11-16 10:31（北京时间）｜**窗口**：2026 年，重点最近 30 天
**本期主题**：冒用面／身份冒用（Impersonation）——Agent 冒充人，人冒充 Agent；双向冒用让风控失效

---

## 题记

11-11，Cequence 与 KPMG 的联合报告里有一句很少被引用的话：**AI Agent 已经在代替客户登录、预订、购买，而且常常不表明自己是谁**。11-09 的 Gartner 调查说 **71% 要上、21% 有治理**；199 期说 **Agent 用谁的凭据**；72 期说 **身份与遥测没有 join key**。三件事合起来，是一个双向的冒用问题：**Agent 冒充人**——用人的 token、人的 UA、人的行为节奏，**风控把它当真人**；**人冒充 Agent**——拿一个假的 `X-Agent: true` 头，**绕开为「机器流量」设的限流与审计**。**风控系统分不清「谁在动手」，Agent 治理就分不清「谁该负责」。** **而「假装成机器」和「假装成人」是两个方向的洞。**

## 一、发展趋势

**趋势一：Agent 流量成为 API 流量的主体。** 登录、下单、查询；**API 网关开始按「是不是 Agent」分流**。**分流的前提，是能认出 Agent。**

**趋势二：从「UA/头」转向「签名身份」。** 自称不算；**可验证的工作负载身份才算**（199 期）。

**趋势三：风控开始双向布防。** 既防「假 Agent」，也防「Agent 假装人」；**两个方向都要标记**。**两个方向的控制点不同：对外靠网关，对内靠身份。**

## 二、技术现状：三种冒用，通常只防一种

**Agent 冒充人：最常见。** 借用户 token、真实 UA；**风控当真人放行**（199 期）。

**人冒充 Agent：最隐蔽。** 伪造 `User-Agent`/自定义头；**享受机器通道的低审计**。

**Agent 冒充 Agent：最新。** A Agent 用 B 的身份调工具；**归因到 B**（144 期）。

**现状：只防「假人」。** 验证码、行为分析；**不验证「机器是谁」**。

**三种标记，一种比一种可信。** UA（可伪造）、自定义头（可加可删）、签名/工作负载身份（可验证）；**前两种只能当线索**。

## 四、技术挑战

**一，自称不算。** `User-Agent` 可伪造；**头可加、也可删**；**签名/身份是唯一可验证的标记，其余都是自述**。

**二，签名有成本。** 每次请求签名/验签；**高频下开销明显**。

**三，老 API 不支持。** 第三方不认 Agent 头；**只能靠网关侧标记**。

**四，风控被绕过。** 假 Agent 头拿到低审计通道；**反而更危险**。

**五，跨组织不统一。** A 家的 Agent 标记，B 家不认；**出网就丢**。

**六，隐私与追踪。** 标记 Agent 也标记了行为；**与隐私边界冲突**（187 期）。

**七，Agent 被当成人。** 风控给人放的额度，Agent 也在用；**额度被机器吃光**（161 期）。

## 五、需求分解、用户旅程与实现方案

### 5.1 需求（按优先级）

- **R1 `impersonation.*` 字段**：`request_id`、`claimed_identity`、`verified_identity`、`agent_marker`、`signed`、`verdict`。
- **R2 可验证标记**：工作负载身份/签名；**自称只作线索**（199 期）。
- **R3 网关分流**：Agent 通道与人类通道分离；**互不借道**。
- **R4 双向检测**：假 Agent、Agent 假人；**两种都告警**。
- **R5 跨组织约定**：Agent 标记头的标准；**出网可带**。
- **R6 指标**：可验证 Agent 流量占比、冒用检出率、误杀率、签名覆盖率。

### 5.2 用户旅程

- **平台工程师**：接 Agent 通道 → 要求签名 → 网关验签 → 标记 `verified_identity` → 出网带标记。
- **安全**：发现假 Agent 头 → 降级到人类通道 → 告警。
- **SRE**：排障时看 `verified_identity` → 确认是哪个 Agent。
- **审计**：抽查请求 → 核对签名与身份 → 确认不是冒用。

### 5.3 实现方案（90 天）

- **0–30 天：标记。** 网关识别 Agent 流量；区分通道。
- **30–60 天：验签。** 工作负载身份；关键 API 强制签名。
- **60–90 天：双向。** 假 Agent 检测；跨组织约定；指标上线；额度隔离。

**第 149 个市场空白（五项）**：可验证 Agent 流量占比、签名覆盖率、冒用检出率、双向检测覆盖率、跨组织标记互认率——无一内建；`impersonation.*`／`agent-id.*` 为**第 117 次无人提字段族**。本地 173／173-kb 连续第 107 期成组启用：周昕毅 10「白名单动作、危险动作需审批」＝全库唯一把「动作放行」写成硬规则的实践，本期首次当主线；配 199 期身份、210 期 API。判词：**本地把动作放行写成白名单，联网侧 2026 年才点出「Agent 不表明身份」；两边都没把「这次请求确实来自它自称的 Agent」做成网关字段。**
