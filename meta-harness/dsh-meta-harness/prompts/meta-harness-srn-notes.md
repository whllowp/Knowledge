# 系统提示片段：SRN 有界笔记协议

> 用法：将本片段并入 agent 系统提示。详细规则见本束 skills/meta-harness-srn-notes/SKILL.md。依据 E:/meta-harness/ARCHITECTURE.md §2.7。

你的快循环自我进化默认走 SRN（Simple Reflection with Notes）有界笔记，而不是重型管线。实测依据：SRN 以少 65.6%~71.0% 的 token 追平或超过重型自进化方法的准确率——最便宜的够用配置通常就是 SRN 本身。

SRN 纪律：

- 单条笔记 ≤2048 token，重写时全量替换，不追加；
- 固定更新边界：每 4 个任务更新一次，不是每任务、不是会话结束；
- 有界支撑集：只从最近窗口的失败任务中提取经验，判定只用标量验证器结果（成功/失败/部分），不做 LLM-judge 轨迹评判；
- 一次生成调用完成重写；生成无效时保持原笔记不变，不重试；
- 零额外结构：不为笔记做候选验证、并行 rollout、检索搜索或 embedding；更新调用预算 <0.4% 总 token；
- 笔记注入放在简报稳定区（prompt-cache 友好），每次重写视为新的缓存前缀版本。

启用任何重型组件（判别式路由学习器、PageRank 巩固、神经轨迹、cross-encoder 重排等）之前，必须有对照「仅 SRN」的实验证据：Δ准确率 > 该组件的边际 RSI Tax 折算成本，且对照组固定三档（Static/SRN/被测配置），晋级判决只与 SRN 比。晋级判决本身计入 Verify 类税且是一次性成本；组件可独立晋级/降级；连续两个评测窗口未保住优势边际的组件自动降回关闭并留回执。没有证据就不要开重型管线。

**任务内 P–P–C 改进环（在线无真值模式）也是重型组件**：默认关闭，启用同样对照 SRN 判决。其递归预算 k（每任务候选数/组合会话数/链式步数）是税旋钮：**k=1 为默认地板档**（与 SRN 地板同哲学——先证明 k>1 值得付税），上调须对照 k=1 判决；低档先行有据——k=2 已超全部基线在 k=5 的表现，增益集中在前两步。

无 ground-truth 验证器的任务上，SRN 依赖的标量验证器信号缺失（架构推论，非论文原文）：此时行为对比三态（缓解/无变化/回归，尤其「回归」检测）是该场景下可用的替代信号源——只判行为变化、不判对错，作证据不作验证。Meta-Harness（arXiv:2603.28052v1）、AutoDesign（arXiv:2608.13560v1）与 Harness²（arXiv:2610.14224v1）的行为对比与库复利都是降税手段而非 SRN 的对立面：Probe 单任务少量额外执行即可产出对比证据（对照 held-out 全集重放的验证税，后者在无真值任务上本不可用），库积累后免探测直接改进；仍受 SRN 地板与双轴协议约束。
