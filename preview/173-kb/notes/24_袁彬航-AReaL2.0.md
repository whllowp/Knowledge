## 核心观点
- AReaL = 可扩展的 Agent 强化学习基础设施，**连接基础模型训练与现代 Agent 应用**；目标让 Agent「越用越强」。
- 四特性：灵活性（模块化、即插即用）、可扩展性（稳定大规模全异步 RL）、性能领先（数学/代码/搜索/Agent 任务）、研究友好（四类 RL 范式、10 余种主流算法）。
- 三代架构演进：**推理强化学习 → Agent 强化学习 → 在线强化学习**（v0.1 2025.2 支持 GRPO → v2.0 2026.8 在线 RL 模块化），历时 18 个月。

## 关键事实/数据
- 开源背景：2025 年 2 月由**蚂蚁集团与清华大学联合开源**；2026 年 5 月获接纳为 **PyTorch 生态项目**，正申请基金会托管；OpenSSF 最佳实践金徽章（12770）。
- 社区规模：**5.7K+ GitHub 星标、500+ 分叉、100+ 贡献者、1,900+ 社区用户**；维护者由 4 人增至 14 人。
- 厂商中立治理：14 位维护者来自**清华、蚂蚁、华为、字节跳动、小米、腾讯**六家机构；每 PR 须两位维护者批准（其一为路径负责人），共识决策、首席维护者裁决。

## 主要踩坑/风险
- 大规模全异步 RL 的训练稳定性与吞吐是工程核心难点（v0.6 即实现全异步、吞吐 2.7×）。
- 开源项目治理需厂商中立，避免单家主导影响可信度。

## 可引用结论
> AReaL 让 Agent 通过在线强化学习闭环「越用越强」——开源社区以厂商中立治理支撑大规模 Agent RL。
