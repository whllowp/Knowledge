什么是 AReaL？
可扩展的 Agent 强化学习（RL）基础设施，连接基础模型训练与
现代 Agent 应用。
2025年2月，由蚂蚁集团与清华大学联合开源
• 灵活性 — 模块化架构，支持即插即用的 Agent 强化学习服
务。
• 可扩展性 — 支持稳定的大规模全异步强化学习训练。
• 性能领先 — 在数学、代码、搜索及 Agent 任务中取得领先表
现。
• 研究友好 — 支持四类主要强化学习范式及 10 余种主流算法。
